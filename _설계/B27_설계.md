# B27 체험 설계 — 같은 조건으로

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 문제 정하기와 모델 만들기(활동1·2, 그리고 뒤 차시)는 그대로 한다.

- **웹이 아니면 못 하는가.** 활동3은 `각도 정하기` `배경 정하기`를 시키고, 활동4는
  `조건과 다르게 찍은 것은 장수를 적어 두기`를 시킨다. 종이 기록표로는 찍고 나서
  세어야 알 수 있고, 대개 아무도 세지 않는다. 화면은 담을 때마다 **그 순간의 조건을
  딱지로 붙여** 둔다. 조건별 장수가 저절로 선다.
- **값을 바꾸면 결과가 바뀌는가.** 조건을 바꾸고 담으면 붙는 딱지가 달라지고 막대가 바뀐다.

**여전히 만들지 않는 것.** 후보 네 가지 가려내기, 문제 정하고 까닭 쓰기, 역할 나누기,
검사 자료를 학습 묶음에서 갈라 두기(**B26이 자물쇠로 맡고 있다**), 모델 학습, 발표.

## 1. 과정안 어디에 붙는가

- 블록 B27, 27~30차시. **활동3이 끝나고 활동4로 들어가기 직전**에 4분.
  조건을 종이에 정한 **다음**, 그 조건대로 몇 장 담아 보며 손을 맞춘다.
- 활동4의 실제 자료 수집은 그대로 한다. 이 화면이 모은 것을 쓰지 않는다.
  화면에 `진짜 자료는 따로 모아요`를 상시로 둔다.

## 2. 한 문장

지금 **조건**을 바꾸고 담으면 그 조건 딱지가 붙어, 조건이 섞인 장수가 눈에 보인다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 | 카메라 그림 | 물건을 비춘다 |
| 가운데 | 지금 조건 두 가지, 조건 네 가지별 장수 막대 | 조건을 바꾼다 |
| 아래 | `담기`, `한 장 빼기`, `다시 하기` | 담는다 |

## 4. 조작과 값

- 조절하는 값: **지금 조건** 하나. 두 갈래를 각각 누르면 넷 가운데 하나가 된다.
  - 각도: `위에서` / `옆에서`
  - 배경: `흰 종이` / `교실 바닥`
- 처음에는 **둘 다 안 골라져 있다.** 둘을 다 골라야 `담기`가 눌린다.
- 보조 조작: `담기`(지금 조건 딱지를 붙여 한 장 담는다, 최대 20장),
  `한 장 빼기`(마지막 한 장을 뺀다 — 활동4 셋째 줄 `사람이 들어온 자료는 지우고 다시 찍기`),
  `다시 하기`(다 비운다).
- 막대 넷: 조건 짝마다 담긴 장수. 가장 많은 조건과 그 밖의 조건이 한눈에 갈린다.
- 담은 그림은 24×24 미리보기로만 남긴다. **원본을 들고 있지 않는다.**

**열어 두는 딴짓.** 조건을 매번 바꿔 가며 담으면 막대 넷이 고르게 선다. 막지 않는다.
활동3의 `같은 조건으로`가 왜 규칙인지가 그때 손에 잡힌다. 화면은 나무라지 않는다.

**재미 검토(2026. 9. 17.)에서 더한 것.** 담아도 막대가 슬쩍 길어질 뿐이라 담는 맛이 없었고,
어느 조건에 몰렸는지도 한눈에 안 들어왔다. 글자는 늘리지 않고 모양만 둘 더했다.
- 방금 담긴 줄만 0.34초 오른쪽으로 한 번 튕긴다.
- 가장 많이 담긴 조건의 이름에 밑줄이 생긴다. 여럿이 같으면 여럿에 생긴다.
  **나무라거나 권하는 말은 하지 않는다.** 어느 쪽이 옳다고 적지 않는다.
- 둘 다 `prefers-reduced-motion`에서 꺼진다.

## 6. 연습 모드

| 막히는 것 | 처리 |
|---|---|
| 카메라 권한 거부·기기 없음 | 그리기 칸으로 바꾼다. 담으면 저절로 지워진다. |
| 화면을 벗어남 | 카메라를 끊는다. 담아 둔 것과 조건은 그대로 남긴다. |

그리기 칸에서도 조건 딱지가 붙는 것은 똑같다. `진짜와 같다`고 적지 않는다.

## 7. 만드는 방법

```
각도 = null, 배경 = null          // '위'|'옆' , '흰'|'바닥'
담김 = []                         // {각도, 배경, mini: 24x24 그림}

담기():
  if (각도 === null || 배경 === null) return
  if (담김.length >= 20) 버튼을 흐리게 두고 한 줄로 알린다
  지금 화면을 24x24로 줄여 담고 지금 조건을 함께 적는다
  막대 넷과 장수만 다시 그린다
한장빼기(): 담김.pop(); 막대만 다시 그린다
막대(a, b): 담김에서 각도===a && 배경===b 인 것의 수
```

- 막대 넷은 인라인 SVG `<rect>`의 `width`만 바꾼다.
- 카메라는 `facingMode:'environment'`. `getTracks().forEach(t => t.stop())`로 끊는다.
  `visibilitychange`·`pagehide`에서 끊는다.
- 사진을 밖으로 보내지 않고 내려받기도 두지 않는다. 얼굴을 다루지 않는다.
- 포인트색 한 가지: 갈색 `#B45309`.

## 8. 난이도 점검

첫 조작 5초, 1화면, 조작 요소 7개(조건 단추 4 + 버튼 3), 값 1개, 4분, 새 조작법 0개.

조건 단추 넷은 두 갈래의 고르기 하나이므로 실제로 바꾸는 값은 하나다.
공통기준 10절 6번에 따라 까닭을 여기에 적어 둔다.

## 9. 디버깅

- [ ] 조건 둘을 다 고르기 전에는 `담기`가 흐리고 까닭이 뜬다.
- [ ] 담은 뒤 조건을 바꾸면 다음 장부터 다른 딱지가 붙는다.
- [ ] 막대 넷의 합이 담은 장수와 같다.
- [ ] `한 장 빼기`가 마지막 한 장만 뺀다.
- [ ] 20장에서 `담기`가 흐려지고 까닭이 뜬다.
- [ ] 카메라를 거부하면 그리기 칸이 뜨고 끝까지 된다.
- [ ] 그리기 칸에서 담으면 그림이 저절로 지워진다.
- [ ] 다른 앱으로 갔다 와도 담아 둔 것이 남아 있다.
- [ ] 카메라 표시등이 화면을 벗어나면 꺼진다.
