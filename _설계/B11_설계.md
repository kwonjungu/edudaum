# B11 체험 설계 — 흔들면 세는 주머니

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 단, 앞 판정이 막았던 자리(세 가지 걸음 실측·두 수의 차이)는 그대로 막아 둔다.

- **웹이 아니면 못 하는가.** 학생은 마이크로비트를 받기 전에 "흔들림을 센다"가 무슨 뜻인지
  모른 채 블록을 놓는다. 태블릿 가속도계는 그 감각을 **몸으로 먼저** 준다. 종이로는 안 된다.
- **값을 바꾸면 결과가 바뀌는가.** 흔들면 숫자가 오르고(활동2 기본 만보기), 목표에 닿으면
  격자가 갈린다(활동2 기능 카드 `목표 알림`). 판마다 목표가 바뀐다.

**여전히 만들지 않는 것.** 거치대 달고 세 가지 걸음으로 재기(활동3), 직접 센 걸음과 기기 수의 **차이**와 그 까닭(활동4), 무선 전송·수신과 무선 게임(활동5~8).
이 셋은 학급마다 다르게 나와야 하므로 화면이 먼저 보여 주지 않는다. 화면은 숫자 하나만 센다.

---

## 1. 과정안 어디에 붙는가

- 블록 B11, 21~24차시. **21차시 활동2 「기본 만보기 만들고 기능 하나 더하기」 앞**(활동1 「쓸 사람 정하고 설계 카드 쓰기」 뒤)에 3~5분.
- 설계 카드의 입력(흔들림)·처리(1 더하기)·출력(수·아이콘)을 기기에 옮기기 **전에** 손으로 한 번 겪는다.
  활동2의 블록 놓기·전송·배터리 팩 시험을 대신하지 않는다.
- 격자가 목표 아래 한 점 → 목표에서 전체로 갈리는 모양은 활동2 기능 카드 `목표 알림`과 같다.
- 관찰 물음 `걷지 않고 흔들어도 올라가나요`는 도입의 `화면의 수는 흔들림을 센 값`과
  활동4의 까닭 고르기(`너무 잘 셈`)를 미리 만나 두는 자리다.
- 23~24차시의 무선 전송·수신(활동5·6)과 무선 게임(활동7·8, 확장)은 **마이크로비트 두 대로 한다.** 이 화면은 무선을 흉내 내지 않는다.

## 2. 한 문장

태블릿을 **흔들면** 수가 1씩 오르고, 이번 판 **목표**에 닿는 순간 격자가 갈린다. 넘기면 그 판은 끝난다.

---

## 3. 화면 (1화면, 스크롤 없이) — 2026. 9. 17. 게임으로 다시 짬

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 | 제목·부제, 안전 한 줄 | 읽지 않아도 된다 |
| 이번 목표 | 목표 수(판마다 8~25), **큰 수**(주머니 값), 5×5 점 격자, 상태 한 줄 | 태블릿을 흔든다 |
| 손 | `흔들기` `멈추기` `다시 하기` `다음 판`, 관찰 물음, 기기 되짚기 | 목표에 닿았다 싶으면 멈춘다 |

- 격자: 목표 아래는 가운데 한 점, 목표에 닿으면 25칸 전체. 목표에 딱 닿는 순간 한 번 번쩍인다.

## 4. 조작과 값

- 판이 뽑는 것: **목표** 8~25. 직전 판과 같으면 다시 뽑는다.
- 주된 조작: **흔들기**(센서). 센서가 없으면 `흔들기` 버튼.
- `멈추기`: 이 판을 끝낸다. 목표와 같으면 `목표에 딱 멈췄어요`, 모자라면 `N번 모자라요`.
- 목표를 넘기는 순간 판이 끝나고 `N번 더 흔들렸어요`만 적는다. 틀렸다고 쓰지 않는다.
- `다시 하기`: 같은 목표로 0부터. `다음 판`: 목표를 새로 뽑는다.
- 값의 상한 99.

**흔들림 판정**
- `devicemotion`의 `accelerationIncludingGravity`에서 직전 표본과의 차이 크기를 구한다.
  `d = |x-px| + |y-py| + |z-pz|`
- `d > 16`이면 한 번으로 센다. 센 뒤 **250ms 동안은 다시 세지 않는다**(되풀이 방지).
- 표본은 오는 대로 받되 처리는 50ms마다 한 번만 한다.
- 이 기준(16, m/s² 차이의 합)은 화면 안에서만 쓰는 값이다. 과정안 활동4의 `가속도 세기 기준값`(예: 1500 → 2000, mg 단위)과
  단위가 달라 화면에 기준값으로 띄우지 않는다. 기준값 바꾸기는 기기에서 한다.

**열어 두는 딴짓.** 걷지 않고 손목만 털어도 값이 오른다. **막지 않는다.**

## 7. 만드는 방법

외부 라이브러리 없음. CDN 없음. 저장 없음. 포인트색 주황 `#FF7A00`.

```
새판(): 목표 = 8~25(직전과 다르게); 값 = 0; 끝남 = 거짓
bump(): if 끝남 return; 값 += 1
        if 값 > 목표: 끝남 = 참(넘김)   else if 값 == 목표: 격자 번쩍
멈추기(): if 끝남 or 값 == 0 return; 끝남 = 참
격자(): 값 < 목표 ? 가운데 한 칸 : 25칸 전체
```

## 9. 디버깅

공통기준 8-2에 더해 이 차시만의 항목.

- [ ] 한 번 크게 흔들었을 때 값이 **1만** 오른다(250ms 잠금이 듣는다).
- [ ] 세게 30번 흔들어도 숫자가 건너뛰지 않는다.
- [ ] 값이 목표에 닿는 순간 격자가 한 점 → 전체로 바뀐다.
- [ ] 목표를 넘기면 그 판이 끝나고 `흔들기`가 잠긴다.
- [ ] `다시 하기`가 값만 0으로 만들고 목표는 남긴다. `다음 판`은 목표를 새로 뽑는다.
- [ ] 다른 앱으로 갔다 오면 값이 혼자 오르지 않는다.
- [ ] 99에서 멈춘다.
- [ ] 센서가 없는 노트북에서 `흔들기` 버튼만으로 끝까지 된다.
