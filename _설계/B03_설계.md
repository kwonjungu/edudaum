# B03 체험 설계 — 어디서 달라졌나

2026. 9. 17. 판정을 뒤집었다. **다만 학생 기기로 쓰지 않는다.** 까닭은 아래에 적는다.

## 0. 만들까 말까

**만든다. 단 교사 준비용이다.**

과정안 B03에는 `이 블록은 기기와 인터넷을 사용하지 않는다`가 유의점으로 못박혀 있다.
이 한 줄은 지킨다. 그러므로 이 쪽은 **수업 중에 학생이 여는 쪽이 아니다.**
교사가 수업 전날 활동3의 `틀린 명령 여섯 개`를 짜 보는 자리다.

- **웹이 아니면 못 하는가.** 활동3은 `목표는 같은데 결과가 다른 명령 여섯 개`를 요구한다.
  여섯 개가 서로 다른 곳에서 어긋나야 `몇 번째 명령부터 달라졌는지`를 찾는 활동이 선다.
  손으로 짚으면 여섯 개를 다 확인하는 데 오래 걸리고, 격자 밖으로 나가는 명령을 놓치기 쉽다.
  화면은 **한 줄씩 되감아** 볼 수 있다. 짝은 되감을 수 없다.
- **값을 바꾸면 결과가 바뀌는가.** 몇 번째 줄까지 실행할지 바꾸면 말이 선 칸이 바뀐다.

**만들지 않는 것.** 놀이판 위의 몸 움직임, 짝이 로봇이 되는 일, 미션 만들기.
화면에 `수업 중에는 종이와 몸으로 해요`를 상시로 둔다.

## 1. 과정안 어디에 붙는가

- 블록 B03, 5~6차시. **수업 중이 아니다.** 교사가 활동3 자료를 준비할 때 쓴다.
- 허브 카드와 쪽 위에 `교사 준비용`이라고 적어 학생용과 갈라 둔다.

## 2. 한 문장

명령 줄을 **몇 번째까지** 실행할지 옮기면 말이 선 칸과 보는 방향이 그때그때 보인다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 하는 것 |
|---|---|---|
| 위 | 4×4 놀이판, 말, 물건, 도착 칸 | 본다 |
| 가운데 | 명령 여섯 줄(번호·명령). 실행한 줄에 표시 | 어디서 어긋나는지 본다 |
| 아래 | `한 줄 더`, `한 줄 뒤로`, `처음으로` | 한 줄씩 옮긴다 |

- 격자 밖으로 나가는 줄에 닿으면 말이 그 자리에 서고 멈춘 까닭이 한 줄 뜬다
  (과정안 유의점 그대로).

## 4. 조작과 값

- 조절하는 값: **실행한 줄 수** 하나. 0~6.
- 보조 조작: `한 줄 뒤로`, `처음으로`.
- 명령 넷은 과정안 활동2 그대로: `앞으로` `오른쪽` `왼쪽` `집기`.
  **돌기를 해도 서 있는 칸은 그대로다**(활동2 둘째 줄). 방향 표시로만 보인다.
- 명령 여섯 줄은 교사가 칸을 눌러 골라 넣는다. 미리 채우지 않는다.

**교사 검토(2026. 9. 17.)에서 고친 것.** 처음에는 줄마다 명령 넉 장을 늘어놓아 단추가
스물넷이었다. 정적 감사는 자바스크립트로 만든 단추를 세지 못해 통과했지만, 교실 화면에서는
명령 칸만 세로 264px을 먹어 놀이판과 함께 한 화면에 들어오지 않는다.
**줄마다 단추 하나**로 줄이고 누를 때마다 `비어 있음 → 앞으로 → 오른쪽 → 왼쪽 → 집기`를
돌게 했다. B02의 칸 돌리기와 같은 조작이라 새로 배울 것이 없다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 | 글자 수 |
|---|---|---|
| 제목 | 어디서 달라졌나 | 8 |
| 부제 | 한 줄씩 되감아 봐요 | 10 |
| 꼬리표 | 교사 준비용 | 6 |
| 칸 이름 | 놀이판 / 명령 | 3 / 2 |
| 명령 | 앞으로 / 오른쪽 / 왼쪽 / 집기 | 3 / 3 / 2 / 2 |
| 빈 줄 | 비어 있음 | 5 |
| 버튼 | 한 줄 더 / 한 줄 뒤로 / 처음으로 | 5 / 6 / 4 |
| 멈춘 까닭 | 판을 벗어나 멈췄어요 | 11 |
| 되짚기(상시) | 수업 중에는 종이와 몸으로 해요 | 15 |

**쓰지 않는 말**: 정답, 성공, 실패, 점수.

## 6. 연습 모드

**해당 없음.** 외부 호출·센서·카메라를 쓰지 않는다.

## 7. 만드는 방법

```
말 = {x:0, y:3, dir:0}      // dir 0=위 1=오른쪽 2=아래 3=왼쪽
줄 = ['','','','','','']    // 교사가 고른다
n  = 0                      // 실행한 줄 수

다시그리기():
  말을 시작 자리로 되돌리고 n줄까지 차례로 적용한다   // 되감기는 늘 처음부터 다시 센다
  '앞으로': dir 쪽으로 한 칸. 판 밖이면 그 자리에 서고 멈춤 표시를 켠다
  '오른쪽': dir = (dir+1)%4     // 칸은 그대로
  '왼쪽'  : dir = (dir+3)%4
  '집기'  : 말과 물건이 같은 칸이면 물건을 든다
```

- 놀이판·말·물건·방향은 인라인 SVG. 포인트색 한 가지: 남보라 `#4F46E5`.

## 8. 난이도 점검

첫 조작 5초, 1화면, 값 1개, 3분, 새로 배우는 조작법 0개.

## 9. 디버깅

- [ ] 돌기 명령에서 말이 있는 칸이 바뀌지 않는다.
- [ ] 판을 벗어나는 줄에서 말이 그 자리에 서고 까닭이 뜬다.
- [ ] `한 줄 뒤로`가 언제나 처음부터 다시 세어 같은 자리를 만든다.
- [ ] 여섯 줄을 다 비운 채로도 화면이 깨지지 않는다.
- [ ] 쪽 위와 허브 카드에 `교사 준비용`이 보인다.
