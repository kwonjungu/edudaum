## 4. 장 순서 틀 (블록 한 벌)
과정안의 차시·단계를 따라 아래 장 종류를 놓는다.
1. **표지**: 블록 이름, `n학년 a~b차시`, 담당 단원 + 새싹쌤, 풀 배경
2. **미션 카드**: 해결단 n호 미션 + 학습 문제(과정안 그대로)
3. **오늘의 길**: 차시별 활동 지도(도입·활동1·2…·정리, 분)
4. **도입 장**(1~3장): 동기 유발 상황 그림/시연 + 말풍선 발문
5. **활동 묶음**(활동마다 3~5장)
   - 활동 여는 장: 꼬리표 + 활동 이름 + 할 일 한 줄 + 타이머
   - 예측 장(활동에 예측이 있으면): 예측 카드
   - 단서 장: 활동지 캡처(그 칸 확대 컷) + 가리키기 + 말풍선 + 단서 메모
   - 체험 장(그 차시에 체험·연계 활동이 있으면): 체험 캡처 처음 → 결과 순서 + 체험 단추
   - 영상 장(링크가 있으면): 영상 단추
6. **차시 사이**(2차시 이상): "쉬는 시간" 한 장 + 다음 차시 길 다시 보기
7. **정리 장**: 과정안 정리 활동 + 블록 돌아보기(활동지 캡처) + 스스로 점검
8. **해결 보고**: 해결 도장 + 다음 미션 예고(다음 블록 이름)

## 5. HTML 모션 (PDF에서는 모두 펼친 상태)
- 넘기기: → / 스페이스 / 클릭, ← 뒤로. 화면 크기에 맞춰 1280×720 비율 그대로 늘림. `F` 전체 화면
- **단계 보이기**: 한 장 안에서 말풍선·가리키기·정답 아닌 "확인" 내용이 클릭마다 하나씩 나온다(`data-step`)
- **말풍선 팝**: 캐릭터가 살짝 튀어 오르며 풍선이 펼쳐짐(0.35초), 움직임 줄이기 설정이면 끔
- **가리키기 맥박**: 동그라미가 두 번 숨 쉬듯 커졌다 작아짐
- **예측 카드**: 교사가 보기를 누르면 고른 보기에 표시(점수·정답 표시 없음), 다음 단계에서 실제 결과 캡처가 나타남
- **체험 미리보기**: 체험 장에서 캡처가 처음 → 예측 뒤 → 결과로 교차 전환(1.2초 간격, 클릭으로 멈춤)
- **해결 도장**: 마지막 장에서 도장이 쿵 찍힘
- 바깥 요청 없음: 글꼴·그림·썸네일 모두 로컬. 유튜브·체험은 단추를 눌렀을 때만 새 창

## 9. 집중 장치: 게임 형식 (2026-10-30 추가)
초등 학생이 화면에 집중하도록 활동 묶음마다 **게임 장을 하나 이상** 둔다. 체험 활동 원칙을 그대로 따른다: 점수·등수·맞힌 판 수 없음, 판정·칭찬 말(맞았어요·틀렸어요·잘했어요·정답·오답·대단해요) 없음, "먼저 예측 → 확인" 흐름.
| 게임 장 | 하는 법 | HTML 모션 |
|---|---|---|
| 먼저 예측하기 | 보기 2~4개 가운데 고르고 손 들기 → 다음 단계에서 실제 결과 사진 | 고른 보기에 도장, 결과 사진이 뒤집혀 나옴 |
| 숨은 그림 찾기 | 상황 사진에서 SW·센서·규칙 같은 것을 찾아 짚기 | 누르면 동그라미가 하나씩 나타남 |
| 카드 뒤집기 | 카드 앞면(물건·상황) → 뒤집으면 뒷면(하는 일·까닭) | 3D 뒤집기 |
| 순서 맞추기 | 섞인 그림 카드 3~5장을 순서대로 | 누르면 제자리로 미끄러짐 |
| 둘 중 하나 | 사진 두 장 "어느 쪽일까?" (예: 기계/인공지능) | 고른 쪽이 커지고 말풍선이 까닭을 묻음 |
| 10초 관찰 | 사진을 10초 보여 주고 가린 뒤 무엇이 있었는지 말하기 | 카운트다운 후 가림막 |
| 미션 도장판 | 활동을 마칠 때마다 블록 도장판에 도장 | 마지막 장에서 모인 도장이 반짝 |
게임 장은 과정안 활동의 생각을 그대로 가져온다(새 내용을 만들지 않는다). 교사가 진행하므로 학생 기기가 없어도 된다.
