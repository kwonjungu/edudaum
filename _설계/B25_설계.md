# B25 체험 설계 — 같은 시험지로 견주기

- 경로: `B25/index.html` (단일 파일, 정적 호스팅, 서버·API 키 없음)
- 포인트 컬러: 코랄 `#FF5A5F` / `#FFE3E4`
- 카메라·마이크: **쓰지 않는다.** 그림은 전부 인라인 SVG로 그렸다.
- 공통기준과 다르게 한 것: 아래 9절에 적었다.

## 0. 만들까 말까

**만든다.**

- 조건 하나를 바꾸어 다시 학습시키고 같은 시험 자료로 견주는 일은 교실에서 한 회차에
  20분이 든다. 두 회차를 넘겨 세 갈래를 다 해 볼 수는 없다. 웹은 세 갈래의 결과를 30초에
  보여 주므로 학생이 **어느 조건을 바꿀지 고르기 전에** 예상해 볼 수 있다.
- 값을 바꾸면 결과가 바뀐다. 배경·각도·장수 가운데 하나를 바꾸면 맞힌 수와 틀린 자료가
  즉시 달라진다. 미리 채워 둔 수치는 없고, 학생이 `시험하기`를 눌러야 숫자가 생긴다.

## 1. 과정안 어디에 붙는가

- 블록 B25, 23차시 **활동5 「못 알아본 사례 보고 조건 고르기」의 앞 3~5분**.
- 실물 활동의 **앞**이다. 1회차 기록표를 이미 손에 든 상태에서, 바꿀 조건 하나를 고르기
  직전에 쓴다. 이 웹이 촬영·학습·시험을 대신하지 않는다. 실제 자료는 학생이 찍은 것이고
  실제 학습은 엔트리에서 한다.
- 교실에서 3~5분. 길게 붙잡지 않는다.

## 2. 한 문장

배경·각도·장수 가운데 **하나만** 바꾸면, 같은 시험 자료 아홉 장에서 맞는 장이 어떻게
달라지는지 본다.

## 3. 화면 — 게임판(2026. 9. 17. 고침)

**목표를 `아홉 장을 다 맞게 만들어라`로 세웠다.** 한 화면, 세로로 이어져 있고 단계 넘김이
없다. 판마다 학습 묶음의 시작 상태(배경·각도·장수 세 값)와 시험 자료 9장의 짜임이
**그 자리에서 새로 뽑힌다**(고정 표가 아니라 미리 지어 둔 짜임 여덟 가지 가운데 하나).

| 자리 | 보이는 것 | 학생이 하는 것 | 다음 조건 |
|---|---|---|---|
| 위 | 새로 뽑힌 학습 묶음 세 줄과 `시험하기` | `시험하기`를 누른다 | 1회차 결과(몇 장 맞았는지)가 생긴다 |
| 위 | 세 줄의 `바꾸기`가 켜진다 | 한 줄만 바꾼다 | 나머지 두 줄이 잠기고 `그대로`로 표시된다 |
| 위 | 0~9 짚기 칸이 나타난다 | **다시 시험하기 전에 몇 장이 맞을지 짚는다** | 짚어야 `다시 시험`이 풀린다 |
| 아래 | 시험 자료 9칸, 회차별 ○·✕ 배지, 맞힌 수 표 | `다시 시험`을 누른다 | 짚은 것과 견주어 결과 문구가 뜬다 |
| 아래 | `다음 판` / `다시 하기` | 다음 판을 새로 뽑거나 이번 판을 처음부터 | 새 시작 상태 또는 같은 판 되돌리기 |

첫 화면에서 스크롤 없이 `시험하기`가 보인다(세로 800px 기준). 짚기 칸이 펼쳐진
가장 붐비는 상태(1회차 결과 + 조건 바꿈 + 짚기 칸 + 2회차 결과)까지도 800px 안에 들어오게
칸·글자를 줄였다.

## 4. 조작과 값

**한 번에 바꾸는 값은 하나다.** 1회차를 마쳐야 `바꾸기`가 켜지고, 하나를 바꾸면 나머지
둘은 즉시 잠긴다(그대로다).

| 조건 | 바뀌는 값 |
|---|---|
| 배경 | 판의 시작 배경 → 시작 배경·다른 배경 |
| 각도 | 판의 시작 각도 → 시작 각도·다른 각도 |
| 장수 | 판마다 정해진 부족한 이름의 장수 → 세 이름 모두 넉넉함 |

**시험 자료 9장(그 판 안에서는 고정).** 두 회차 내내 바뀌지 않는다. 이것이 두 회차를
견줄 수 있게 하는 조건이므로 학생이 손댈 수 없게 두었다.

**짚기.** 조건을 바꾼 뒤, `다시 시험`을 누르기 **전에** 0~9 가운데 몇 장이 맞을지
한 번 짚는다. 짚어야 `다시 시험`이 풀린다. 무르지 못한다.

**판정 규칙(하드코딩 아님, 미리 지어 둔 짜임 여덟 가지 가운데 하나가 그 자리에서 뽑힌다).**
한 장이 맞으려면 세 가지가 모두 서야 한다.

```
맞음 = (학습 배경 목록에 그 장의 배경이 있다)
     그리고 (학습 각도 목록에 그 장의 각도가 있다)
     그리고 (그 이름의 학습 장수가 여덟 장 이상이다)
```

결과를 미리 적어 두지 않았다. 판마다 고른 묶음 구성으로 아홉 장을 그 자리에서 하나씩
따져 숫자가 나온다. **여덟 짜임 가운데 여섯은 한 가지만 바꾸면 아홉 장이 다 맞는 판이고,
둘은 셋 다 바꿔 봐도 여덟 장까지만 맞는 판이다(넷에 하나꼴).** 어느 짜임이 뽑혔는지는
화면에 적지 않는다. 시험해 보며 드러난다.

**빗나갔을 때.** `짚은 대로였어요` / `N장 더 맞았어요` / `N장 덜 맞았어요`. 9장이면
`아홉 장을 다 맞혔어요`라고만 적는다(과정안 말이라 예외로 쓴다).

**되풀이.** `다음 판`은 시작 상태를 새로 뽑는다(직전 판과 같은 시작 상태면 다시 뽑는다).
`다시 하기`는 같은 판을 처음(1회차 전)으로 되돌린다.

## 7. 만드는 방법

- 외부 라이브러리 **없음**. CDN 주소 **없음**. 바닐라 JS, 인라인 CSS·SVG.
- 손동작 세 가지와 ○·✕ 표식은 `<symbol>` 다섯 개로 그리고 `<use>`로 꺼내 쓴다.
  이모지를 쓰지 않는다.
- 배경은 타일 바탕색(흰색 / 베이지)과 글자 라벨로 함께 알린다. 각도 `옆`은 손 그림을
  -24도 돌려 함께 알린다. 색으로만 구별하지 않는다.
- 상태는 객체 하나(`st`)에 모은다. `{bg, ang, cnt, changed, round, marks}`.
- 그려 주는 함수를 넷으로 쪼개(`paintCond` `paintMarks` `paintScore` `paintHint`)
  화면을 통째로 다시 그리지 않는다. 시험 자료 9칸은 처음 한 번만 짓고 배지만 갈아 끼운다.
- 두 번 눌림 막기: `run()`은 맨 앞에서 `run` 버튼의 `disabled`를 보고 되돌아간다.
  `change()`는 `round !== 1`이거나 이미 바꾼 것이 있으면 되돌아간다.

```
fresh()  → bg:[흰], ang:[위], cnt:[10,10,4], changed:null, round:0
run()    → round가 0이면 marks[0], 1이면 marks[1]에 아홉 장 판정을 담고 round+1
change(k)→ round가 1이고 아직 바꾼 것이 없을 때만 k 하나를 바꾼다
reset()  → fresh()로 되돌리고 배지·표를 모두 지운다
```
