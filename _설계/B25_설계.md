## 0. 만들까 말까

**만든다.**

- 샘플 수를 3개에서 8개로 늘려 다시 학습시키고 같은 시험 방법으로 견주는 일은 교실에서 한 회차에
  20분이 든다. 예상을 걸고, 빗나간 까닭을 빠르기·착용 손과 이어 보는 일을 여러 판 되풀이할 수는 없다.

- 값을 바꾸면 결과가 바뀐다. 샘플 수·빠르기·착용 손 가운데 하나를 바꾸면 알아본 수와
  빗나간 시도가 즉시 달라진다. 미리 채워 둔 수치는 없고, 판은 그 자리에서 뽑힌다.

- 교실에서 3~5분.

## 3. 화면 — 게임판

**목표는 `아홉 번을 다 알아보게 만들어라`.** 한 화면, 세로로 이어져 있고 단계 넘김이 없다.
학습 데이터의 시작은 늘 과정안 그대로 **샘플 3개·보통 빠르기·오른손**이다. 시험 데이터 9번
(동작마다 셋)의 짜임은 판마다 **그 자리에서 새로 뽑힌다.**

| 자리 | 보이는 것 | 학생이 하는 것 | 다음 조건 |
|---|---|---|---|
| 위 | 학습 데이터 세 줄과 `시험하기` | `시험하기`를 누른다 | 1회차 결과가 생긴다 |
| 위 | 세 줄의 `바꾸기`가 켜진다 | 한 줄만 바꾼다 | 나머지 두 줄이 잠기고 `그대로`로 표시된다 |
| 위 | 0~9 짚기 칸 | **다시 시험하기 전에 몇 번 알아볼지 짚는다** | 짚어야 `다시 시험`이 풀린다 |
| 아래 | 시험 데이터 9칸(동작 그림·착용 손·빠르기), 회차별 ○·✕, 맞힌 수 표 | `다시 시험`을 누른다 | 짚은 것과 견주어 결과 문구가 뜬다 |
| 아래 | `다음 판` / `다시 하기` | 새 판 또는 같은 판 처음부터 | |

## 4. 조작과 값

**한 번에 바꾸는 값은 하나다.** 1회차를 마쳐야 `바꾸기`가 켜지고, 하나를 바꾸면 나머지 둘은 잠긴다.

| 조건 | 바뀌는 값 |
|---|---|
| 샘플 수 | 3개 → 8개 (과정안 활동6) |
| 빠르기 | 보통 → 보통·빠르게 (활동6 선택) |
| 착용 손 | 오른손 → 오른손·왼손 (활동6 선택) |

**시험 데이터 9번(그 판 안에서는 고정).** 두 회차 내내 바뀌지 않는다. 과정안의 봉인한 시험 방법과
같은 자리다. 학생이 손댈 수 없다.

**판 뽑기.** 동작마다 세 번, 모두 오른손·보통으로 시작한다. 문지르기 두 동작의 시도는 저마다
35% 확률로 `또렷한 시도`가 된다(화면에 적지 않음). 셋에 한 판꼴로 아홉 시도 가운데 하나가
`빠르게` 또는 `왼손`으로 바뀐다. 1회차에 두 번 넘게 빗나가지 않는 판, 직전 판과 같은 판은 다시 뽑는다.

**판정 규칙.**

```
알아봄 = (학습 데이터의 빠르기에 그 시도의 빠르기가 있다)
       그리고 (학습 데이터의 착용 손에 그 시도의 손이 있다)
       그리고 (샘플 8개 이거나, 물 털기이거나, 또렷한 시도다)
```

샘플 3개로는 손바닥·손등 문지르기가 서로 헷갈린다(과정안 활동5의 헷갈림 판). 빠르게·왼손 시도가
섞인 판은 **한 가지만 바꿔서는 아홉 번을 다 알아볼 수 없다**(안 되는 판이 셋에 하나꼴).

**결과 문구.** `짚은 대로였어요` / `N번 더 알아봤어요` / `N번 덜 알아봤어요`. 짚은 대로 9번이면
`짚은 대로 아홉 번을 다 알아봤어요`.

**되풀이.** `다음 판`은 시험 데이터를 새로 뽑는다. `다시 하기`는 같은 판을 1회차 전으로 되돌린다.

## 7. 만드는 방법

- 외부 라이브러리 **없음**. 바닐라 JS, 인라인 CSS·SVG.
- 세 동작 그림(`h-palm` `h-back` `h-shake`)과 ○·✕는 `<symbol>`로 그리고 `<use>`로 꺼내 쓴다. 이모지 없음.
- 왼손 시도는 타일 바탕색(베이지)과 글자 `왼손`으로, 빠르게 시도는 그림을 -24도 기울이고 글자 `빠르게`로 함께 알린다.
- 상태: `st = {tmpl, smp, spd, hand, changed, round, marks, guess}`.

```
makeBoard() → 동작 0·1·2 각 3번 {hand:'r', spd:'n', clear: 문지르기면 35%}
             1/3 확률로 한 시도를 spd:'f' 또는 hand:'l'로
pickBoard() → 직전 판과 같거나 1회차 알아봄이 8번 이상이면 다시 뽑기
fresh(t)    → smp:3, spd:['n'], hand:['r'], round:0
change(k)   → 샘플 수: smp=8 / 빠르기: spd=['n','f'] / 착용 손: hand=['r','l']
```
