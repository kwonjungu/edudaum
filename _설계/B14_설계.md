# B14 체험 활동 설계 — 드러난 개인정보 찾기 활동

2026. 10. 11. 교사가 고친 지도안(31~32차시)에 맞춰 다시 짰다. 옛 설계(점검표 다섯 항목으로 걸리는 곳 찾기)는
고친 지도안에 점검표가 없어 버렸다. 옛 글은 git 기록에 남아 있다.
구조는 `판이 나온다 → 짚는다 → 확인한다`이고, 학생에게 보이는 이름은 '체험 활동'이다.

## 0. 지도안의 어느 활동 앞/뒤에 붙나

**32차시 활동3-2. 개인정보를 지킨 작품 소개 페이지 만들기**의 넷째 줄 **앞**에 3~4분.

> - 활동2에서 정한 약속으로 짝 모둠과 서로 확인하고, 이름·얼굴·학교 이름·사는 곳이 드러난 곳 고치기

- 바로 앞 줄 `예시 작품 소개를 보며 해결한 문제·해결 방법·작동 순서·다음에 고칠 점이 어디에 있는지 찾기`와
  같은 칸 이름을 쓴 예시 작품 소개에서, 개인정보가 **드러난 곳 한 곳**을 짚어 본다. 짝 모둠 페이지를 보기 전에
  어디를 보아야 하는지 눈을 익히는 조각이다.
- 사진 칸의 걸리는 값은 활동3-1 `얼굴·이름표·교실 게시물·창밖이 나오지 않게 작품(기기와 틀)만 찍기`에서 가져온다.
- **만들지 않는 것.** 활동1 암호 찾기(마이크로비트 실물), 인터랜드, Canva로 실제 페이지 만들기, 짝 모둠 확인,
  활동4 CCL 고르기. 화면은 학생 사진·작품을 열지 않는다.

**다섯 칸.** 목표(드러난 곳 한 곳 짚기) · 실패(다른 곳을 짚을 수 있음) · 예상(짚기 전 확인 잠금) ·
제약(한 곳만, 확인 뒤엔 못 바꿈) · 되풀이(다음 예시가 새로 나옴) — 다섯 다 채움.

## 1. 지도안 어디에 붙는가

- 블록 B14, 5학년 32차시 전개 활동3-2 안, `짝 모둠과 서로 확인하고 … 고치기` 직전 3~4분.
- 실제 확인과 고치기는 짝 모둠의 Canva 페이지에서 한다. 화면은 예시만 보여 준다.

## 2. 한 문장

예시 작품 소개의 네 칸 가운데 개인정보가 **드러난 곳**을 짚으면(없을 수도 있다), 확인할 때 실제로 드러난 곳과 몇 칸 떨어졌는지가 보인다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 예시 작품 소개 | 네 칸(인라인 SVG): 칸 이름 + 그 칸에 적힌 것 | 훑어본다 |
| 어디에 드러났나요 | 짚기 단추 다섯(네 칸 + `드러난 곳 없음`), `확인하기` `다시 하기` `다음 예시`, 상태 한 줄 | 하나를 짚고 확인한다 |

| 번호 | 칸 이름 | 바른 값(하나 뽑음) | 드러난 값(하나 뽑음) | 지도안 말 |
|---|---|---|---|---|
| 0 | 만든 사람 | 반짝 모둠 / 별빛 모둠 / 바람 모둠 | 김하늘, 이바다 / 박나래온, 최솔 (지어낸 이름) | 실제 이름 대신 모둠 이름 |
| 1 | 작품 사진 | 기기와 틀만 찍힘 / 수신기와 틀만 찍힘 | 얼굴이 함께 찍힘 / 이름표가 보임 / 창밖 건물이 보임 / 교실 게시물이 보임 | 활동3-1 |
| 2 | 해결한 문제 | 복도에서 뛰는 친구 알리기 / 쉬는 시간 끝 알리기 | ㅇㅇ초 5학년 복도 문제 / ㅇㅇ초 쉬는 시간 문제 | 학교 이름 |
| 3 | 다음에 고칠 점 | 소리를 더 크게 하기 / 틀을 더 튼튼하게 하기 | ㅇㅇ동 우리 집 앞에서 다시 시험 / ㅇㅇ아파트 놀이터에서 다시 시험 | 사는 곳 |

실제 학교·동네 이름은 쓰지 않는다(`ㅇㅇ`). 사람 이름은 지어낸 이름을 쓴다 — `ㅇㅇ`로 쓰면 학생이 '이미 가려졌다'로 읽어 드러난 것으로 보지 못한다(교사 검토).

## 4. 조작과 값

- **판.** 드러난 칸을 0~3 가운데 뽑거나, 넷에 하나꼴로 `드러난 곳 없음` 판을 낸다. 직전 판과 같은 칸이면 다시 뽑는다.
  나머지 칸은 바른 값 가운데 하나.
- **예상.** 짚기 전에는 `확인하기`가 잠긴다. 확인 전에는 다른 단추를 눌러 바꿀 수 있다.
- **제약.** 한 곳만 짚는다. 확인한 뒤에는 짚기 단추가 잠긴다.
- **확인.** 드러난 칸에 강조 테두리가 뜬다. 문구는
  - 짚은 곳 = 드러난 곳: `짚은 칸에 ○○이 드러나 있었어요`
  - 다른 칸: `N칸 아래(위)에 ○○이 드러나 있었어요`
  - 드러난 곳 없음 판인데 칸을 짚음: `이 예시는 드러난 곳이 없었어요`
  - 드러난 곳이 있는데 `없음`을 짚음: `○○ 칸에 ○○이 드러나 있었어요`
  - 둘 다 없음: `짚은 대로 드러난 곳이 없었어요`
  (○○ = 실제 이름 / 얼굴 / 이름표 / 창밖 / 교실 게시물 / 학교 이름 / 사는 곳)
- **되풀이.** `다음 예시`는 새 판. `다시 하기`는 확인 전이면 고른 것만 지우고, 확인 뒤에는 다음 예시와 같다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 |
|---|---|
| 제목 | 드러난 개인정보 찾기 활동 |
| 부제 | 예시 작품 소개에서 개인정보가 드러난 곳을 짚어요 |
| 소제목 | 예시 작품 소개 / 어디에 드러났나요 |
| 짚기 단추 | 만든 사람 / 작품 사진 / 해결한 문제 / 다음에 고칠 점 / 드러난 곳 없음 |
| 상태(짚기 전) | 한 곳을 짚어요. 없을 수도 있어요 / 확인하면 드러나요 |
| 단추 | 확인하기 / 다시 하기 / 다음 예시 |
| 되짚기(상시) | 짝 모둠 작품은 활동2 약속으로 확인해요 |

**쓰지 않는 말**: 게임, 판, 점수, 등수, 맞았어요, 틀렸어요, 잘했어요, 퀴즈.

## 6. 연습 모드

해당 없음. 센서·카메라·외부 호출을 쓰지 않는다.

## 7. 만드는 방법

외부 라이브러리 없음. 단일 파일. 포인트색은 공통 강조색.

```
새판():
  드러남 = (난수 < 0.25) ? 없음 : 0~3 (직전과 다르게)
  칸마다 값 = (칸 == 드러남) ? 드러난 값 가운데 하나 : 바른 값 가운데 하나
짚기(i): 확인함이면 무시; 짚음 = i   (i = 0~3 또는 4=없음)
확인(): 확인함이거나 짚음 없음이면 무시; 확인함 = 참; 드러남 칸에 테두리; 문구는 4절
```

## 9. 디버깅

- [ ] 짚기 전에는 `확인하기`가 흐리다.
- [ ] 한 판에 드러난 칸은 하나이거나 없다. 다른 칸은 바른 값이다.
- [ ] 확인 뒤 짚기 단추가 잠기고, 테두리는 짚은 곳이 아니라 실제로 드러난 곳에 뜬다.
- [ ] 빗나가면 몇 칸 떨어졌는지만 적는다.
- [ ] 화면에 실제 사람 이름·점수·판 수가 없다.
- [ ] 폭 390·세로 800에서 `확인하기`에 스크롤로 닿고 가로 스크롤이 없다.
