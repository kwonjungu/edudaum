# B14 체험 설계 — 다시 판정하기

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.
2026. 9. 17. 저녁, 게임으로 다시 짰다 — 붙는 자리를 활동3에서 **활동1**로 옮겼다(1절).
아래 0절은 그 뒤집기 당시의 까닭을 그대로 남긴다. 지금 붙는 자리와 화면은 1·3~5절을 본다.

## 0. 만들까 말까

**만든다.** 점검 대상인 실물 작품과 전시(활동1·4)는 그대로 한다.

- **웹이 아니면 못 하는가.** (뒤집을 당시 근거) 활동3 마지막 줄은
  `고친 뒤 같은 다섯 항목으로 다시 판정하기`였다. 종이에서 다시 판정하려면 표를 한 번 더
  그려야 하고, 처음 판정이 남지 않는다는 것이 그때의 까닭이었다. 게임으로 다시 짜면서
  **표를 두 번 쓰는 일 자체가 게임이 안 된다**는 것이 드러나, 활동1의 `예시에서 걸리는 곳
  찾기`로 자리를 옮기고 화면도 다시 짰다(1절).
- **값을 바꾸면 결과가 바뀌는가.** 다섯 항목 가운데 하나를 짚으면 맞았는지가 즉시 드러난다.

**여전히 만들지 않는 것.** 자기 작품 열어 보기, 실제로 고치기, 사용 안내 쓰기, 전시와 둘러보기.
화면은 예시 화면 하나만 보여 준다. 학생 작품을 열지 않는다.

  옮기고, 화면은 **어긋난 자리를 찾아 짚는** 일로 다시 짰다.

## 2. 한 문장

예시 안내기 화면 하나에서 다섯 항목 가운데 **어긋난 자리 하나**를 짚으면 드러난다.

## 4. 조작과 값 — 게임으로 다시 짬

- **목표.** 다섯 항목 가운데 예시가 어긋난 **자리 하나**를 짚는 것.
- **실패.** 다른 곳을 짚을 수 있다. 확인하면 `다른 곳이 걸렸어요`라고만 적는다 —
  몇 번 틀렸는지는 세지 않는다.
- **예상.** 확인하기 전에 다섯 줄을 스스로 훑어보고 짚어야 한다. 짚기 전에는
  `확인하기`가 잠긴다.
- **제약.** **한 곳만** 짚을 수 있고, 확인한 뒤에는 못 바꾼다(판마다 한 번).
- **되풀이.** `다음 판`이 어긋난 항목이 **다른** 예시를 새로 뽑는다(다섯 벌을 돌려 쓰며
  직전 판과 같은 항목이면 다시 뽑는다). `다시 하기`는 확인 전이면 고른 것만 지우고,
  확인한 뒤에는 다음 판과 같다(무를 수 없어서).
- 확인하면 예시 화면에서 **실제로 어긋난 줄**에 굵은 테두리 표시가 뜬다(학생이 짚은 곳이
  아니라 진짜 어긋난 곳).

**열어 두는 딴짓.** 다섯 벌을 다 겪고 나면 패턴이 보일 수 있다. 막지 않는다 — 겪어서
아는 것도 아는 것이다.

## 7. 만드는 방법

```
지금 = [null, null, null, null, null]      // 'Y' | 'N'
처음 = null                                 // 담으면 배열 다섯 개가 얼어붙는다

표시(i, v): 지금[i] = v; 그 줄과 개수 두 칸만 다시 그린다
담기(): if (지금에 null이 없고 처음 === null) 처음 = 지금을 복사한 것
다시하기(): 처음 = null; 지금 = 다섯 null; 다 비운다

개수(배열): 배열에서 'N'인 것의 수
달라진줄(i): 처음 !== null && 처음[i] !== 지금[i]
```

- **처음 배열은 복사해서 얼린다.** 같은 배열을 가리키면 지금을 고칠 때 처음도 바뀐다.
- 예·아니요는 `aria-pressed`로 고른 것을 표시하고, 색 말고 테두리로도 구별되게 한다.
- 달라진 줄은 왼쪽에 굵은 금을 긋는다. 색으로만 구별하지 않는다.
- 포인트색 한 가지: 청록 `#0D9488`.
