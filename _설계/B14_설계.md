2026. 9. 17. 판정을 뒤집었고(9절), 같은 날 저녁 게임으로 다시 짰다(예시에서 걸리는 곳 한 곳 짚기).

## 0. 만들까 말까

**만든다.** 엿듣기 실험(활동1), CCL 자료 카드 나누기(활동2), 우리 작품 고치기·설명 카드(활동3), 전시와 배지(활동4)는 그대로 한다.

- **웹이 아니면 못 하는가.** 활동3은 `점검표 다섯 항목을 우리 작품에 하나씩 적용해 예·아니요 표시하기`와
  `아니요인 항목은 어느 코드·화면·카드인지 위치까지 적기`를 시킨다. 다섯 항목을 **어느 자리에서** 보아야 하는지를
  제 작품에 적용하기 전에 여러 벌의 예시로 겪어 두면 빠르다. 교사 예시 작품은 한 벌뿐이고, 화면은 판마다 다른 예시를 낸다.
- **값을 바꾸면 결과가 바뀌는가.** 하나를 짚고 확인하면 어긋난 자리가 드러난다.

**여전히 만들지 않는 것.** 무선 엿듣기·가짜 메시지 실험(교사 기기로 실물), 자료 카드 여섯 장 나누기,
우리 작품 열어 고치기, 설명 카드·소개 쪽지 쓰기, 전시와 배지. 화면은 학생 작품을 열지 않는다.

## 1. 과정안 어디에 붙는가

- 블록 B14, 31~32차시. **32차시 활동3 「점검표로 작품 고치고 설명 카드 만들기」 앞**에 2~3분.
  첫 줄 `점검표 다섯 항목을 우리 작품에 하나씩 적용해 예·아니요 표시하기`에 들어가기 전에,
  예시 작품에서 걸리는 한 곳과 그 **위치**(코드·화면·카드)를 짚어 본다.
- 활동4의 `걸리는 항목은 번호와 위치만 적어 전해 주기`와 같은 말(번호 ①~⑤, 위치)을 쓴다.
- 실제 판정은 각자 점검 활동지에, 고치기는 우리 작품에서 한다.

## 2. 한 문장

예시 작품의 다섯 자리를 훑어 점검표 다섯 항목 가운데 **걸리는 한 곳**을 짚으면, 확인할 때 그 자리가 드러난다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 예시 작품 | 다섯 줄(인라인 SVG): 자리 이름 + 그 자리에 든 것 | 어디가 걸리는지 훑어본다 |
| 몇 번 항목에 걸리나요 | 짚기 버튼 다섯, `확인하기` `다시 하기` `다음 판`, 되짚기 한 줄 | 하나를 짚고 확인한다 |

다섯 항목은 과정안 32차시 점검표 그대로다. 줄 순서가 항목 번호와 같다.

| 번호 | 짚기 버튼 | 점검표 항목 | 예시 자리 | 바른 값(판마다 하나) | 걸리는 값(판마다 하나) |
|---|---|---|---|---|---|
| ① | ① 개인정보 | 이름·연락처·사진·목소리·위치 보내지 않음 | 코드 · 보내는 것 | 수 1 / 수 0 / GOAL | 이름 ㅇㅇㅇ / 전화번호 / 지금 위치 |
| ② | ② 그룹 번호 | 배정 그룹 번호 | 코드 · 그룹 번호 | 배정 N · 코드 N | 배정 N · 코드 M (M≠N) |
| ③ | ③ 친구 이름 | 친구 이름·기록 | 안내 화면 | 사용자1 · 12걸음 / 사용자2 · 성공 | ㅇㅇㅇ · 12걸음 / ㅇㅇ이 · 성공 |
| ④ | ④ 그림 출처 | 그림·게임 규칙 허락·출처 | 설명 카드 · 그림 | LED로 직접 그림 / 출처·BY 적음 | 출처 없음 / ND 그림 · 바꿔 씀 |

실제 사람 이름을 쓰지 않는다(`ㅇㅇㅇ`). CCL 표시는 과정안 활동2의 세 가지(BY·NC·ND) 가운데 BY·ND만 쓴다.

## 4. 조작과 값

- **목표.** 다섯 자리 가운데 걸리는 **한 곳**을 짚는 것. 판마다 걸리는 곳은 딱 하나다.
- **실패.** 다른 곳을 짚을 수 있다. 확인하면 `다른 곳이 걸렸어요`라고만 적고, 몇 번 빗나갔는지는 세지 않는다.
- **예상.** 짚기 전에는 `확인하기`가 잠긴다.
- **제약.** 한 곳만 짚는다. 확인한 뒤에는 못 바꾼다.
- **되풀이.** `다음 판`이 걸리는 항목을 새로 뽑고(직전 판과 같은 항목이면 다시 뽑음), 다섯 자리의 값도 새로 뽑는다.
  `다시 하기`는 확인 전이면 고른 것만 지우고, 확인한 뒤에는 다음 판과 같다.
- 확인하면 예시에서 **실제로 걸린 줄**에 굵은 테두리가 뜬다.

## 7. 만드는 방법

```
새판():
  걸림 = 0~4 (직전과 다르게)
  for i in 0..4:
    i == 1 이면  배정 = 1~9; 코드 = (i == 걸림) ? 배정과 다른 1~9 : 배정
    아니면       값[i] = (i == 걸림) ? 걸리는 값 가운데 하나 : 바른 값 가운데 하나
짚기(i): if 확인함 → 무시; 짚음 = i
확인(): if 확인함 or 짚음 없음 → 무시; 확인함 = 참; 걸림 줄에 테두리
```

- 포인트색 청록 `#0D9488`. 외부 라이브러리 없음.

## 9. 디버깅

- [ ] 짚기 전에는 `확인하기`가 흐리다.
- [ ] 한 판에 걸리는 줄은 하나뿐이다. 다른 네 줄은 바른 값이다.
- [ ] ② 줄은 걸린 판에서만 배정과 코드의 번호가 다르다.
- [ ] 확인 뒤 짚기 버튼이 잠기고, 테두리는 짚은 곳이 아니라 실제로 걸린 곳에 뜬다.
- [ ] `다음 판`이 직전과 다른 항목을 걸리게 한다.
- [ ] 화면 어디에도 실제 사람 이름·점수·판 수가 없다.
