# B14 체험 설계 — 다시 판정하기

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 점검 대상인 실물 작품과 전시(활동1·4)는 그대로 한다.

- **웹이 아니면 못 하는가.** 활동3 마지막 줄은 `고친 뒤 같은 다섯 항목으로 다시 판정하기`다.
  종이에서 다시 판정하려면 표를 한 번 더 그려야 하고, 그러면 **처음 판정이 어땠는지**가
  옆에 남지 않는다. 화면은 첫 판정을 얼려 두고 둘째 판정을 그 옆에 세운다.
- **값을 바꾸면 결과가 바뀌는가.** 항목의 표시를 바꾸면 `아니요` 개수가 즉시 바뀐다.

**여전히 만들지 않는 것.** 예시 작품 훑어보기, 실제로 고치기, 사용 안내 쓰기, 전시와 둘러보기.
화면은 다섯 항목의 표시만 받는다. 작품을 열지 않는다.

## 1. 과정안 어디에 붙는가

- 블록 B14, 31~32차시. **활동2와 활동3 마지막 줄, 두 자리**에 각 2분.
  - 활동2 뒤: 다섯 항목을 처음 판정한 뒤 `판정 담기`로 얼려 둔다.
  - 활동3 뒤: 고친 다음 다시 표시해 두 판정을 나란히 본다.
- 실제로 고치는 일은 그 사이에 작품에서 한다. 화면이 고쳐 주지 않는다.

## 2. 한 문장

다섯 항목을 **다시 판정하면** 처음 판정이 옆에 남아 어디가 달라졌는지 보인다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 | 다섯 항목. 각 줄에 `처음`과 `지금` 두 칸 | 어디가 달라졌는지 본다 |
| 가운데 | `아니요` 개수. 처음과 지금을 나란히 | 본다 |
| 아래 | 줄마다 예/아니요 단추, `판정 담기`, `다시 하기` | 표시하고 담는다 |

- 다섯 항목은 과정안 활동1 다섯째 줄의 점검표다. 학생이 못 고친다.

| 번호 | 항목 |
|---|---|
| 1 | 실제 이름이 없나 |
| 2 | 학교와 반이 없나 |
| 3 | 쓰는 방법이 적혀 있나 |
| 4 | 알 수 없는 것을 적었나 |
| 5 | 가져온 자료를 적었나 |

## 4. 조작과 값

- 조절하는 값: **항목의 표시** 하나. 줄마다 `예` / `아니요` 둘 중 하나. 처음엔 둘 다 안 눌림.
- 보조 조작: `판정 담기`(지금 다섯 표시를 `처음` 칸으로 얼린다. 한 번만 된다),
  `다시 하기`(처음 칸과 지금 표시를 모두 비운다).
- **담기 전에는 `처음` 칸이 비어 있다.** 담고 나면 `처음` 칸은 어떤 길로도 안 바뀐다.
- 다섯 줄을 다 표시해야 `판정 담기`가 눌린다. 그 전에는 흐리고 까닭이 한 줄 뜬다.

**열어 두는 딴짓.** 고친 뒤 판정이 더 나빠질 수도 있다. 막지 않고 아쉬워하는 말도 하지 않는다.
활동3은 `한 사람이 하나씩 맡아 고치기`라 다른 항목이 함께 흔들릴 수 있다.

## 6. 연습 모드

## 7. 만드는 방법

```
지금 = [null, null, null, null, null]      // 'Y' | 'N'
처음 = null                                 // 담으면 배열 다섯 개가 얼어붙는다

표시(i, v): 지금[i] = v; 그 줄과 개수 두 칸만 다시 그린다
담기(): if (지금에 null이 없고 처음 === null) 처음 = 지금을 복사한 것
다시하기(): 처음 = null; 지금 = 다섯 null; 다 비운다

개수(배열): 배열에서 'N'인 것의 수
달라진줄(i): 처음 !== null && 처음[i] !== 지금[i]
```

- **처음 배열은 복사해서 얼린다.** 같은 배열을 가리키면 지금을 고칠 때 처음도 바뀐다.
- 예·아니요는 `aria-pressed`로 고른 것을 표시하고, 색 말고 테두리로도 구별되게 한다.
- 달라진 줄은 왼쪽에 굵은 금을 긋는다. 색으로만 구별하지 않는다.
- 포인트색 한 가지: 청록 `#0D9488`.
