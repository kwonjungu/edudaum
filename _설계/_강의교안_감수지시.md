## 판정 쓰기
`_tools/_판정/lecture/Bxx_L{N}.json` 형식(B01_L4.json과 같다):
```
{"block":"Bxx","round":N,"verdict":"PASS 또는 FAIL",
 "score":{"A1":0~2, ... 14항목},
 "zero":["0점 항목과 까닭"],
 "fix":["항목 위치(몇 장) 문제 → 고칠 방법", ...]}
```
0점이 하나도 없으면 PASS. fix는 고칠 사람이 바로 손댈 수 있게 **장 번호와 고칠 방법**을 쓴다.
