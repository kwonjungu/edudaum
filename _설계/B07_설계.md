# B07 체험 설계 — 기다리지 않으면

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 블록 놓기와 전송(활동1·2)은 그대로 한다.

- **웹이 아니면 못 하는가.** 이 차시의 진짜 함정은 `잠시 기다리는 블록`이다.
  기다리는 시간이 짧으면 **첫 그림이 보이지도 않고 지나간다.** 그것을 기기에서 보려면
  블록을 고쳐 다시 전송해야 하고 한 번에 몇 분이 걸린다.
  화면은 기다리는 시간을 0초에서 2초까지 밀면서 **눈으로** 본다.
- **값을 바꾸면 결과가 바뀌는가.** 기다리는 시간을 바꾸면 두 그림이 보이는 모습이 바뀐다.

**여전히 만들지 않는 것.** 블록 고르기·붙이기, 전송, 저장. 화면에 블록 창을 만들지 않는다.
`마이크로비트로 옮겨 봐요`를 상시로 둔다.

## 1. 과정안 어디에 붙는가

- 블록 B07, 13~14차시. **활동3 셋째 줄의 예상 자리**에 3분.
  `두 표시 블록의 자리를 바꾸기 전에 예상을 먼저 적기` — 그 예상을 손으로 맞춰 본다.
- 활동2에서 이미 전송해 LED로 확인한 **뒤**에 쓴다. 전송 전에 쓰지 않는다.

## 2. 한 문장

**기다리는 시간**을 바꾸면 두 그림이 어떻게 보이는지 달라지고, 자리를 바꾸면 차례가 바뀐다.

## 3. 화면 (게임, 2026. 9. 17. 다시 짬)

`_게임설계.md` 4절의 지정: **"무엇이 보일지" 짚어라, 기다림이 0인 판이 섞인다.**
기다리는 시간을 학생이 막대로 밀어 보며 눈으로 관찰하던 것을, **시간을 가려 두고
결과만으로 되짚게** 뒤집었다. 막대(슬라이더)는 없앴다.

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 | 블록 넉 줄(시작할 때 / 하트·웃는 얼굴 / 잠시 기다리기 / 나머지 하나), 5×5 LED | 차례를 본다 |
| 가운데 | 짚기 세 갈래: `하트만 보인다` / `웃는 얼굴만 보인다` / `둘 다 보인다` | 짚기 전에 하나를 고른다 |
| 아래 | `켜 보기`(잠김→풀림), `다시 보기`, `자리 바꾸기`, `다음 판` | 켜 보기로 확인한다 |

- 블록 넉 줄의 차례(하트가 먼저인지 웃는 얼굴이 먼저인지)는 판마다 새로 뽑힌다.
  `잠시 기다리기`의 값은 화면에 **숫자로 보여 주지 않는다.**

## 4. 조작과 값

- 짚는 값: 셋 갈래(하트만·웃는 얼굴만·둘 다). 확인 전에는 `켜 보기`가 잠겨 있다.
- 판이 뽑는 것: 기다리는 시간(0초 또는 0.1~1.5초, 0초가 셋에 하나쯤)과 두 그림의 차례.
  0초면 첫 그림이 건너뛰어져 **차례상 둘째 그림만** 보이고, 0초가 아니면 둘 다 보인다.
- `켜 보기`를 누르면 LED가 **한 바퀴만** 돈다(계속 되풀이하지 않는다). 다 돌면
  기다린 시간이 그제야 숫자로 드러난다.
- `자리 바꾸기`: 하트·웃는 얼굴의 차례를 뒤집는 예약을 켠다. **다음 판부터** 적용된다
  — 지금 판의 결과에는 영향을 주지 않는다(과정안 활동3의 "자리를 바꾸면" 대응).
- `다시 보기`: 같은 판(같은 기다림·차례)을 다시 한 바퀴 돌린다. 확인이 끝난 뒤에만 쓴다.
- `다음 판`: 기다림과 차례를 새로 뽑는다. 직전 판과 같은 조합이면 다시 뽑는다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 | 글자 수 |
|---|---|---|
| 제목 | 기다리지 않으면 | 8 |
| 부제 | 무엇이 보일까 | 7 |
| 블록 줄 | 시작할 때 / 하트 / 잠시 기다리기 / 웃는 얼굴 | 5 / 2 / 8 / 5 |
| 짚기 갈래 | 하트만 보인다 / 웃는 얼굴만 보인다 / 둘 다 보인다 | 7 / 10 / 7 |
| 버튼 | 켜 보기 / 다시 보기 / 자리 바꾸기 / 다음 판 | 4 / 4 / 6 / 3 |
| 확인 뒤 표시 | 기다린 시간 0.4초 | 가변 |
| 되짚기(상시) | 마이크로비트로 옮겨 봐요 | 13 |

한 화면 약 140자.

**쓰지 않는 말**: 순차, 알고리즘, 프로그램, 코드, 밀리초.

## 6. 연습 모드

**해당 없음.** 외부 호출·센서·카메라를 쓰지 않는다.

## 7. 만드는 방법

```
그림 = { 하트: 25칸 배열, 웃는얼굴: 25칸 배열 }
차례 = ['하트', '웃는얼굴']        // 자리 바꾸기로 뒤집는다
기다림 = 0                         // 초

돌기():
  줄2 표시 → 그림[차례[0]]을 LED에 켠다
  줄3 표시 → 기다림 초 동안 그대로 둔다 (0이면 곧장 다음으로)
  줄4 표시 → 그림[차례[1]]을 LED에 켠다
  0.8초 뒤 처음부터 되풀이
```

- LED 스물다섯 칸은 SVG `<rect>` 25개. `fill`만 바꾼다(B11과 같은 방식).
- 막대를 미는 동안에도 되풀이가 끊기지 않게 한다. 다음 바퀴부터 새 값을 쓴다.
- 화면을 벗어나면 되풀이를 멈춘다. 돌아오면 다시 돈다. **두 벌이 겹쳐 돌지 않게 한다.**
- 포인트색 한 가지: 하늘 `#0EA5E9`.

## 8. 난이도 점검

첫 조작 3초, 1화면, 조작 요소 3개, 값 1개, 3분, 새로 배우는 조작법 0개.

## 9. 디버깅

- [ ] 0초에서 첫 그림이 보이지 않는다(눈으로 확인한다).
- [ ] 0.5초쯤부터 두 그림이 또렷이 갈린다.
- [ ] 막대를 끝까지 밀었다 되돌려도 되풀이가 끊기지 않는다.
- [ ] `자리 바꾸기`를 누르면 다음 바퀴부터 차례가 바뀐다.
- [ ] 다른 앱으로 갔다 오면 되풀이가 한 벌만 돈다.
- [ ] 스물다섯 칸이 두 그림에서 서로 다르게 켜진다.

### 앞선 판정문 (2026. 9. 11.)

> 만들지 않는다. MakeCode 모의 실행 화면이 이미 같은 일을 한다.

블록을 놓고 모의 실행하는 일에 대해서는 그대로 살아 있다. 뒤집은 것은
**기다리는 시간을 밀어 보는** 자리다. 기기에서 그것을 보려면 블록을 고쳐 다시 돌려야 한다.
