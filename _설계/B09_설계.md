## 0. 만들까 말까

**만든다.**

반복 횟수를 바꾸면 하트가 몇 번 나타나는지, 그리고 블록 수가 어떻게 달라지는지가 손잡이 하나로
즉시 보인다. 실물에서는 횟수를 바꿀 때마다 코드를 옮겨야 해서 한 차시에 두세 번밖에 못 견준다.

늘어선 코드와 반복으로 묶은 코드의 **블록 수를 나란히** 보는 일은 종이로는 세어야만 알 수 있고
MakeCode 화면에서는 한 번에 한 쪽밖에 안 보인다. 이 견줌이 웹이 아니면 어려운 자리다.

## 3. 화면 (게임, 2026. 9. 17. 다시 짬)

`_게임설계.md` 4절의 지정: **하트가 "몇 번 나타날지" 짚어라, 반복 안에 반복이 든
판(겹침)이 섞인다.** 손잡이로 횟수를 정해 즉시 결과를 보던 것을, **반복 블록을 먼저
보여 주고 수를 짚은 뒤에 돌려 확인하는** 순서로 뒤집었다. 손잡이(슬라이더)는 없앴다.

| | 내용 |
|---|---|
| 보이는 것 | 반복 블록 글줄(홑겹 또는 겹침), LED 5×5 격자(검정 패널), 1~20 짚기 띠 |
| 학생이 하는 것 | 블록을 보고 몇 번 나타날지 띠에서 짚는다 → `돌려 보기`로 세어 확인한다 |
| 넘어가는 조건 | 없다. 한 화면에서 끝내고 기기로 간다 |

---

## 4. 조작과 값

- 짚는 값: **1~20 가운데 하나**(띠). 짚기 전에는 `돌려 보기`가 잠겨 있다.
- 판이 뽑는 것: 반복 횟수 N(2~5), 안쪽 횟수 M(1~4), 홑겹·겹침 여부(겹침이 셋에 하나쯤).
  - 홑겹: `N번 반복하기 { 하트 M번 보여주기 }`
  - 겹침: `N번 반복하기 { M번 반복하기 { 하트 보여주기 } }`
  - 둘 다 실제로 나타나는 수는 **N×M**으로 같다. 겹침이라고 더 많이 나타나지 않는다는
    것을 몸소 세어 보며 깨닫게 하는 것이 이 판의 핵심이다.
- `돌려 보기`를 누르면 하트가 한 번에 하나씩 켜졌다 꺼지며(켜짐 300ms, 꺼짐 160ms)
  실제 수까지 센다. 다 세면 짚은 수와 견주어 `N번 더/덜 나타났어요`로 알려 준다.
- `다시 보기`: 같은 판을 다시 세어 본다(짚은 수는 그대로 유지). `다음 판`: N·M·홑겹
  또는 겹침 여부를 새로 뽑는다. 직전 판과 같으면 다시 뽑는다.
- 실행 중에는 띠와 `돌려 보기`를 잠근다.

## 7. 만드는 방법

- 순수 HTML·CSS·JS. 외부 라이브러리 **없음**.
- LED 격자: `document.createElementNS`로 `rect` 25개를 만들어 `viewBox="0 0 100 100"`에 21.25 간격으로 놓는다.
  하트 도안은 마이크로비트 기본 하트와 같은 5×5 배치.
- 블록 견줌 그림: `viewBox="0 0 120 188"`, 아래에서 위로 쌓는다. 왼쪽 `3n`개, 오른쪽은 테두리 한 겹 + 3개.
- 실행 의사코드

```
해 보기:
  실행 중이면 무시
  타이머 비우기, 카운트 0, 하트 끄기, 버튼·손잡이 잠그기
  step():
    센 수 == n 이면 잠금 풀고 끝
    하트 켜기; 센 수 += 1; 숫자 갱신
    420ms 뒤 하트 끄고, 230ms 뒤 step()

다시 하기:
  타이머 비우기, 잠금 풀기, 하트 끄기, 카운트 0
```

- `prefers-reduced-motion`에서는 CSS `transition`을 모두 끈다. 켜짐·꺼짐 자체는 남긴다.
  깜빡임을 없애면 "몇 번 나타났는가"를 셀 수 없어 활동이 성립하지 않는다. 일부러 다르게 한 곳이다.
