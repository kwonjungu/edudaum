## 0. 만들까 말까

**만든다.**

반복 횟수를 바꾸면 하트가 몇 번 나타나는지, 그리고 블록 수가 어떻게 달라지는지가 손잡이 하나로
즉시 보인다. 실물에서는 횟수를 바꿀 때마다 코드를 옮겨야 해서 한 차시에 두세 번밖에 못 견준다.

늘어선 코드와 반복으로 묶은 코드의 **블록 수를 나란히** 보는 일은 종이로는 세어야만 알 수 있고
MakeCode 화면에서는 한 번에 한 쪽밖에 안 보인다. 이 견줌이 웹이 아니면 어려운 자리다.

---

## 1. 과정안 어디에 붙는가

- 블록 B09, 17~18차시, 활동2 「반복 블록으로 묶어 견주기」와 활동3 「반복 횟수를 바꾸어 확인하기」
- **실물 앞**에 쓴다. 횟수를 정하고 예상해 본 뒤, 같은 횟수로 코드를 옮겨 기기에서 확인한다.
- 교실에서 5분. 활동3에서 3·5·8을 옮기기 전에 한 번씩 열어 본다.

## 2. 한 문장

반복 횟수를 바꾸면 하트가 나타나는 수와 늘어선 블록 수가 함께 달라진다.

## 3. 화면 (1화면)

| | 내용 |
|---|---|
| 보이는 것 | LED 5×5 격자(검정 패널), 블록 견줌 그림(늘어선 쪽·반복 쪽), 반복 횟수 손잡이, `해 보기`·`다시 하기`, 하트가 나타난 수 |
| 학생이 하는 것 | 손잡이를 움직여 횟수를 정한다 → 몇 번 나타날지 말한다 → `해 보기`를 눌러 센다 |
| 넘어가는 조건 | 없다. 한 화면에서 끝내고 기기로 간다 |

## 4. 조작과 값

- 조절하는 값: **반복 횟수 하나**. 범위 1~8, 한 칸씩. 기본값 3(활동3의 첫 칸과 같다).
- 반영되는 곳 세 군데가 동시에 바뀐다.
  - LED 하트가 켜졌다 꺼지기를 n번 되풀이한다(켜짐 420ms, 꺼짐 230ms).
  - `하트가 나타난 수`가 한 번 켜질 때마다 1씩 오른다.
  - 왼쪽 블록 더미가 `3×n`개, 오른쪽은 늘 4개(반복 블록 1 + 묶음 3)로 그려진다.
- 묶음을 3개로 잡은 근거: 과정안 도입의 「같은 블록 세 개가 다섯 번 늘어선 코드」.
- 실행 중에는 `해 보기`와 손잡이를 잠근다. `다시 하기`는 언제나 눌린다.

## 7. 만드는 방법

- 순수 HTML·CSS·JS. 외부 라이브러리 **없음**.
- LED 격자: `document.createElementNS`로 `rect` 25개를 만들어 `viewBox="0 0 100 100"`에 21.25 간격으로 놓는다.
  하트 도안은 마이크로비트 기본 하트와 같은 5×5 배치.
- 블록 견줌 그림: `viewBox="0 0 120 188"`, 아래에서 위로 쌓는다. 왼쪽 `3n`개, 오른쪽은 테두리 한 겹 + 3개.
- 실행 의사코드

```
해 보기:
  실행 중이면 무시
  타이머 비우기, 카운트 0, 하트 끄기, 버튼·손잡이 잠그기
  step():
    센 수 == n 이면 잠금 풀고 끝
    하트 켜기; 센 수 += 1; 숫자 갱신
    420ms 뒤 하트 끄고, 230ms 뒤 step()

다시 하기:
  타이머 비우기, 잠금 풀기, 하트 끄기, 카운트 0
```

- `prefers-reduced-motion`에서는 CSS `transition`을 모두 끈다. 켜짐·꺼짐 자체는 남긴다.
  깜빡임을 없애면 "몇 번 나타났는가"를 셀 수 없어 활동이 성립하지 않는다. 일부러 다르게 한 곳이다.

### 이 차시에만 해당하는 항목
- [x] `해 보기`를 연달아 세 번 눌러도 한 번만 돈다 — 잠금 확인(실행 중 카운트 3, 겹쳐 돌지 않음).
