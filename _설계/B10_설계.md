# B10 체험 활동 설계 — 처음 값 바꿔 흔든수 짚기

2026. 10. 11. 지도안(검토반영본)에 맞춰 다시 짰다. 옛 설계(처음 값 블록이 '있다/없다'를 가려 두고 짚기)는
지도안이 그 활동을 없앴으므로 버린다. 구조는 `판이 나온다 → 짚는다 → 확인한다` 그대로이고,
사람에게 보이는 이름만 '체험 활동'이라 부른다.

- 경로: `B10/index.html` (단일 파일, 외부 라이브러리·CDN·서버 없음)
- 포인트 컬러: 통일 테마 `--point`

## 0. 지도안의 어느 활동에 붙나

**19차시 전개 「활동2. 흔들기 카운터 만들기 (18분)」**, 아래 줄들 **앞**에 5분.

> - 다섯 번 흔들 때 나올 값을 먼저 예상해 적기
> - 전송하고 흔들어 예상과 화면의 수 비교하기
> - 처음 값을 10으로 바꾸면 다섯 번 흔든 뒤 몇이 될지 예상하고 확인하기
> - 처음 값이 달라지면 결과가 어떻게 달라지는지 한 문장으로 쓰기

과정·기능 ③ `흔들기 횟수와 처음 값을 바꾸며 예상과 실행 결과 비교하기`를 판으로 만든다.
유의점 `예상한 값을 적기 전에는 실행하지 않게 한다`는 **짚기 전 흔들기 잠금**으로,
`'처음 값 빼기' 대신 '처음 값 바꾸기(0→10)'로 비교한다`는 **두 판 한 쌍(0 판 → 10 판)** 으로 옮겼다.

화면에서 몇 판 해 본 뒤 자기 마이크로비트(또는 MakeCode 시뮬레이터의 SHAKE)로 0과 10을 확인하고,
한 문장은 변수 추적지(붙임 1)에 쓴다.

**대신하지 않는 것.** 활동1 숫자 주머니 놀이(종이컵·바둑돌), 기기 전송·흔들기, 활동3 종합 미션,
활동4 종이컵 셰이커 30 챌린지, 추적지 쓰기. 모두 실물로 한다.

## 1. 다섯 칸

| 칸 | 이 화면에서 |
|---|---|
| 목표 | 이번 판의 처음 값과 흔들 횟수를 보고 마지막 흔든수를 짚는다 |
| 실패 | 짚은 수와 화면의 수가 빗나갈 수 있다 |
| 예상 | 짚기 전에는 `흔들기`가 잠긴다 |
| 제약 | 흔들기는 판이 정한 횟수만큼만 된다 |
| 되풀이 | `다음 판`마다 흔들 횟수가 새로 나오고, 처음 값이 0 → 10으로 바뀐다 |

다섯 칸 모두 채운다.

---

## 2. 판

- 판은 **두 판이 한 쌍**이다. 한 쌍 안에서 흔들 횟수 N은 같고 처음 값만 0 → 10으로 바뀐다(지도안의 0과 10 비교).
- N은 3~8에서 뽑는다. 첫 쌍은 지도안대로 N = 5. 다음 쌍부터는 직전 쌍과 다른 N.
- 10 판에서는 `지난 판과 다른 것: 처음 값 0 → 10`을 코드 카드 아래에 보인다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 |
|---|---|
| 흔들기 카운터 | LED 5×5, `흔든수` 칸, 코드 카드 `시작하면 실행: 흔든수에 [처음 값] 저장`, `흔들림 감지하면 실행: 흔든수 값 1 증가 / 수 출력 흔든수` |
| 이번 판 | `처음 값 a, N번 흔들면 흔든수는?` 짚는 칸(숫자, − / +), `짚기`, `흔들기`(남은 횟수), 견주는 말, `다음 판`, `처음으로` |
| 지난 판 | 지난 판 몇 줄: `처음 값 0 · 5번 → 5 (짚은 수 4)` |

## 4. 조작과 값

- 판이 열리면 흔든수 = 처음 값, LED는 꺼져 있다. 짚는 칸은 비어 있다.
- 짚는 칸에 수를 넣으면 `짚기`가 열린다. **짚기 전에는 몇 번이든 고칠 수 있다.** `짚기`를 누르면 굳고 `흔들기`가 열린다.
- `흔들기`: 흔든수 += 1, LED에 그 수, 버튼에 남은 횟수. N번이면 잠긴다.
- 끝나면: 같으면 `짚은 수와 화면의 수가 같아요`, 다르면 `짚은 수 g, 화면 v. d 떨어졌어요`.
- `다음 판`은 이번 판이 끝나야 열린다. `처음으로`는 첫 쌍(N=5, 처음 값 0)으로.
- 맞힌 판 수·점수는 세지 않는다.

## 5. 글자

| 자리 | 문구 |
|---|---|
| 제목(h1) | 처음 값 바꿔 흔든수 짚기 |
| 부제 | 짚고 나서 흔들어 견줘요 · 체험 활동 |
| 버튼 | 짚기 / 흔들기 / 다음 판 / 처음으로 |
| 잠금 안내 | 짚어야 흔들 수 있어요 |

쓰지 않는 말: 게임, 점수, 맞았어요, 틀렸어요, 잘했어요, 초기화.
블록 이름은 지도안 표기 그대로(`흔든수에 0 저장`, `흔든수 값 1 증가`, `수 출력 흔든수`).

## 6. 센서·권한

없음. 흔들기는 버튼이다(MakeCode 시뮬레이터 SHAKE 버튼과 같은 자리). 지도안이 흔드는 것은 마이크로비트이지
태블릿이 아니므로 태블릿 가속도를 쓰지 않는다.

## 7. 남은 것
