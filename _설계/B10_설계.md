# B10 체험 활동 설계 — 처음 값 바꾸기 활동

2026. 10. 11. 지도안(검토반영본)에 맞춰 **게임을 버리고 체험 활동으로 다시 짰다.**
옛 설계(처음 값 블록이 '있다/없다'를 가려 두고 짚는 게임)는 지도안이 그 활동을 없앴으므로 쓰지 않는다.

- 경로: `B10/index.html` (단일 파일, 외부 라이브러리·CDN·서버 없음)
- 포인트 컬러: 통일 테마 `--point`

---

## 0. 지도안의 어느 활동을 웹으로 옮겼나

**19차시 전개 「활동2. 흔들기 카운터 만들기 (18분)」의 뒤 네 줄**을 그대로 옮겼다.

> - 다섯 번 흔들 때 나올 값을 먼저 예상해 적기
> - 전송하고 흔들어 예상과 화면의 수 비교하기
> - 처음 값을 10으로 바꾸면 다섯 번 흔든 뒤 몇이 될지 예상하고 확인하기
> - 처음 값이 달라지면 결과가 어떻게 달라지는지 한 문장으로 쓰기

유의점도 그대로 따른다.

> △ 예상한 값을 적기 전에는 실행하지 않게 한다.
> △ MakeCode 변수는 처음 값 블록이 없어도 0에서 시작하므로, '처음 값 빼기' 대신 '처음 값 바꾸기(0→10)'로 비교한다.
> △ 마이크로비트가 없으면 MakeCode 화면 왼쪽 시뮬레이터로 같은 활동을 한다.

**붙는 자리.** 활동2에서 코드를 다 만든 뒤, 기기에 전송하기 **앞**에 5분. 화면에서 0과 10 두 번을 해 보고
같은 순서를 기기로 확인한다. 기기가 없거나 전송이 막힌 학생은 이 화면으로 같은 활동을 끝낸다.

**대신하지 않는 것.** 활동1 숫자 주머니 놀이(종이컵·바둑돌), 활동3 종합 미션, 활동4 종이컵 셰이커 30 챌린지는
실물로 한다. 변수 추적지(붙임 1)도 종이에 쓴다. 화면은 끝에 **옮겨 적을 것**만 보여 준다.

## 1. 활동 순서 (지도안 순서 그대로)

| 차례 | 지도안 | 화면에서 하는 일 |
|---|---|---|
| ① | `[흔든수에 0 저장]` 놓기 | 코드 카드에 처음 값 `0`이 보인다 |
| ② | 다섯 번 흔들 때 나올 값을 먼저 예상해 적기 | 예상 칸에 수를 넣고 `예상 적기` |
| ③ | 흔들어 예상과 화면의 수 비교하기 | `흔들기` 다섯 번 → 추적표 0~5번째 칸이 찬다 → 예상과 견준다 |
| ④ | 처음 값을 10으로 바꾸면 … 예상하고 확인하기 | `처음 값 10으로` → 코드 카드가 `10`으로 바뀜 → ②③ 다시 |
| ⑤ | 한 문장으로 쓰기 | 문장 칸에 직접 쓴다 |
| ⑥ | (변수 추적지에 옮겨 적기) | 옮겨 적을 것 한 줄이 보인다 |

---

## 2. 화면 (1화면, 세 구역)

| 구역 | 보이는 것 |
|---|---|
| 코드와 화면 | LED 5×5, `흔든수` 칸, 코드 카드 두 장(`시작하면 실행: 흔든수에 [0] 저장`, `흔들림 감지하면 실행: 흔든수 값 1 증가 / 수 출력 흔든수`) |
| 변수 추적지 | 처음 값 0 줄과 10 줄. 칸: 예상 / 처음 / 1~5번째 흔들기. 예상 칸(숫자), `예상 적기`, `흔들기`, `처음 값 10으로` |
| 한 문장 | 문장 칸(직접 쓰기), 옮겨 적을 것 한 줄, `처음으로` |

## 3. 조작과 값

- 예상 칸이 비어 있으면 `예상 적기`가 잠긴다. `예상 적기` 전에는 `흔들기`가 잠긴다(유의점 그대로).
- `예상 적기` 전에는 예상 칸을 몇 번이든 고칠 수 있다. 적고 나면 그 줄의 예상은 굳는다.
- `흔들기`를 누를 때마다 흔든수 += 1, LED에 그 수, 추적표 다음 칸에 값. 다섯 번이면 잠긴다.
- 다섯 번 뒤 견주기 문구: 같으면 `예상과 화면의 수가 같아요`, 다르면 `예상과 N 떨어졌어요`. 판정 말은 없다.
- 0 줄이 끝나면 `처음 값 10으로`가 열린다. 누르면 코드 카드의 `0`이 `10`으로 바뀌고 흔든수 = 10, 10 줄 차례.
- 두 줄이 다 끝나면 한 문장 구역이 열린다. 문장은 학생이 쓴다. 화면이 정답 문장을 주지 않는다.
- 옮겨 적을 것: `처음 값 0: 예상 a → 5번 뒤 5 / 처음 값 10: 예상 b → 5번 뒤 15 / 내 문장: …`
  저장·전송하지 않는다. 새로 고치면 사라진다.
- `처음으로`: 모든 값 비우기, 처음 값 0으로.

## 4. 글자

| 자리 | 문구 |
|---|---|
| 제목 | 처음 값 바꾸기 활동 |
| 부제 | 예상을 먼저 적고 흔들어 견줘요 |
| 버튼 | 예상 적기 / 흔들기 / 처음 값 10으로 / 처음으로 |
| 안내 | 예상을 적어야 흔들 수 있어요 |
| 한 문장 칸 안내 | 처음 값이 달라지면 결과는 어떻게 달라지나요 |

쓰지 않는 말: 점수, 맞았어요, 틀렸어요, 잘했어요, 초기화, 게임, 판.
블록 이름은 지도안 표기 그대로(`흔든수에 0 저장`, `흔든수 값 1 증가`, `수 출력 흔든수`).

## 5. 센서·권한

없음. 흔들기는 버튼으로 한다(지도안의 시뮬레이터 SHAKE 버튼과 같은 자리). 태블릿 가속도를 쓰지 않는다 —
지도안이 흔드는 것은 마이크로비트이지 태블릿이 아니다.

## 6. 남은 것

두 자리 수는 LED에 한 자리씩 차례로 보인다(실물은 흘러간다). 지도안 유의점 '두 자리 수는 화면에 흘러가며 보이므로
다 보일 때까지 기다리게 한다'와 같은 기다림이 생기도록 표시가 끝날 때까지 다음 흔들기를 받되 표시는 마지막 값으로 다시 그린다.
