# B10 체험 설계 — 다시 시작하면 어떻게 될까

- 경로: `B10/index.html` (단일 파일, 외부 라이브러리·CDN·서버 없음)
- 포인트 컬러: 퍼플 `--point #7C3AED` / `--point-soft #EDE7FF`
- 공통기준과 다르게 한 곳: 6절(연습 모드)만. 아래 6절에 까닭을 적었다.

---

## 0. 만들까 말까

**만든다.**

처음 값 블록을 넣었을 때와 뺐을 때의 차이는 **다시 시작해 봐야** 드러난다. 실물에서는 블록을
지우고 코드를 다시 옮겨야 해서 두 경우를 오가며 견주기 어렵다.

웹에서는 스위치 하나로 그 블록을 넣었다 빼며 같은 자리에서 바로 견줄 수 있다. 값을 바꾸면
결과가 즉시 달라지고, 기기 없이 예상해 본 뒤 실물로 확인하는 차례가 그대로 이어진다.

---

## 1. 과정안 어디에 붙는가

- 블록 B10, 19~20차시, 활동5 「처음 값이 빠진 예제 견주어 고치기」와 활동6 「멈추고 흔들고 다시 시작해 보기」
- **실물 앞**에 쓴다. 활동5의 "다시 실행하면 값이 어떻게 될지 예상해 적기"를 이 화면에서 먼저
  손으로 해 보고, 예제를 기기에 옮겨 실제 값을 적는다.
- 교실에서 5~7분.

---

## 2. 한 문장

처음 값 블록을 넣었다 뺀 뒤 다시 시작하면, 흔들어 올린 값이 0으로 돌아가거나 그대로 이어진다.

---

## 3. 화면 (게임, 2026. 9. 17. 다시 짬)

`_게임설계.md` 4절의 지정: **다시 시작하면 "값이 몇일지" 짚어라, 처음 값 블록이
있는지 가려 둔다.** 스위치로 학생이 직접 블록을 넣었다 뺐다 하던 것을, **블록의
있고 없음을 가려 두고 결과로 되짚게** 뒤집었다. 스위치(토글)는 없앴다.

| | 내용 |
|---|---|
| 보이는 것 | LED 5×5 격자, `걸음` 칸, `흔들기`, 가려진 코드 카드(`처음에 — ? ? ?`), 흔들면 카드 |
| 학생이 하는 것 | 흔들어 값을 올린다 → `0`과 `지금 값` 가운데 다시 시작하면 값이 몇일지 짚는다 → `다시 시작` |
| 넘어가는 조건 | 없다. 한 화면에서 끝내고 기기로 간다 |

---

## 4. 조작과 값

- 판이 뽑는 것: **처음 값 블록의 있고 없음**(반반). 판마다 `처음에` 카드가 `? ? ?`로
  가려져 있어 학생이 미리 알 수 없다.
- 주된 조작은 `흔들기`. 누를 때마다 `걸음`이 1 오르고 LED에 그 수가 보인다. 짚기 전에는
  몇 번이든 흔들 수 있다(한 번 이상 흔들어야 짚기가 열린다).
- 짚는 값: `0` 또는 `지금 값 N`(N은 짚는 순간의 걸음 수로 정해진다). 짚고 나면
  `흔들기`도 잠기고, 그 순간의 값으로 짚기가 굳는다.
- `다시 시작`을 누르면 가려진 카드가 드러난다.
  - 블록이 있던 판이면 `걸음 0으로 정하기`가 보이고 값이 0이 된다.
  - 블록이 없던 판이면 카드가 빗금 바탕·점선 테두리로 바뀌고 값이 그대로 남는다.
  - 짚은 값과 실제 값이 같으면 `짚은 대로 나왔어요`, 다르면 `실제로는 N이었어요`.
- `다음 판`: 블록의 있고 없음을 새로 뽑고 `걸음`을 0으로 되돌리며 카드를 다시 가린다.
  직전 판과 같으면 다시 뽑는다.

## 6. 연습 모드

**두지 않는다.** 외부 호출이 하나도 없다. 기기 센서를 쓰지 않고 버튼 누름으로 흔들림을 대신하므로
권한도 필요 없다. 인터넷을 끊어도 파일만으로 그대로 돈다. 공통기준 7절 표에서 이 차시에 해당하는
줄이 없어 `연습 모드` 표시를 넣지 않았다.

## 7. 만드는 방법

- 순수 HTML·CSS·JS. 외부 라이브러리 **없음**.
- LED 격자: `rect` 25개를 `viewBox="0 0 100 100"`에 21.25 간격으로 놓는다.
- 숫자 도안: 3칸×5칸 비트맵 10개를 문자열로 두고 가운데 세 열(1~3)에 그린다.
- 표시 의사코드

```
보이기(v):
  타이머 비우기
  s = 문자열(v)
  한 자리씩:
    그 자리 켜기
    마지막 자리면 켠 채로 끝
    620ms 뒤 지우고, 150ms 뒤 다음 자리

흔들기: 걸음 += 1; 변수 칸 갱신; 보이기(걸음)
다시 시작: 타이머 비우기; 화면 지우기; 스위치가 켜져 있으면 걸음 = 0; 변수 칸 갱신
처음으로: 걸음 0, 스위치 켬, 카드 되돌리기, 화면 지우기
```

- 두 자리 이상을 한 자리씩 차례로 보여 준 것은 단순하게 만든 것이다. 실물은 글자가 옆으로
  흘러가며 보인다. 공통기준과 다르게 한 것이 아니라 그림을 줄인 것이므로 화면에 설명을 붙이지 않고
  여기에만 적어 둔다.
- 흔들림은 가속도 센서가 잡은 **흔들림 감지**를 세는 것이다. 이 화면도 같은 셈이므로 화면 어디에도
  걸음 측정값이라고 적지 않았다. 변수 이름만 `걸음`으로 두어 과정안 코드와 맞췄다.
- 감도 조절 같은, 지금 블록에 없는 기능은 넣지 않았다.
