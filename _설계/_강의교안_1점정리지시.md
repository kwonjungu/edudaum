# 강의교안 게시 뒤 1점 메모 정리 지시 (2026-10-31)

저장소 `C:\Users\권준구\projects\edudaum`. 먼저 `_설계/_강의교안_수정지시.md`(고쳐도 되는 곳, 금지, 확인 순서)와 `_설계/_강의교안_배운것.md`를 읽는다. 규칙은 수정지시와 같다. 다른 점:

- 입력은 판정 파일이 아니라 이 프롬프트에 적힌 고칠 점이다. 맡은 블록 하나만 고친다.
- 공통 파일(make_lecture.py, lecture.css/js, lecture_pdf.cjs, lecture_check.cjs, make_site.py, _published.json)은 오케스트레이터가 동시에 고치고 있으니 절대 건드리지 않는다.
- `_설계/_강의교안_배운것.md`에 쓰지 않는다(여러 에이전트가 동시에 씀). 배운 것 한 줄은 마지막 답에 적는다.
- 원본 그림은 덮어쓰지 않고 새 이름(`*_v2.webp` 등)으로 만들어 원고 경로를 바꾼다.
- PIL 스크립트는 Write로 .py 파일을 만들어 `C:/Python313/python.exe 파일.py`로 돌린다(`-I` 금지, heredoc 금지).
- 체험 쪽을 다시 찍어야 하면 `_tools/lecture_recipes/Bxx.cjs`를 보고 고쳐 돌린다. 서버가 필요하면 레시피 안의 방식대로 하되, 끝나면 띄운 프로세스를 끈다.
- 커밋·푸시 금지. 한/글 조작 금지(`hwp.quit()` 금지).
- 확인: `python _tools/make_lecture.py Bxx` → `node _tools/_판정/lecture_check.cjs Bxx` 0건 → `C:/Python313/python.exe _tools/lecture_pages.py Bxx`로 고친 장 그림을 직접 열어 보고 글자 크기와 가림을 눈으로 확인한다.

마지막 답(짧게): `Bxx 정리 끝 / 고친 장과 방법 / 못 고친 것과 이유 / 새 파일 목록 / 배운 것 한 줄`.
