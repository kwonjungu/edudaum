# B24 체험 설계 — 기준만 바꾸면

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 자료는 **그 반이 손 들어 센 수**를 학생이 직접 넣는다. 미리 채우지 않는다.

- **웹이 아니면 못 하는가.** 활동3은 `자료표는 그대로 두고 기준만 바꾸어 다시 나누기`와
  `두 기준의 분류를 나란히 적고 달라진 항목에 표시`를 시킨다. 종이로는 막대를 두 번 그려야
  하고, 첫 기준의 막대는 대개 지워진다. 화면은 자료표를 잠가 두고 두 막대를 나란히 세운다.
- **값을 바꾸면 결과가 바뀌는가.** 항목을 어느 묶음에 넣느냐를 바꾸면 막대가 즉시 바뀐다.

**여전히 만들지 않는 것.** 손 들어 세기, 질문 문장 적기, 어느 묶음에도 안 맞는 항목을 어떻게
할지 정하기, 목적에 맞는 기준 고르기. 화면은 **수를 담고 두 번 가르는 일만** 한다.

## 1. 과정안 어디에 붙는가

- 블록 B24, 19~20차시. **활동3 셋째 줄 자리**에 4~5분.
  `두 기준의 분류를 나란히 적고 달라진 항목에 표시하기` — 그 나란히 놓기를 화면이 맡는다.
- 활동1의 손 들어 세기는 먼저 교실에서 한다. 그 수를 화면에 옮겨 넣는다.
- 활동2의 질문 문장과 활동4의 목적 고르기는 그대로 종이에 쓴다.

## 2. 한 문장

같은 자료표를 두고 **기준만 바꾸면** 막대 두 벌이 나란히 서고 달라진 항목이 보인다.

## 3. 화면 (1화면, 위아래)

| 칸 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 `자료표` | 일곱 항목과 사람 수, 합계 | `+` `−`로 수를 넣는다. 다 넣으면 잠근다 |
| 아래 `가르기` | 항목 일곱 개를 예/아니요로. 막대 두 벌 | 항목을 눌러 가른다. 기준을 바꾼다 |

- 일곱 항목은 과정안 활동1 그대로다. 학생이 못 고친다.
  `걸어서` `자전거` `킥보드` `버스` `자동차` `지하철` `그 밖에`
- 자료표를 잠그면 수가 바뀌지 않는다. 활동3 둘째 줄(`자료표는 그대로 두고`)을 구조가 지킨다.

## 4. 조작과 값

- 조절하는 값: **항목이 든 묶음** 하나. 항목을 누르면 `예 ↔ 아니요`.
- 자료표 단계: 항목마다 `+` `−`로 0~30. 처음은 모두 0. `자료표 잠그기`로 넘어간다.
- 보조 조작: `기준 바꾸기`(첫째 기준과 둘째 기준을 오간다), `다시 하기`(다 비운다).
- 막대 두 벌: 첫째 기준의 `예`·`아니요` 사람 수, 둘째 기준의 `예`·`아니요` 사람 수.
  둘째 기준을 아직 안 갈랐으면 그쪽 막대는 비어 있다.
- 각 기준의 두 묶음 합은 늘 표의 합계와 같다. 그 수를 막대 옆에 적는다(활동2 마지막 줄).

**열어 두는 딴짓.** 두 기준을 똑같이 갈라 볼 수 있다. 막지 않는다.
달라진 항목이 하나도 없는 것을 보는 것도 활동3의 답이다.

**쓰지 않는 말**: 데이터, 분류, 알고리즘, 인공지능, 정답, 좋은 기준.

## 6. 연습 모드

**해당 없음.** 외부 호출·센서·카메라를 쓰지 않는다.

## 7. 만드는 방법

```
항목 = 일곱 개. 각 {이름, 수:0}
잠김 = false
가르기 = { 1: 일곱 개 null, 2: 일곱 개 null }    // 'Y' | 'N'
지금기준 = 1

수더하기(i): if (!잠김) 항목[i].수 = min(수+1, 30); 그 줄과 합계만 다시 그린다
잠그기(): if (합계 > 0) 잠김 = true
항목누르기(i): 가르기[지금기준][i] = (지금 값이 'Y' ? 'N' : 'Y'); 막대만 다시 그린다
막대(k, v): 가르기[k]가 v인 항목들의 수를 더한다
달라진항목(i): 가르기[1][i] !== null && 가르기[2][i] !== null && 두 값이 다르다
```

- 막대 넷은 인라인 SVG `<rect>`의 `width`만 바꾼다.
- 달라진 항목은 왼쪽에 굵은 금을 긋는다. 색으로만 구별하지 않는다.
- 이름과 번호를 적는 칸을 두지 않는다(활동1 둘째 줄).
- 포인트색 한 가지: 보라 `#9333EA`.

## 8. 난이도 점검

첫 조작 5초, 1화면(두 칸), 값 1개, 4~5분, 새로 배우는 조작법 0개.

## 9. 디버깅

- [ ] 사람 수를 하나도 안 넣으면 `자료표 잠그기`가 흐리고 까닭이 뜬다.
- [ ] 잠근 뒤 `+` `−`가 눌리지 않는다.
- [ ] 두 묶음 사람 수의 합이 늘 합계와 같다.
- [ ] `기준 바꾸기`로 오가도 앞 기준의 가르기가 남아 있다.
- [ ] 두 기준을 다 가른 항목만 달라짐 표시가 붙는다.
- [ ] 두 기준을 똑같이 갈라도 화면이 아무 말도 하지 않는다.
- [ ] 학생 이름을 적는 칸이 없다.

### 앞선 판정문 (2026. 9. 11.)

> 만들지 않는다. 나눌 자료가 그 반이 손 들어 센 자료다.

**이 판정을 지켰다.** 자료를 미리 넣어 두지 않고 학생이 교실에서 센 수를 직접 넣는다.
뒤집은 것은 **같은 자료표로 두 번 가르는** 자리다. 종이에서는 첫 막대가 지워진다.
