# B24 체험 설계 — 기준 바꿔 다시 나누기 활동

작성: 2026. 10. 11. 검토반영본 지도안 기준으로 다시 썼다. 구조는 `판이 나온다 → 짚는다 → 확인한다`, 화면에 보이는 이름만 **체험 활동**. 옛 설계(일곱 항목 사람 수를 넣고 두 기준의 예 묶음을 똑같이 맞추기)는 git 기록에 남는다.

## 0. 지도안의 어느 활동 앞/뒤에 붙나

19차시 **활동2. 사람이 기준 세워 나누고 차트로 나타내기**의 아래 두 줄 **앞**(4~5분).

> - 표에 ‘기준1’ 속성을 더해 줄마다 예·아니요 적기
> - 두 번째 기준으로 다시 나누어 묶음이 달라진 줄 표시하기

학생이 자기 기준으로 엔트리 표를 나누기 전에, 판마다 새로 나온 등교 표(등교 방법·걸리는 시간(분)·횡단보도 수)와 기준1·기준2 문장을 보고 **기준2로 바꾸면 묶음이 달라질 줄을 먼저 짚는다.** 확인하면 기준2 칸이 채워지고 달라진 줄이 드러나며, 두 기준의 막대 차트가 나란히 선다.

옛 웹이 어긋난 까닭(보고서 B24 6절): 손 들어 센 일곱 항목 수를 넣던 구조였으나, 지도안은 구글 폼 응답을 엔트리 표로 불러와 **줄마다** 숫자 기준(예: 15분보다 오래 걸리나?)으로 나눈다. 그래서 판을 `줄 단위 등교 표 + 숫자 기준`으로 바꾼다.

웹으로 옮기지 않는 것: 구글 폼 응답 불러오기(활동1), 학생이 자기 기준 문장을 적고 엔트리 차트를 그리는 일, 짝의 비밀 기준 찾기(짝과 말로), 엔트리 숫자 분류 모델(활동3), 목적에 맞는 기준 고르기(활동4). 화면의 표는 판이 그 자리에서 뽑은 **예시 표**이며 우리 반 자료가 아니라고 상시로 밝힌다.

## 1. 다섯 칸

| 칸 | 이 활동에서 |
|---|---|
| 목표 | 기준2로 바꾸면 **묶음이 달라질 줄**을 모두 짚어라 |
| 실패 | 놓친 줄·그대로인데 짚은 줄의 수만 알려 준다 |
| 예상 | 기준2 칸은 가려 둔다. 한 줄이라도 짚어야 `확인하기`가 열린다 |
| 제약 | 표의 값과 두 기준은 바꿀 수 없다. 짚은 줄은 확인 전까지만 바꿀 수 있다 |
| 되풀이 | `다음 판`마다 표 8줄과 두 기준이 새로 뽑힌다. 기준값과 딱 같은 값(예: 15분)인 줄, 빈칸 줄이 섞인다 |

## 2. 화면 (한 쪽, 두 칸)

| 칸 | 보이는 것 | 학생이 하는 것 | 다음으로 |
|---|---|---|---|
| ① 등교 표 | 기준1·기준2 문장, 8줄 표(번호·방법·시간·횡단보도·기준1·기준2). 기준1 칸은 채워져 있고 기준2 칸은 `?` | 달라질 줄을 누른다(다시 누르면 풀림) | 한 줄 이상 짚으면 `확인하기` |
| ② 막대 차트 | 확인 뒤 기준1·기준2 각각 예·아니요 사람 수 막대, 결과 한 줄 | 결과를 읽는다 | `다음 판` / `다시 하기`(같은 판 짚기부터) |

## 3. 판을 뽑는 법

- 등교 방법: 걸어서(절반쯤)·자전거·자동차·버스.
  - 걸어서 5~25분·횡단보도 0~3 / 자전거 5~15분·0~3 / 자동차 5~20분·0~4 / 버스 10~30분·1~4
- 기준 꼴(지도안의 예 `15분보다 오래 걸리나?`를 따름)
  - 시간: `N분보다 오래 걸리나?` N ∈ 10·15·20
  - 횡단보도: `횡단보도를 N개보다 많이 건너나?` N ∈ 1·2
  - 방법: `걸어서 오나?`
- 기준1·기준2는 서로 다른 문장. 달라지는 줄이 1~6줄인 판만 낸다(아니면 다시 뽑음). 직전 판과 같은 기준 짝이면 다시 뽑는다.
- 셋에 하나쯤 한 줄의 시간이 빈칸(`—`). 시간 기준에서 그 줄은 `못 정함`이다. 못 정함이 낀 줄은 달라진 줄로 세지 않고, 결과 끝에 `빈칸 줄은 어느 묶음에도 넣지 못했어요`를 붙인다(지도안 "어느 묶음에도 맞지 않는 데이터"로 이어짐).

## 4. 결과 문구

- 다 들어맞을 때: `짚은 3줄이 모두 묶음이 달라졌어요`
- 아닐 때: `달라진 줄 4줄 가운데 3줄을 짚었어요 · 놓친 줄 1 · 그대로인 줄 짚음 1` (0인 항목은 뺀다)
- 확인 뒤 달라진 줄은 왼쪽에 강조색 띠와 `달라짐` 글자. 짚었는데 그대로인 줄은 점선 테두리.

## 6. 연습 모드

센서·네트워크를 쓰지 않는다. 해당 없음.

## 7. 만드는 방법

순수 JS, 외부 라이브러리 없음. 표의 줄은 `button`(aria-pressed)로 만든다.

```
ans(c, row) : 값이 빈칸이면 null, 아니면 c.test(row) ? '예' : '아니요'
changed(row): ans(c1,row) 와 ans(c2,row) 가 둘 다 null 이 아니고 서로 다름
```
