# B22 체험 활동 설계 — 날씨 카드로 판단 도우미 시험

2026. 10. 11. 교사가 고친 지도안(검토반영본)과 카드 자료 세트·시험 활동지에 맞춰 다시 쓴다.
9월 27일 판(비·미세먼지·기온 네 줄, 기온 먼저 판)의 뼈대는 살리고, 결론 낱말·미세먼지 등급·카드 값을
지도안 그대로 바꾼다. 옛 설계는 git 기록에 남는다. 사람에게 보이는 이름은 '게임'이 아니라 **체험 활동**이다.

## 0. 지도안의 어느 활동에 붙나

**16차시 전개 · 활동3. 날씨 카드로 시험하고 규칙 순서 바꿔 보기 (18분)** 에 붙는다. 지도안 문구:

> - 날씨 카드 A~E 값을 시험 단추로 넣어 실행 결과 적기
> - 규칙표로 정한 결과와 다르면 블록과 비교해 원인을 적고 고치기
> - 기준 값(28도·27도·33도·32도, 미세먼지 보통·나쁨·매우나쁨)을 넣어 경계에서 맞게 판단하는지 보기
> - 짝과 자리를 바꾸어 기온 규칙 두 줄을 맨 앞으로 옮기기
> - 비 오는 30도 카드(A)를 다시 넣고 결과가 달라진 까닭 쓰기

- **앞**: 시험 활동지 3-①·3-②의 `예상 결론` 칸을 적을 때. 학생은 엔트리 시험 단추(t 키)를 누르기 **전에**
  화면에서 규칙표를 위에서부터 따라가 결론을 먼저 짚어 본다. 실행 결과는 엔트리 도우미로 적는다.
- **뒤**: 3-③ 확인 순서 바꿔 보기를 마친 뒤 `결과가 달라진 까닭`을 쓰기 전 3분. 기온 먼저 판이 섞여 나와
  "카드 A만 결과가 달라진다(비 규칙과 28도 규칙에 모두 해당)"는 유의점을 여러 카드로 다시 겪는다.
- 활동4-③ 한계 카드 F~H(눈·강풍·천둥번개)도 판에 섞여 나온다. 지도안: "눈 오는 날에도 '운동장 수업'이 나와요."
- 대신하지 않는 것: 활동2 엔트리 도우미 만들기, 활동3 시험 단추로 넣기·블록 고치기, 활동4 사례 카드 나누기.
  화면 상시 한 줄 `엔트리 도우미에도 넣어 봐요`.

## 1. 다섯 칸

| 칸 | 이 활동 |
|---|---|
| 목표 | 판마다 나온 날씨 카드에 규칙표가 어떤 결론을 낼지 짚어라 |
| 실패 | 기온 먼저 판·경계 값(28·33도)·매우나쁨에서 다른 줄이 먼저 걸린다 |
| 예상 | 결론을 짚어야 `확인하기`가 풀린다. 확인 전엔 어느 줄이 걸렸는지 안 보인다 |
| 제약 | 조건·결론·확인 순서는 못 고친다. 확인하면 그 판은 끝 |
| 되풀이 | 카드와 확인 순서가 판마다 새로 나온다 |

## 2. 한 문장

판마다 나온 날씨 카드(날씨·미세먼지·최고기온)를 규칙표 순서대로 따라가 결론을 짚고, 확인하면 줄마다
`아니요 → 예`가 차례로 켜지며 어느 줄에서 정해졌는지 보인다.

## 3. 화면 (1화면, 두 구획)

| 구획 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 이번 카드 · 확인 순서 | 카드 이름(`날씨 카드 A`·`기준 값`·`한계 카드 F`·`새 카드`), 날씨·미세먼지·최고기온, 한계 카드는 카드에 적힌 주의 한 줄. 확인 순서(기온 먼저 판이면 `기온 규칙을 맨 앞으로 옮긴 순서` 딱지), 규칙 네 줄 + `어디에도 해당하지 않으면` | 위에서부터 따라간다 |
| 결론 고르기 | 결론 다섯 버튼, `확인하기`·`다시 하기`·`다음 카드`, 결과 한 줄, 상시 한 줄 | 하나를 짚는다(확인 전엔 바꿀 수 있다) |

## 4. 조작과 값

규칙표(지도안 활동1 그대로, 학생이 못 고침)

| 줄 | 조건 | 결론 |
|---|---|---|
| ① | 비가 오면 | 강당 수업 |
| ② | 미세먼지가 나쁨 또는 매우나쁨이면 | 교실 수업 |
| ③ | 최고기온 33도 이상이면 | 실내 수업 |
| ④ | 28도 이상이면 | 그늘에서 짧게 |
| - | 어디에도 해당하지 않으면 | 운동장 수업 |

확인 순서: 기본 ①②③④, 기온 먼저 ③④①②(지도안 "기온 규칙 두 줄을 맨 앞으로").

카드(카드 자료 세트 값 그대로)

| 카드 | 날씨 | 미세먼지 | 최고기온 | 기본 순서 결론 |
|---|---|---|---|---|
| A | 비 | 보통 | 30 | 강당 수업 (기온 먼저면 그늘에서 짧게) |
| B | 맑음 | 나쁨 | 24 | 교실 수업 |
| C | 구름많음 | 좋음 | 34 | 실내 수업 |
| D | 맑음 | 보통 | 29 | 그늘에서 짧게 |
| E | 구름조금 | 좋음 | 21 | 운동장 수업 |
| 기준 값 | 맑음 | 좋음 | 28·27·33·32 | 활동지 3-② |
| 기준 값 | 맑음 | 보통·나쁨·매우나쁨 | 20 | 활동지 3-② |
| F | 눈 | 좋음 | 1 | 운동장 수업 · `눈이 펑펑 내려요` |
| G | 맑음 | 좋음 | 18 | 운동장 수업 · `강풍 · 바람이 초속 14m로 세게 불어요` |
| H | 흐림 | 보통 | 26 | 운동장 수업 · `천둥·번개가 쳐요 (비는 아직 안 와요)` |

판 뽑기:
- 1~5판: 날씨 카드 A~E를 섞은 차례로, 모두 기본 순서(시험 활동지 3-①과 같은 다섯 장).
- 6판: 카드 A, 기온 먼저(3-③).
- 7판부터: 기준 값 30% · 한계 카드 20% · A~E 25% · 새 카드 25%(최고기온 15~37, 비 30%, 미세먼지 좋음·보통·나쁨·매우나쁨).
  확인 순서는 1/3이 기온 먼저. 직전 판과 같은 카드·순서면 다시 뽑는다.

확인:
- 줄마다 0.25초 간격으로 `아니요`를 켜 내려가다 걸린 줄에 `예`, 그 줄을 강조.
- 결과 한 줄(얼마나 떨어졌는지만):
  - 같으면 `짚은 대로 ○번째 줄에서 정해졌어요`.
  - 다르면 `○번째 줄에서 정해졌어요 · 짚은 결론은 △번째 줄이에요`. 맞았어요·틀렸어요 없음.
- 한계 카드면 결과 아래 `규칙표에 없는 날씨예요 · 알맞은 결론일까요?` (활동지 4-③ 물음 그대로).
- `다시 하기`: 확인 전 짚은 것만 지운다. `다음 카드`: 새 판.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 |
|---|---|
| 제목 | 날씨 카드로 판단 도우미 시험 |
| 부제 | 규칙표를 위에서부터 따라가 결론을 짚어요 |
| 소제목 | 이번 카드 · 확인 순서 / 결론 고르기 |
| 순서 딱지 | 기온 규칙을 맨 앞으로 옮긴 순서 |
| 결론 | 강당 수업 / 교실 수업 / 실내 수업 / 그늘에서 짧게 / 운동장 수업 |
| 안내 | 결론을 하나 짚어요 / 확인하기를 눌러요 |
| 상시 | 엔트리 도우미에도 넣어 봐요 |
| 버튼 | 확인하기 / 다시 하기 / 다음 카드 |

## 6. 연습 모드

해당 없음. 외부 라이브러리·카메라·마이크·센서·네트워크를 쓰지 않는다. 날씨 블록을 흉내 내지 않는다.

## 7. 만드는 방법

```
RULES = [비→강당, 미세먼지 나쁨|매우나쁨→교실, 33이상→실내, 28이상→그늘에서 짧게]
BASE=[0,1,2,3] TEMP_FIRST=[2,3,0,1]
fire(order, card): 위에서부터 처음 걸린 줄의 자리(없으면 마지막 '어디에도')
deck: A~E 섞기 → (A, TEMP_FIRST) → 무작위
confirm: 줄마다 setTimeout 으로 아니요/예 표시, 끝에 결과 한 줄
```
