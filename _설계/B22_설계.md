# B22 체험 설계 — 온도를 움직이면

## 0. 만들까 말까

**만든다.**

- 온도를 -5도부터 40도까지 0.5도씩 훑으면서 **어느 구간에서 어느 규칙이 걸리는지**를 띠 하나로 볼 수 있다. 기기로는 값을 하나씩 넣어 봐야 하고, 경계값을 만들려고 기기를 데우거나 식히는 것은 과정안이 막아 둔 일이다. 온도를 손으로 옮기는 것은 웹이 아니면 안전하게 못 한다.
- 슬라이더 하나를 움직이면 걸린 규칙과 알릴 문장이 즉시 바뀐다. 브라우저만으로 되고 5분 안에 끝난다.

**되돌아본 점.** 활동2의 프로그램 만들기와 활동4의 온도 재기는 실물이 본론이다. 이 웹은 블록을 대신 놓아 주지 않고, 온도계를 흉내 내지도 않는다. 규칙표를 **읽는 순서**와 **값의 구간**만 다룬다.

---

## 1. 과정안 어디에 붙는가

- 블록 B22, 15~16차시. 두 자리에 쓴다.
  - 활동1 뒤: 종이에 다섯 가지 기온의 예상 결과를 적은 **다음**, 기기를 켜기 전에 맞춰 본다.
  - 활동5 뒤: 확인 순서를 바꾼 결과를 기기에서 확인한 **다음**, 구간 띠로 견준다.
- 활동2·3·4를 대신하지 않는다. 잰 온도는 학교 온도계로 직접 읽는다.
- 교실에서 한 번에 3~5분.

---

## 2. 한 문장

넣는 **온도**를 옮기면 세 규칙 가운데 **먼저 걸린 규칙 하나**와 그 문장이 바뀌고, 확인 순서를 바꾸면 **어느 구간의 답이 달라지는지**가 띠에 보인다.

## 3. 화면 (3화면, 한 쪽에 세로로)

| 화면 | 보이는 것 | 학생이 하는 것 | 넘어가는 조건 |
|---|---|---|---|
| ① 넣어 보는 온도 | 큰 숫자, 알릴 문장, 슬라이더 | 슬라이더를 움직인다 | 움직이는 대로 ②③이 바뀐다 |
| ② 확인 순서 | 규칙 세 줄(번호·조건·문장), 걸린 줄에 체크 | 순서 바꾸기를 누른다 | 다시 하기로 처음으로 |
| ③ 온도별 결과 | -5~40도 띠, 구간마다 규칙 번호, 지금 온도 표시 | 달라진 구간을 본다 | — |

## 4. 조작과 값

- 조절하는 값: **온도** 하나. 범위 -5 ~ 40도, 0.5도씩, 기본 20도.
- 보조 조작: `순서 바꾸기`(첫째 줄과 둘째 줄의 확인 순서만 맞바꾼다), `다시 하기`.
- 규칙표는 과정안 활동1 그대로다. **기준값과 문장은 학생이 못 고친다.**

| 확인 순서 | 조건 | 알릴 말 |
|---|---|---|
| ① | 30도 이상 | 그늘에서 쉬면서 활동하세요 |
| ② | 25도 이상 | 물통을 챙기세요 |
| ③ | 5도 이하 | 장갑을 챙기세요 |

- 반영: 위에서부터 확인해 처음 걸린 규칙 하나의 문장만 알린다. 어느 규칙에도 안 걸리면 `해당하는 규칙 없음`.
- **기본값을 20도로 둔 까닭**: 5도 초과 25도 미만은 어느 규칙에도 안 걸리는 구간이다. 열자마자 미해당 구간에 서 있고, 띠가 그 까닭을 함께 보여 준다. 활동1의 "어느 규칙에도 해당하지 않을 때"를 첫 화면에서 만난다.

**순서를 바꾸면 무엇이 달라지나.** 25도 이상을 먼저 확인하면 30도 이상 구간 전체가 그늘 문장에서 물통 문장으로 바뀐다. 25도 미만 구간은 그대로다. 과정안 다섯 값 가운데 32도만 달라지는 까닭이 띠에서 구간으로 보인다. 25도는 `25 이상`에 **들어간다**는 것도 슬라이더를 24.5 → 25로 옮겨 확인한다.

| 자리 | 문구 | 글자 수 |
|---|---|---|
| 제목 | 온도를 움직이면 | 8 |
| 부제 | 먼저 걸린 규칙 하나만 알려요 | 15 |

| 안내 | 잰 값은 온도계로 직접 읽어요 | 14 |
| 버튼 | 순서 바꾸기 / 다시 하기 | 6 / 5 |

`잰 값은 온도계로 직접 읽어요`는 늘 보이게 둔다. 이 화면이 온도를 재 주는 것이 아니라는 것을 한 줄로 못 박는다.

## 6. 연습 모드

**해당 없음.** 외부 라이브러리·CDN·카메라·마이크·네트워크·센서를 쓰지 않는다. 인터넷이 끊겨도 같다. 기기가 없는 학급이 이 화면으로 활동1의 예상을 맞춰 볼 수는 있으나, 활동2의 프로그램 만들기를 대신하지는 않는다.

## 7. 만드는 방법

- 순수 JS. 외부 라이브러리 **없음**. 구간 띠는 인라인 SVG(미해당 구간은 빗금 `pattern`).
- 포인트색 한 가지(앰버)만 쓰고, 규칙 세 줄은 진하기 세 단계와 ①②③ 번호로 가른다. 색만으로 가르지 않는다.

```
RULES = [ {30 이상, 그늘...}, {25 이상, 물통...}, {5 이하, 장갑...} ]
order = [0,1,2]
fire(order, t): for i in order: if RULES[i].f(t): return i ; return -1
띠: t를 -5부터 40까지 0.5씩 훑어 fire 값이 바뀌는 자리에서 구간을 끊는다
순서 바꾸기: order[0] <-> order[1]
```

### 이 차시에만 해당하는 항목

### 남은 것

- 미해당 구간의 알릴 문장은 비워 두었다(`해당하는 규칙 없음`). 활동1에서 학생이 그 문장을 직접 정하게 되어 있어서, 웹이 먼저 적으면 답을 주는 셈이 된다.
- 띠의 세 구간은 같은 앰버의 진하기 세 단계로 갈랐다. 진하기 차이가 흐린 화면에서는 덜 또렷할 수 있어 구간마다 ①②③ 번호를 함께 적어 두었다.
