# B23 체험 설계 — 기록 간격 견주기 활동

작성: 2026. 10. 11. (검토반영본 지도안 기준으로 다시 씀. 게임이 아니라 **체험 활동**으로 만든다)

## 0. 지도안의 어느 활동을 웹으로 옮겼나

**만든다.** 18차시 **활동3. 센서 기록표로 기록 간격 바꾸어 보기** 가운데 실측이 끝난 **뒤** 두 줄을 웹으로 옮긴다.

> - 같은 길을 30초마다 적은 기록과 나란히 막대로 그리기
> - 간격이 넓을 때 놓친 변화를 찾아 표시하기

- 붙는 자리: 같은 활동의 "나머지는 10초마다 A를 눌러 나온 값을 기록표에 적기" **뒤**. 학생이 기록표에 적은 10초 값을 옮겨 적으면, 웹이 같은 기록에서 30초마다 고른 값을 나란히 막대로 세운다. 그 전에 학생은 **30초 기록이 놓칠 자리를 먼저 짚는다**(예상).
- 웹으로 옮기지 않은 것: 활동1 온도계 관찰, 활동2 CreateAI 그래프, 활동3의 **빛 세기 측정과 걷기** 자체, 활동4 데이터 카드 나누기. 모두 실물이 본론이다. 화면의 막대는 학생이 직접 잰 값이어야 하며, 값이 없는 학급만 `연습 기록`(그 자리에서 뽑은 값, 화면에 `연습 기록` 표시)을 쓴다.
- 지도안과 다른 점 하나: 지도안은 30초 기록을 "같은 길을" 다시 걸어 적을 수도 있게 읽힌다. 웹은 10초 기록에서 0·30·60초 값을 골라 30초 기록으로 삼는다. 같은 길을 한 번만 걸은 모둠도 견줄 수 있게 하려는 것이며, 화면에 `10초 기록에서 30초마다 고른 값`이라고 밝힌다. 두 번 걸은 모둠은 자기 30초 기록표와 화면을 견주면 된다.

## 1. 과정안 어디에 붙는가

- B23, 6학년 18차시, 활동3(20분) 가운데 기록이 끝난 뒤 5~7분.
- 이어서 정리 활동 "기록 간격을 넓혔을 때 놓친 것을 자기 기록에서 하나 들어 쓰기"에 화면 끝의 `활동지에 옮겨 적을 것` 한 줄을 그대로 쓴다.

## 2. 한 문장

내 10초 기록을 옮겨 적고, 30초로 적었다면 어디를 놓칠지 먼저 짚은 뒤, 두 막대를 나란히 놓고 놓친 변화를 확인한다.

## 3. 화면 (한 쪽, 세 칸을 세로로)

| 칸 | 보이는 것 | 학생이 하는 것 | 다음으로 |
|---|---|---|---|
| ① 10초 기록 옮겨 적기 | 0초·10초·20초… 칸(처음 7칸), 칸마다 숫자 입력, 바로 아래 10초 막대 | 기록표의 빛 세기 값(0~255)을 적는다. `칸 더하기`·`칸 빼기`로 4~13칸 | 모든 칸이 차면 ②가 열린다 |
| ② 놓칠 자리 짚기 | 10초 막대. 0·30·60·90·120초 막대에는 `30초` 표시가 붙고 누를 수 없다 | 30초 기록이 놓칠 것 같은 막대 하나를 누른다. 확인 전엔 다른 막대로 바꿀 수 있다 | 짚어야 `확인하기`가 열린다 |
| ③ 나란히 막대 | 10초 막대 아래 30초 막대(같은 시간 줄에), 놓친 정도가 가장 큰 자리에 테두리 | 결과 한 줄을 읽고, `활동지에 옮겨 적을 것`을 활동지로 옮긴다 | `다시 하기` |

## 4. 조작과 값

- 값: 칸마다 빛 세기 0~255(마이크로비트 빛 세기 범위). 숫자가 아니거나 범위를 벗어나면 그 칸은 빈 칸으로 본다.
- 30초 값: 10초 기록의 0번·3번·6번… 칸.
- 놓친 정도: 30초 기록에 없는 칸마다, 양옆 30초 값을 곧게 이은 선과 그 칸 값의 차이(절댓값). 마지막 30초 값 뒤의 칸은 마지막 30초 값과의 차이.
- 가장 크게 놓친 자리 = 놓친 정도가 가장 큰 칸(같으면 앞 칸).
- 결과 문구
  - 짚은 칸이 그 자리: `짚은 40초에서 가장 크게 놓쳤어요 · 차이 37`
  - 아니면: `가장 크게 놓친 곳은 짚은 곳에서 2칸 옆 60초예요` + `짚은 곳의 차이 12`
  - 모든 차이가 3 이하: `30초 기록도 거의 같은 모양이에요`
- 옮겨 적을 것: `10초 기록 7개 · 30초 기록 3개 / 놓친 변화: 40초(값 120, 30초로는 83쯤)`

| 자리 | 문구 |

| 제목 | 기록 간격 견주기 활동 (11자) |
| 부제 | 10초 기록을 옮겨 30초 기록과 나란히 그려요 (23자) |

## 6. 연습 모드

센서·네트워크를 쓰지 않는다. 기록이 없는 학급은 `연습 기록`을 누르면 창가(밝음)에서 안쪽(어두움)으로 내려가며 중간에 한 번 출렁이는 값을 그 자리에서 뽑아 채운다. 화면에 `연습 기록`을 띄운다.

## 7. 만드는 방법

순수 JS, 외부 라이브러리 없음. 막대는 `button`(②에서 누르기)과 `div` 높이로 그린다.

```
vals[i] (i=0..n-1, 10초 간격)
is30(i) = i % 3 == 0
miss(i) = is30(i) ? 0 : |vals[i] - lerp(vals[a], vals[b], (i-a)/(b-a))|   a=i-i%3, b=a+3 (b>=n 이면 vals[a])
```

## 8. 난이도 점검

| 재는 것 | 상한 | 실제 |
|---|---|---|
| 첫 조작까지 | 30초 | 첫 칸 입력이 화면 위쪽 |

| 한 칸의 조작 요소 | 5 | ① 입력+3단추 ② 막대 누르기+확인 ③ 다시 하기 |
| 전체 시간 | 5~10분 | 5~7분 |

## 9. 디버깅

- 칸 4개(30초 값 2개)·13개에서 막대가 깨지지 않는다.
- 값을 고치면 ②의 짚기와 ③의 결과가 지워진다(옛 결과가 남지 않는다).
- 폭 390에서 13칸 막대가 넘치지 않는다.
- 검사 결과는 끝 절에 적는다.
