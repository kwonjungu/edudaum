## 0. 만들까 말까

**만든다. 다만 온도계 관찰과 CreateAI 그래프 보기는 웹으로 옮기지 않는다.**

- 활동2에서 학생은 녹화한 x 그래프를 다섯 지점(도전 열 지점)으로 끊어 막대로 그린다. 한 번 그리는 데 몇 분이 걸려 "몇 지점이면 움직임을 알아볼 수 있나"를 여러 곡선으로 견줄 틈이 없다. 지점 수를 바꿔 막대를 다시 세우는 일은 웹이 몇 초면 한다.
- 버튼 하나를 누르면 막대와 적을 숫자 개수가 즉시 바뀐다. 브라우저만으로 되고 5분 안에 끝난다.

**웹으로 옮기지 않은 것.** 활동1의 눈금·숫자 온도계 관찰, 활동2의 마이크로비트·CreateAI 그래프 살피기, 활동3의 빛 세기 기록은 **실물이 본론**이다. 이 웹의 곡선은 센서가 잰 값이 아니라 판이 뽑은 모양이다.

## 2. 한 문장

**지점 수**를 바꾸면 끊어 적은 막대가 손 곡선에 얼마나 가까워지는지, 그리고 그 대신 **적을 숫자가 몇 개로 늘어나는지**가 함께 보인다.

## 3. 게임 (2화면, 한 쪽에 세로로)

**해내야 할 것**: 손 곡선을 2초만 보고, 몇 지점으로 끊어야 그 움직임을 알아볼 수 있는지 직접 겪어 짚어라. 판마다 다섯 움직임(한 번 들기·두 번 들기·천천히 올리기·들었다 멈추기·빠르게 흔들기) 가운데 하나가 뽑힌다. 움직임 이름은 화면에 적지 않는다.

| 화면 | 보이는 것 | 학생이 하는 것 | 제약 |
|---|---|---|---|
| ① 움직임 그래프 | 위 손 곡선(2초 뒤 가려짐), 아래 끊어 적은 막대 | 2초 동안 눈에 담는다 | 가려진 뒤엔 다시 못 본다(확인 전까지) |
| ② 지점 수 고르기 | 3·5·10·20·40지점 버튼, `이제 알겠어요` | 지점 수를 눌러 막대를 본다 | 확인 전엔 자유롭게 바꿔 봄, 누르는 순간이 답 |

`이제 알겠어요`를 누르면 손 곡선이 다시 나오고 막대 위에도 겹쳐진다(과정안 "손 곡선과 겹쳐 보기").

---

## 4. 조작과 값

- 조절하는 값: **지점 수** 하나. 3 / 5 / 10 / 20 / 40.
- 판마다: 다섯 곡선 가운데 하나를 무작위로 뽑는다. 직전 판과 같으면 다시 뽑는다.
- 반영: 곡선을 같은 간격 k개 지점에서 읽어 막대로 세운다. 10지점 이하면 막대 위에 높이 숫자(0~99)를 적는다. 빠르게 흔들기는 5·10지점에서 흔들림이 사라지거나 다른 모양으로 보인다 — 간격이 넓으면 놓치는 변화(활동3으로 이어짐).
- `다시 하기`는 **같은 곡선**으로 2초 보여 주기부터 다시 한다. `다음 판`은 곡선을 새로 뽑는다.

## 7. 만드는 방법

- 순수 JS + 인라인 SVG. 외부 라이브러리 **없음**. 곡선은 수식이다.

```
곡선 f(t), t∈[0,1] : sin²(πt) / sin²(2πt) / smoothstep 오르막 / 올렸다 멈춤 / 0.5+0.42·sin(2π·6.5t)
bars(f,k)          : i=0..k-1, t=(i+.5)/k 에서 f(t) 높이의 막대, k≤10이면 round(f·99) 글자
확인 뒤            : 막대 위에 f 곡선을 겹쳐 그린다
```
