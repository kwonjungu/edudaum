# B08 체험 설계 — 아홉과 열

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 코드 만들기와 실물 버튼 시험(활동2·3)은 그대로 한다.

- **웹이 아니면 못 하는가.** 활동4는 `기준값만 10에서 5로 바꾸고 예상을 먼저 적기`를 시킨다.
  기기에서 기준값을 바꾸려면 블록을 고쳐 다시 전송해야 하고, 한 번에 몇 분이 걸려
  한두 번밖에 못 해 본다. 화면에서는 기준값을 밀면서 **경계가 어디로 옮겨 가는지**를 본다.
- **값을 바꾸면 결과가 바뀌는가.** 기준값을 바꾸면 갈라지는 자리가 옮겨 간다.

**여전히 만들지 않는 것.** 블록 놓기, 전송, 뼈대 파일, 오류 예제 고치기.
화면은 버튼 두 개와 기준값만 다룬다. `마이크로비트로 다시 시험해요`를 상시로 둔다.

## 1. 과정안 어디에 붙는가

- 블록 B08, 15~16차시. **활동4 넷째 줄의 예상 자리**에 3~4분.
  `기준값만 10에서 5로 바꾸고 예상을 먼저 적기` — 종이에 예상을 적은 **다음** 맞춰 본다.
- 활동3의 아홉 번·열 번 시험은 실물 버튼으로 이미 한 뒤다. 그것을 대신하지 않는다.

## 2. 한 문장

**기준값**을 바꾸면 하트와 가위표가 갈라지는 자리가 옮겨 간다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 | 5×5 LED, 지금 값(누른 횟수) | 왼쪽을 눌러 값을 올린다 |
| 가운데 | 0~15 띠. 칸마다 하트/가위표, 지금 값 표시 | 갈라지는 자리를 본다 |
| 아래 | 기준값 막대, `왼쪽`, `오른쪽`, `다시 시작` | 기준값을 민다 |

- 띠는 0부터 15까지 열여섯 칸이다. 기준값을 밀면 칸의 모양이 한꺼번에 바뀐다.
- LED는 `오른쪽`을 눌렀을 때만 바뀐다. 조건은 그때 한 번 따진다(과정안 그대로).

## 4. 조작과 값

- 조절하는 값: **기준값** 하나. 1~15, 처음은 **10**(과정안 활동2 그대로).
- 보조 조작: `왼쪽`(값 +1, 상한 15), `오른쪽`(지금 값으로 판단해 LED를 바꾼다),
  `다시 시작`(값을 0으로 — 과정안 뒤쪽 다시 시작 단추와 같은 일).
- 규칙은 과정안 활동2 그대로다. 학생이 못 고친다.
  `값이 기준값 이상이면 하트` / `아니면 가위표`

**열어 두는 딴짓.** `오른쪽`을 누르지 않고 `왼쪽`만 스무 번 눌러 볼 수 있다.
LED가 그대로인 것을 보는 것이 활동1 마지막 줄(`블록을 바꾸지 않았는데 그림이 달라진 까닭`)로
이어진다. 막지 않는다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 | 글자 수 |
|---|---|---|
| 제목 | 아홉과 열 | 5 |
| 부제 | 한 번 더 누르면 달라져요 | 13 |
| 값 이름 | 누른 횟수 | 5 |
| 막대 이름 | 기준값 | 3 |
| 버튼 | 왼쪽 / 오른쪽 / 다시 시작 | 2 / 3 / 5 |
| 관찰 물음(상시) | 갈라지는 자리가 어디인가요 | 14 |
| 되짚기(상시) | 마이크로비트로 다시 시험해요 | 15 |

한 화면 약 130자.

**쓰지 않는 말**: 조건, 참, 거짓, 분기, 프로그램, 코드.

## 6. 연습 모드

**해당 없음.** 외부 호출·센서·카메라를 쓰지 않는다.

## 7. 만드는 방법

```
값 = 0, 기준값 = 10, 보인그림 = null

왼쪽(): 값 = min(값+1, 15); 숫자와 띠의 지금 자리만 다시 그린다
오른쪽(): 보인그림 = (값 >= 기준값) ? '하트' : '가위표'; LED만 다시 그린다
다시시작(): 값 = 0; 보인그림 = null; 숫자·LED·띠 자리를 다시 그린다
기준값바꾸기(v): 기준값 = v; 띠 열여섯 칸의 모양만 다시 그린다   // LED는 그대로
```

- **기준값을 밀어도 LED는 바뀌지 않는다.** `오른쪽`을 눌러야 바뀐다. 이것이 이 차시의 규칙이다.
- 띠 칸의 하트·가위표는 인라인 SVG로 그린다. 색으로만 구별하지 않는다.
- LED 스물다섯 칸은 SVG `<rect>` 25개.
- 포인트색 한 가지: 자주 `#DB2777`.

## 9. 디버깅

- [ ] 기준값 10에서 아홉 번 누르고 `오른쪽`을 누르면 가위표가 나온다.
- [ ] 되돌리지 않고 한 번 더 눌러 열 번에서 `오른쪽`을 누르면 하트가 나온다.
- [ ] 기준값을 5로 밀면 띠의 갈라지는 자리가 옮겨 간다.
- [ ] 기준값을 밀어도 LED는 그대로다.
- [ ] `왼쪽`만 스무 번 눌러도 LED가 바뀌지 않는다.
- [ ] 값이 15에서 멈춘다.
- [ ] `다시 시작`이 값과 LED를 함께 되돌린다.
