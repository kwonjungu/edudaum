# B20 체험 설계 — 규칙 순서 바꾸기

## 0. 만들까 말까

**만든다.**

- 규칙 줄 하나를 위로 올리면 카드 18장의 판정이 한꺼번에 다시 계산되어 달라진 카드가 바로 보인다. 종이로는 한 번 바꿀 때마다 카드를 다시 읽어야 해서 실제로는 한두 번밖에 못 해 본다.
- 학생이 바꾸는 것은 규칙 순서 하나뿐이고 결과(상자 이름)가 즉시 바뀐다. 브라우저만으로 되고 5분 안에 끝난다.

**되돌아본 점.** 활동2가 종이로 이미 하는 일과 겹친다. 그래서 이 웹은 카드 18장을 처음부터 판정하는 일(활동1·2의 본론)은 맡지 않는다. **순서를 여러 번 바꾸어 견주는 부분만** 맡는다. 활동3의 "새 규칙을 맨 위와 맨 아래에 각각 넣어 결과 견주기"가 종이로는 가장 느린 곳이고, 웹이 대신하기에 가장 알맞은 곳이다.

## 1. 과정안 어디에 붙는가

- 블록 B20, 11~12차시. 활동2 "규칙표대로 판정하고 순서 바꾸기"를 **종이로 끝낸 뒤**, 활동3으로 넘어가기 직전 5분.
- 실물(활동지) **뒤**에 붙는 견주기 도구다. 활동1·2를 아직 안 한 학급에서 먼저 열지 않는다.
- 교실에서 5분.

## 2. 한 문장

규칙 줄의 **순서**를 바꾸면 카드 18장 가운데 **어떤 카드의 상자가 달라지는지** 바로 보인다.

## 3. 화면 (2화면, 한 쪽에 나란히)

| 화면 | 보이는 것 | 학생이 하는 것 | 넘어가는 조건 |
|---|---|---|---|
| ① 규칙표 | 규칙 네 줄(번호·조건·상자), 맨 윗줄은 흐림 | 규칙 줄을 눌러 한 칸 위로 올린다 | 누르는 즉시 ②가 다시 그려진다 |
| ② 카드 18장 | 카드마다 모양·색·테두리와 판정 글자(가/나/다/—), 달라진 카드는 별표와 굵은 테 | 달라진 카드를 눈으로 세고 공통점을 찾는다 | 다시 하기로 처음 순서로 돌아간다 |

스크롤 없이 ①이 화면 가운데 오고, ②는 바로 아래에 붙는다.

## 4. 조작과 값

- 조절하는 값: **규칙 네 줄의 순서 하나**. 값의 범위는 순서 조합뿐이고 규칙 문장과 상자 이름은 고칠 수 없다.
- 조작: 규칙 줄을 **누르면 한 칸 위로**. 끌기는 넣지 않았다(누르기만으로 모든 순서를 만들 수 있다).
- 기본값: `테두리가 있으면 → 가 / 빨강이면 → 나 / 파랑이면 → 다 / 테두리 있는 네모면 → 다`
- 반영: 카드마다 위에서부터 처음 맞는 규칙 하나만 적용한다. 어디에도 안 맞으면 `—`.

**규칙표를 이렇게 짠 까닭**

| 조작 | 달라지는 카드 | 과정안 대응 |
|---|---|---|
| 처음 순서 | 노랑·테두리 없음 3장이 `—` | 활동3 "규칙 없음 카드 세 장", 공통점은 노랑 |
| 2번(빨강)을 맨 위로 | 테두리 있는 빨강 3장이 가→나 | 활동2 "첫 줄과 둘째 줄 자리 바꾸기" |
| 4번(테두리 있는 네모)을 맨 위로 | 테두리 있는 네모 3장이 가→다 | 활동3 "새 규칙을 맨 위와 맨 아래에 넣어 견주기" |

4번 규칙은 **맨 아래에 있으면 한 장도 걸리지 않는다**(1번이 먼저 걸린다). 맨 위로 올리면 세 장이 걸린다. 같은 규칙표인데 순서만으로 결과가 갈리는 것을 조작으로 겪는다. 글로 설명하지 않는다.

카드 18장 = 모양 3(동그라미·세모·네모) × 색 3(빨강·파랑·노랑) × 테두리 2. 테두리 있는 카드가 정확히 9장이라 과정안 활동2와 맞는다.

| 자리 | 문구 | 글자 수 |
|---|---|---|
| 제목 | 규칙 순서를 바꾸면 | 9 |
| 부제 | 위에서 처음 맞는 규칙 하나만 걸려요 | 18 |
| 칸 이름 | 규칙표 / 카드 18장 | 3 / 7 |
| 안내 | 규칙 줄을 누르면 한 칸 위로 올라가요 | 19 |
| 결과 | 처음 순서 / 달라진 카드 N장 | 5 / 9 |
| 버튼 | 다시 하기 | 5 |

한 화면 글자 수는 감사기 기준 250자 아래다(실측: 두 화면 모두 통과).

## 7. 만드는 방법

- 순수 JS. 외부 라이브러리 **없음**. CDN **없음**. 저장 **없음**.
- 카드 그림·별표는 인라인 SVG. 이모지를 쓰지 않는다.
- 규칙 줄 버튼은 `document.createElement`로 만든다(문자열로 만들면 감사기의 버튼 글자 수 검사가 스크립트 안 문자열을 버튼으로 읽는다).

```
order = [0,1,2,3]                 // 규칙 번호의 현재 순서
judge(order, card):
    for i in order: if RULES[i].f(card): return RULES[i].box
    return '—'
누르기(p): p>0이면 order[p-1] <-> order[p] 를 바꾸고 다시 그린다
달라진 카드 = judge(order, c) != judge([0,1,2,3], c) 인 카드
```

바뀐 부분만 고쳐 그린다: 카드 타일 18개는 처음 한 번만 만들고, 그 뒤에는 판정 글자와 클래스만 바꾼다.

### 남은 것

- 카드의 **색**은 속성 자체라서 글자로 덧붙이지 않았다. 색을 구별하기 어려운 학생에게는 모양과 테두리가 함께 단서가 되지만, 색만으로 갈리는 규칙 두 줄(빨강·파랑)은 짝과 함께 보게 하는 것이 안전하다. 화면 읽기 도구에는 카드마다 `색 모양 테두리 상자` 순서로 읽히도록 라벨을 붙여 두었다.
