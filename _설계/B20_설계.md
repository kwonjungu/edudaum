# B20 체험 설계 — 규칙 순서 바꾸기

## 0. 만들까 말까

**만든다.**

- 규칙 줄 하나를 위로 올리면 카드 18장의 판정이 한꺼번에 다시 계산되어 달라진 카드가 바로 보인다. 종이로는 한 번 바꿀 때마다 카드를 다시 읽어야 해서 실제로는 한두 번밖에 못 해 본다.
- 학생이 바꾸는 것은 규칙 순서 하나뿐이고 결과(상자 이름)가 즉시 바뀐다. 브라우저만으로 되고 5분 안에 끝난다.

**되돌아본 점.** 활동2가 종이로 이미 하는 일과 겹친다. 그래서 이 웹은 카드 18장을 처음부터 판정하는 일(활동1·2의 본론)은 맡지 않는다. **순서를 여러 번 바꾸어 견주는 부분만** 맡는다. 활동3의 "새 규칙을 맨 위와 맨 아래에 각각 넣어 결과 견주기"가 종이로는 가장 느린 곳이고, 웹이 대신하기에 가장 알맞은 곳이다.

## 1. 과정안 어디에 붙는가

- 블록 B20, 11~12차시. 활동2 "규칙표대로 판정하고 순서 바꾸기"를 **종이로 끝낸 뒤**, 활동3으로 넘어가기 직전 5분.
- 실물(활동지) **뒤**에 붙는 견주기 도구다. 활동1·2를 아직 안 한 학급에서 먼저 열지 않는다.
- 교실에서 5분.

## 2. 한 문장

규칙 줄의 **순서**를 바꾸면 카드 18장 가운데 **어떤 카드의 상자가 달라지는지** 바로 보인다.

## 3. 화면 (2026. 9. 17. 게임으로 다시 짠다 — 몇 장이 옮겨갈까)

순서를 눌러 바꿔 보는 관찰 도구였던 것을, **바뀔 두 줄을 미리 보여 주고 몇 장이
옮겨갈지 먼저 짚게 하는** 구조로 바꾼다. 규칙과 카드는 판마다 새로 뽑는다.

| 화면 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| ① 규칙표 | 규칙 네 줄(번호·조건·상자), 이웃한 두 줄에 표시 | 옮겨갈 카드 수(0~6)를 짚는다 |
| ② 카드 18장 | 카드마다 모양·색·테두리와 판정 글자, `순서 바꾸기` 뒤 달라진 카드는 별표와 굵은 테 | `순서 바꾸기`(짚어야 풀림, 한 번뿐) 뒤 결과 문구를 읽는다 |

스크롤 없이 ①이 화면 위에 오고, ②는 바로 아래에 붙는다(카드 18장 전체를 보려면 스크롤할 수 있다).

## 4. 조작과 값

- 조절하는 값: **옮겨갈 카드 수 0~6 가운데 하나**를 짚는다. 짚어야 `순서 바꾸기`가 풀리고,
  한 번 누르면 그 판에서 더는 못 무른다.
- 규칙 네 줄은 판마다 그 자리에서 짠다: 테두리 규칙 하나(고정), 서로 겹치지 않는 색 규칙
  둘(빨강/파랑/노랑 가운데 무작위로 둘), 테두리 있는 어떤 모양이면 규칙 하나(모양도 무작위).
  네 줄의 순서와, **이번 판에 자리를 바꿀 이웃한 두 줄**도 판마다 새로 뽑는다.
- **이웃한 두 줄만 바꾼다.** 사이에 낀 줄이 있으면 옮겨가는 장수를 가늠하기 어려울 만큼
  커진다. 이웃이면 두 규칙 자신의 겹침만으로 정해져 늘 0~3장 안에 든다.
- 두 줄이 서로 겹칠 수 없는 색 규칙 쌍(예: 빨강↔파랑)일 때는 순서를 바꿔도 **한 장도
  옮겨가지 않는다** — 이런 판을 열에 서넛쯤 섞는다. 겹치지 않는 규칙이면 순서가 상관없다는 것을
  조작으로 겪는다.
- 반영: 카드마다 위에서부터 처음 맞는 규칙 하나만 적용한다. 어디에도 안 맞으면 `—`.
- 확인 결과: 실제로 옮겨간 장수와 짚은 수를 견주어 `짚은 대로 N장 옮겨갔어요` /
  `N장 더 옮겨갔어요` / `N장 덜 옮겨갔어요`.

카드 18장 = 모양 3(동그라미·세모·네모) × 색 3(빨강·파랑·노랑) × 테두리 2. 테두리 있는 카드가
정확히 9장이라 과정안 활동2와 맞는다.

## 7. 만드는 방법

- 순수 JS. 외부 라이브러리 **없음**. CDN **없음**. 저장 **없음**.
- 카드 그림·별표는 인라인 SVG. 이모지를 쓰지 않는다.
- 규칙 줄 버튼은 `document.createElement`로 만든다(문자열로 만들면 감사기의 버튼 글자 수 검사가 스크립트 안 문자열을 버튼으로 읽는다).

```
order = [0,1,2,3]                 // 규칙 번호의 현재 순서
judge(order, card):
    for i in order: if RULES[i].f(card): return RULES[i].box
    return '—'
누르기(p): p>0이면 order[p-1] <-> order[p] 를 바꾸고 다시 그린다
달라진 카드 = judge(order, c) != judge([0,1,2,3], c) 인 카드
```

바뀐 부분만 고쳐 그린다: 카드 타일 18개는 처음 한 번만 만들고, 그 뒤에는 판정 글자와 클래스만 바꾼다.
