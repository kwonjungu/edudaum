# B04 체험 활동 설계 — 로봇 셰프 레시피 고치기

2026. 10. 11. 지도안(검토반영본)에 맞춰 새로 짰다. 앞의 「적힌 대로만 / 로봇이 막힐 줄 짚기」 설계는 맨 끝 절에 줄여 남긴다.
화면과 문서에서 사람에게 보이는 이름은 '게임'이 아니라 **체험 활동**이다(사용자 지시, 2026. 10. 11.).
짜임은 `_게임설계.md`의 `판이 나온다 → 짚는다 → 확인한다`를 그대로 따른다.

## 0. 만들까 말까 · 지도안 어디에 붙나

**만든다.**

지도안 8차시 전개 「활동2. 4컷 로봇 셰프 레시피 (33분)」의 이 줄들 **앞**에 5분 연습으로 붙는다.

> - 완성한 A4를 옆 모둠과 바꾸고, 그림만 보고 어떤 순서인지 이야기해 보기 (약 10분)
> - 이해하기 어려운 칸이 있으면 가장 헷갈리는 한 곳에 동그라미 표시하기
> - 다시 돌려받은 모둠은 표시된 부분을 더 알아보기 쉽게 고치기 (약 6분)

빈 A4 4칸 레시피를 그리기(약 12분) 전, 또는 옆 모둠과 바꾸기 직전에 한 번 해 본다.
화면은 **남이 그린 4컷 레시피**를 보고 `가장 헷갈리는 한 곳에 동그라미`를 친 뒤, 로봇 셰프가
그림 순서 그대로 해 보다 멈추는 칸과 견주고, `표시된 부분을 고치기`(칸 자리 바꾸기)까지 해 본다.
7차시 「맛있는 코딩」 보드게임과 8차시 A4 레시피 그리기·바꾸기·고치기는 그대로 종이와 몸으로 한다.
화면의 요리는 보드게임 요리 카드와 같다고 하지 않는다(카드 내용을 옮기지 않음).

지도안 도입의 `로봇 셰프에게는 순서가 보이게 알려 주어야 한다`, 정리의
`좋은 알고리즘은 순서가 분명하고, 다른 사람도 같은 뜻으로 이해할 수 있어야 한다`를 로봇 셰프가 곧이곧대로 하다 멈추는 장면으로 겪는다.

- 웹이 아니면 못 하는가: 사람은 순서가 뒤섞인 그림도 눈치껏 바로잡아 읽는다. 화면의 로봇 셰프는 그림 순서 그대로만 한다.
- 값을 바꾸면 결과가 바뀌는가: 두 칸 자리를 바꾸면 멈추는 칸이 옮겨 가거나 끝까지 간다.

## 1. 게임 다섯 칸

| 칸 | 이 활동 |
|---|---|
| 목표 | 로봇 셰프가 끝까지 요리하게 레시피를 고친다 |
| 실패 | 엉뚱한 두 칸을 바꾸면 다른 칸에서 또 멈춘다 |
| 예상 | 돌리기 **전에** 로봇이 멈출 칸에 동그라미를 친다 |
| 제약 | 동그라미 전엔 `로봇 셰프에게 보여 주기`가 잠긴다. 보여 준 뒤엔 동그라미를 못 바꾼다. 고칠 때는 두 칸 자리 바꾸기만 된다(그림을 지우거나 더하지 못함) |
| 되풀이 | `다른 레시피`마다 요리와 뒤섞인 자리(이웃한 두 칸)를 새로 뽑는다. 직전 판과 같은 판은 안 나온다 |

다섯 칸 모두 찬다.

## 2. 한 문장

뒤섞인 두 칸을 찾아 자리를 바꾸면, 로봇 셰프가 멈추던 칸을 지나 요리를 끝낸다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 레시피 | 요리 이름, A4 4칸처럼 2×2로 놓인 칸(번호 1~4, 그림, 짧은 말, 1→2 / 3→4 화살표) | 1단계: 한 칸을 눌러 동그라미(바꿀 수 있음). 2단계: 두 칸을 차례로 눌러 자리 바꾸기 |
| 안내 한 줄 | 지금 할 일 | — |
| 단추 | `로봇 셰프에게 보여 주기`(10자 넘음 → `보여 주기`) / `처음으로` / `다른 레시피` | 확인·되돌리기·다음 판 |
| 결과 | 멈춘 까닭 한 줄 + 동그라미와 떨어진 거리 한 줄 | — |

**보여 주기**: 1번 칸부터 0.6초씩 차례로 불이 들어온다. 할 수 있는 칸은 `함` 딱지, 못 하는 칸에서
멈추고 `멈춤` 딱지와 까닭(예: `잼을 바를 식빵이 없어요`)이 나온다. 동그라미 친 칸은 점선 동그라미 테두리로 남는다.
끝까지 가면 레시피 틀 전체가 한 번 튀고 `요리가 나왔어요`.

**고치기**: 첫 보여 주기 뒤에 열린다. 한 칸을 누르면 들리고, 다른 칸을 누르면 둘이 자리를 바꾼다.
몇 번이든 바꿀 수 있고 `다시 보여 주기`로 확인한다. `처음으로`는 이 판의 처음(뒤섞인 자리, 동그라미 없음)으로 돌린다.

## 4. 판

요리 넷, 칸은 넷, 각 칸에 그 칸을 하려면 먼저 되어 있어야 할 일(`need`)과 먼저 되어 있으면 안 되는 일(`not`).
판마다 요리 하나와 이웃한 두 칸(1·2 / 2·3 / 3·4)을 뽑아 자리를 바꾼다. 로봇은 앞에서부터 하다 처음으로 조건이 안 맞는 칸에서 멈춘다.

| 요리 | 칸 (바른 순서) | 멈추는 까닭 |
|---|---|---|
| 딸기잼 샌드위치 | 식빵 한 장 놓기 / 식빵에 잼 바르기 / 잼 위에 딸기 올리기 / 식빵으로 덮기 | 잼: `잼을 바를 식빵이 없어요` · 딸기: `딸기를 올릴 잼이 없어요`, 덮은 뒤면 `식빵이 덮여 잼이 안 보여요` · 덮기: `덮을 식빵이 아래에 없어요` |
| 주먹밥 | 그릇에 밥 담기 / 밥에 깨 섞기 / 밥을 동그랗게 뭉치기 / 김 두르기 | 섞기: `섞을 밥이 없어요`, 뭉친 뒤면 `벌써 뭉쳐서 섞을 수 없어요` · 뭉치기: `뭉칠 밥이 없어요` · 김: `김을 두를 주먹밥이 없어요` |
| 바나나 우유 | 바나나 껍질 벗기기 / 믹서에 바나나·우유 넣기 / 뚜껑 닫고 갈기 / 컵에 따르기 | 넣기: `껍질을 안 벗긴 바나나예요` · 갈기: `믹서가 비어 있어요` · 따르기: `아직 갈지 않았어요` |
| 토스트 | 식빵을 토스터에 넣기 / 레버 내리기 / 구운 빵 접시에 놓기 / 빵에 버터 바르기 | 레버: `토스터가 비어 있어요` · 꺼내기: `빵이 아직 안 구워졌어요` · 버터: `버터를 바를 빵이 접시에 없어요` |

멈추는 칸은 뒤섞인 두 칸 가운데 **앞 칸일 때도 뒤 칸일 때도 있다**(예: 샌드위치 3·4를 바꾸면 덮기는 되고 4번 딸기에서 멈춤).
그래서 `바뀐 곳 = 멈추는 곳`으로 외울 수 없다.

## 5. 글자

| 자리 | 문구 |
|---|---|
| 제목 | 로봇 셰프 레시피 고치기 (12자) |
| 부제 | 로봇 셰프가 멈출 칸에 동그라미 치고 고쳐요 (23자) |
| 안내 | 로봇이 멈출 칸에 동그라미 쳐요 / 보여 주기를 눌러요 / 바꿀 두 칸을 차례로 눌러요 / 고쳤으면 다시 보여 줘요 |
| 단추 | 보여 주기 · 다시 보여 주기 / 처음으로 / 다른 레시피 |
| 결과(거리) | `동그라미 친 칸에서 멈췄어요` / `동그라미보다 2칸 뒤에서 멈췄어요` / `…앞에서 멈췄어요` |
| 끝까지 | `요리가 나왔어요` |
| 상시 | 우리 레시피는 A4로 옆 모둠과 바꿔 봐요 |

쓰지 않는 말: 게임, 맞았어요, 틀렸어요, 잘했어요, 정답, 점수, 퀴즈.

## 6. 연습 모드

해당 없음. 외부 호출·센서·카메라 없음.

## 7. 만드는 방법

```
판 = { recipe, order[4](칸 id), circle:null, phase:'circle'|'fix'|'done', shown:false, lift:null }
simulate(order): doneSet={}; for pos 0..3: step=order[pos]
  need 중 doneSet에 없는 것 → {stop:pos, why:needMsg}
  not 중 doneSet에 있는 것 → {stop:pos, why:notMsg}
  doneSet.add(step)
  → {stop:null}
newRound(): (요리, 바꿀 자리) 뽑기(직전과 같으면 다시), order = 바른 순서에서 이웃 두 칸 바꿈, circle=null, phase='circle'
tapCell(pos): phase=='circle' → circle=pos / phase=='fix' → lift 없으면 lift=pos, 있으면 order[lift]↔order[pos], lift=null
show(): phase=='circle'이면 circle 있어야 함. 단추 잠금 → 칸마다 600ms(감속 설정이면 0) 차례로 불
  멈추면 멈춤·까닭, 첫 보여 주기면 거리 줄; phase='fix'
  끝까지면 phase='done', 요리가 나왔어요
```

## 8. 난이도 점검

첫 조작 5초(칸 누르기), 1화면, 누를 것 7개(칸 4 + 단추 3), 한 번에 바꾸는 것 하나(동그라미 또는 두 칸 자리), 5분.

## 9. 디버깅

- [ ] 동그라미 전엔 보여 주기가 잠긴다. 동그라미는 보여 주기 전까지 옮길 수 있다.
- [ ] 보여 주기가 도는 동안 칸·단추가 잠긴다. 두 번 눌러도 한 번만 돈다.
- [ ] 네 요리 × 세 자리 모두 어딘가에서 멈춘다(바른 순서만 끝까지 감).
- [ ] 바른 자리로 바꾸면 끝까지 가고 `요리가 나왔어요`.
- [ ] `처음으로`가 그 판의 뒤섞인 자리로 돌린다.
- [ ] 폭 390에서 2×2가 들어가고 가로 스크롤이 없다.
