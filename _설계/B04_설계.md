# B04 체험 설계 — 적힌 대로만

2026. 9. 17. 판정을 뒤집었다. 앞선 판정문은 9절에 남겨 둔다.

## 0. 만들까 말까

**만든다.** 짝이 몸으로 막히는 일(활동3)은 그대로 한다.

- **웹이 아니면 못 하는가.** 활동3의 규칙은 `적혀 있지 않은 일은 짐작해서 하지 않기`다.
  그런데 사람 짝은 아무리 정해도 눈치껏 해 버린다. 화면은 **곧이곧대로만 한다.**
  두루뭉술한 단계에서 정말로 멈춘다. 이 곧이곧대로를 사람이 해내기가 가장 어렵다.
- **값을 바꾸면 결과가 바뀌는가.** 한 단계를 고쳐 쓰면 멈추던 자리가 옮겨 간다.

**여전히 만들지 않는 것.** 내 절차를 말과 그림으로 적기, 짝과 맞바꿔 실행하기,
두 표현 견주기. 화면은 과정안 활동1의 **예제 다섯 단계만** 다룬다. 학생의 절차를 받지 않는다.

## 1. 과정안 어디에 붙는가

- 블록 B04, 7차시. 활동1 「과제 고르고 단계 나누기」의 `‘잘’, ‘적당히’처럼 사람마다 달라지는 말에 밑줄 긋기`
  **뒤**, 활동2 「로봇용 그림 설명서 만들기」 **앞**에 4분.
- 도입의 `고지식한 로봇`이 애매한 칸에서 엉뚱하게 움직이는 장면을 본 뒤, 과제 카드 세 가지
  (종이컵 탑 쌓기·색 블록 줄 세우기·필통 정리)로 된 다섯 단계에서 로봇이 **어느 줄에서 막힐지** 먼저 짚는다.
- 그림 설명서 만들기와 활동3 「글 없이 따라 하는 사용자 시험」은 그대로 종이와 몸으로 한다.

## 2. 한 문장

두루뭉술한 단계를 **한 가지로 고치면** 멈추던 자리가 다음으로 옮겨 간다.

## 3. 화면 (1화면)

> 2026. 9. 17. 게임으로 다시 짠 뒤의 모습: 판마다 과제 하나(다섯 단계, 두루뭉술한 줄 하나)가 나오고,
> 학생이 **막힐 줄을 먼저 짚은 뒤** `해 보기`로 확인한다. 빗나가면 `2줄 아래에서 막혔어요`처럼
> 떨어진 거리만 알린다. 아래 표와 4절 표는 첫판 기록이다. 판의 내용은 맨 끝 「개정 과정안 반영」 절을 따른다.

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 | 다섯 단계. 지금 하는 줄과 멈춘 줄에 표시 | 어디서 멈추는지 본다 |
| 가운데 | 책상·필통·연필 그림. 단계대로 움직인다 | 본다 |
| 아래 | 두 줄에만 붙은 `고쳐 쓰기`, `해 보기`, `처음으로` | 한 줄을 고치고 다시 해 본다 |

## 4. 조작과 값

- 조절하는 값: **고쳐 쓴 단계** 하나. 다섯 줄 가운데 두루뭉술한 줄이 **둘** 있다.
  누르면 `두루뭉술한 말 ↔ 한 가지 말`로 바뀐다.

| 번호 | 처음 문장 | 고친 문장 |
|---|---|---|
| 1 | 필통을 챙긴다 | 필통을 책상에 올린다 |
| 2 | 필통을 연다 | (고칠 것 없음) |
| 3 | 연필을 정리한다 | 연필 한 자루를 꺼낸다 |
| 4 | 필통을 닫는다 | (고칠 것 없음) |
| 5 | 자리에 앉는다 | (고칠 것 없음) |

- `해 보기`를 누르면 위에서부터 한 줄씩 0.6초 간격으로 실행한다.
  두루뭉술한 줄에 닿으면 그 자리에서 **멈춘다.** 뒤 단계는 하지 않는다.
- 보조 조작: `처음으로`(고친 것과 그림을 모두 되돌린다).

**열어 두는 딴짓.** 둘 다 고치지 않은 채 `해 보기`를 눌러 1번에서 멈추는 것을 볼 수 있다.
막지 않는다. 한 줄만 고쳐 3번에서 멈추는 것도 그대로 둔다. 둘 다 고쳐야 끝까지 간다.

**재미 검토(2026. 9. 17.)에서 더한 것.** 둘 다 고쳐 끝까지 가는 것이 이 화면의 목표인데
그 순간이 다른 줄과 똑같이 조용했다. `끝까지 갔어요`가 뜰 때만 한 번 뛴다.
멈출 때는 뛰지 않는다. `prefers-reduced-motion`에서 꺼진다.

## 6. 연습 모드

**해당 없음.** 외부 호출·센서·카메라를 쓰지 않는다.

## 7. 만드는 방법

```
단계 = 다섯 줄. 1번과 3번만 {두루뭉술, 고친말} 두 벌을 가진다
고침 = {1:false, 3:false}

해보기():
  버튼을 잠근다
  for i in 1..5:
    i번 줄에 표시를 옮긴다
    if (i가 두루뭉술한 줄이고 고침[i]가 false): 멈춤 표시를 켜고 끝낸다
    그림을 i번에 맞게 바꾼다
    0.6초 기다린다
  끝까지 갔으면 한 줄 띄운다
  버튼을 푼다
```

- `해 보기`가 도는 동안 `고쳐 쓰기`를 잠근다. 두 번 눌러도 두 번 돌지 않는다(8-3).
- 그림은 인라인 SVG 몇 조각의 보임·숨김으로만 바꾼다. 포인트색 한 가지: 다홍 `#E11D48`.
- `prefers-reduced-motion`이면 기다림 없이 결과만 보인다.

## 9. 디버깅

- [ ] 아무것도 고치지 않고 `해 보기`를 누르면 1번에서 멈춘다.
- [ ] 1번만 고치면 3번에서 멈춘다.
- [ ] 둘 다 고치면 5번까지 간다.
- [ ] `해 보기`를 빠르게 두 번 눌러도 한 번만 돈다.
- [ ] `처음으로`가 고친 문장과 그림을 모두 되돌린다.
- [ ] 2·4·5번에는 `고쳐 쓰기` 버튼이 없다.

## 개정 과정안 반영 (2026-09-27)

**판정: 게임 수정 (판 내용 교체).**

확인한 것 (`_data/lessons.json` B04)
- 옛 붙는 자리 `활동1 셋째 줄 필통에서 연필 꺼내기 다섯 단계 예제`와 `활동2(내 절차 적기)`는 없어졌다.
  개정안은 **로봇용 그림 설명서**를 만들고 다른 모둠의 **사용자 시험**으로 모호한·빠진 단계를 고친다.
- 활동1에 과제 카드 세 가지(종이컵 탑 쌓기·색 블록 줄 세우기·필통 정리)와
  `‘잘’, ‘적당히’처럼 사람마다 달라지는 말에 밑줄 긋기`가 있다. 게임의 판(필통에서 연필 꺼내기·
  사물함에서 책 꺼내기·우유갑 정리하기)은 개정안에 없는 과제였다.
- 개정안 도입의 `고지식한 로봇`(그림에 있는 대로만 한다)은 게임의 `적힌 대로만` 규칙과 같다.

바꾼 것 — 판 세 가지를 과제 카드와 같게 바꾸고, 두루뭉술한 말을 개정안의 `잘`·`적당히`로 맞췄다.

| 판 | 다섯 단계 | 막히는 줄 |
|---|---|---|
| 필통 정리 | 지퍼를 연다 / 필통을 **잘** 정리한다 / 연필 세 자루를 넣는다 / 지우개 한 개를 넣는다 / 지퍼를 닫는다 | 2 |
| 색 블록 줄 세우기 | 블록 다섯 개를 책상에 놓는다 / 빨간 블록을 맨 왼쪽에 둔다 / 나머지 블록을 **잘** 늘어놓는다 / 블록끼리 붙인다 / 손을 뗀다 | 3 |
| 종이컵 탑 쌓기 | 종이컵 여섯 개를 꺼낸다 / 세 개를 한 줄로 엎어 놓는다 / 그 위에 두 개를 엎어 올린다 / 남은 컵을 **적당히** 올린다 / 손을 뗀다 | 4 |

- 물건 그림 둘을 바꿨다: 사물함·책 → 색 블록 다섯 개, 우유갑 → 종이컵 탑(맨 위 한 개는 점선). 필통 그림은 그대로.
- 부제 `어느 줄에서 막힐지 짚어요` → `고지식한 로봇이 어느 줄에서 막힐까`(17자).
- 되짚기 `내 절차는 짝과 해 봐요` → `내 설명서는 옆 모둠이 시험해요`(개정안 활동3).
- 짚기·확인·다음 판 흐름, 문구 규칙(맞았어요·틀렸어요 없음)은 그대로다.
- 개정안의 `빠진 단계`는 활동4에서 종이로 다룬다. 화면에 넣지 않았다(기능을 늘리지 않음).
- 허브 카드의 부제는 `_tools/make_hub.py`를 다시 돌려야 바뀐다(이 작업에서 허브는 건드리지 않음).

검사: `python _tools/run_all.py B01 B03 B04 B05 B06 B07` — 문법 0건 / 감사 0건 / 헤드리스 0건, **통과**.
