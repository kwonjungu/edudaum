# B13 체험 활동 설계 — 기록 두 장으로 막힌 곳 짚기

2026. 10. 11. 지도안(검토반영본)에 맞춰 다시 짰다. 옛 설계(카드 세 장 2분 발표 나누기)는
지도안에서 `카드 세 장 2분 발표`가 없어져 버린다. 구조는 `판이 나온다 → 짚는다 → 확인한다` 그대로이고,
사람에게 보이는 이름만 '체험 활동'이라 부른다.

- 포인트 컬러: 통일 테마 `--point`

## 0. 지도안의 어느 활동에 붙나

**30차시 전개 「활동4. 기록 정리하고 고칠 점 정하기 (10분)」의 앞**, 활동3 부스가 끝난 직후 3~5분.

> - 모은 기록에서 성공 수와 가장 자주 막힌 곳 세기
> - 기록지를 들고 한 사람씩 1분 말하기: '잘 된다' 대신 기록에 나온 수로
> - 막힌 곳 후보를 '많이 막힘·고치기 쉬움' 표에 놓아 비교하기
> - 다음에 고칠 점 한 가지와 까닭을 기록지 맨 아래 칸에 쓰기

지식·이해 ② `사용 기록(성공 수·막힌 곳·걸린 시간)이 근거가 되는 까닭`과
도입의 `'잘 돼요'와 '처음 써 본 친구 5명 중 4명이 1분 안에 성공했어요' 가운데 더 믿을 만한 말 고르기`,
정리의 `우리끼리 해 본 결과와 무엇이 달랐는가`를 판으로 만든다.
**기록 몇 장만 보고 내린 짐작**이 **기록을 다 세었을 때**와 얼마나 다른지를 몸으로 겪게 한다.

화면에서 두세 판 해 본 뒤, 자기 모둠 기록지(붙임2)로 같은 일을 한다: 세고 → 1분 말하기 → 표에 놓기 → 맨 아래 칸 쓰기.

**대신하지 않는 것.** 활동1 활동 안내 만들기, 활동2 미리 해 보기, 활동3 부스 운영·초시계·기록, 1분 말하기,
자기 모둠의 표 놓기와 고칠 점 쓰기. 화면의 기록지는 **연습용으로 지어낸 기록**이고 `친구1`처럼 번호만 쓴다.

## 1. 다섯 칸

| 칸 | 이 화면에서 |
|---|---|
| 목표 | 이 부스에서 가장 자주 막힌 곳을 짚는다 |
| 실패 | 두 장만 보고 짚은 곳이 다 세어 보면 아닐 수 있다 |
| 예상 | 나머지 기록을 펼치기 **전에** 짚는다. 짚기 전엔 `나머지 펼치기`가 잠긴다 |
| 제약 | 처음엔 기록 여섯 장 가운데 두 장만 보인다 |
| 되풀이 | `다음 판`마다 다른 부스의 기록지가 나온다 |

다섯 칸 모두 채운다.

## 2. 판 (기록지 한 장)

- 부스 하나 = 친구1~6의 기록 여섯 줄. 줄마다 `성공 / 멈춤`, 걸린 시간(성공일 때, 초), 막힌 곳(없으면 `—`).
- 막힌 곳 후보는 판마다 셋. 아래 여섯 가운데 뽑는다. 고치기는 지도안 활동2의 두 갈래(`활동 안내 고치기`, `코드 조정하기`)로 나눈다.

| 막힌 곳 | 고치는 길 | 고치기 |
|---|---|---|
| 어느 버튼을 누를지 | 안내에 버튼 그림·화살표 | 쉬움 |
| LED 모양의 뜻 | 안내에 모양과 뜻 짝 짓기 | 쉬움 |
| 흔들기를 몰랐음 | 안내에 흔들기 그림 | 쉬움 |
| 안내 글이 김 | 글 줄이고 그림으로 | 쉬움 |
| 수신기가 늦게 반응 | 코드의 기다리기 줄이기 | 어려움 |
| A·B 결과가 비슷함 | 코드에서 LED 모양 바꾸기 | 어려움 |

- 막힌 횟수: 가장 많은 곳 3번, 나머지 1~2번(같은 수 1등이 없게). 여섯 줄 가운데 막힌 곳이 있는 줄은 5~6줄.
- **판의 절반은 첫 두 장이 다른 곳을 가리키게** 짠다(첫 두 장에 가장 많은 곳이 0~1번, 다른 곳이 2번 또는 1번씩).
  나머지 절반은 첫 두 장이 실제와 같은 쪽을 가리킨다. 늘 빗나가면 '두 장은 늘 틀린다'는 엉뚱한 규칙을 배운다.
- 성공 수는 3~5명. 걸린 시간은 성공한 줄마다 25~95초.

## 3. 화면 (1화면)

| 구역 | 보이는 것 |
|---|---|
| 활동 기록지 | 여섯 줄 표. 처음엔 친구1·2만 보이고 3~6은 `?` |
| 짚기 | 막힌 곳 후보 단추 셋, `나머지 펼치기`, 견주는 말 |
| 세어 보기 | 펼친 뒤: 후보마다 막힌 횟수 막대, `성공 n명 / 6명` |
| 많이 막힘·고치기 쉬움 | 펼친 뒤: 2×2 표에 후보 셋이 놓인다. 고칠 점 단추 셋, 기록지 맨 아래 칸에 옮겨 적을 한 줄. `다음 판`, `처음으로` |

## 4. 조작과 값

- 후보를 누르면 짚힌다. **펼치기 전까지는 다른 후보로 바꿀 수 있다.** 짚기 전엔 `나머지 펼치기`가 잠긴다.
- `나머지 펼치기`: 3~6줄이 드러나고, 후보마다 막힌 횟수가 막대로 선다. 짚기가 굳는다.
- 견주는 말: 짚은 곳이 가장 많은 곳이면 `짚은 곳이 가장 많이 막혔어요 (3번)`,
  아니면 `짚은 곳 1번, 가장 많은 곳 '…' 3번. 2번 차이예요`. `맞았어요`·`틀렸어요`는 쓰지 않는다.
- 2×2 표: 가로 `많이 막힘`(그 판에서 가장 많은 곳) / `덜 막힘`, 세로 `고치기 쉬움` / `고치기 어려움`. 화면이 자리를 놓는다(센 수와 위 표의 사실).
- 고칠 점은 **학생이 고른다.** 화면은 무엇을 고르라고 하지 않는다. 고르면 한 줄을 만든다:
  `고칠 점: 어느 버튼을 누를지 → 안내에 버튼 그림·화살표 / 까닭: 6명 중 3번 막힘, 고치기 쉬움`.
- `다음 판`은 펼친 뒤 열린다. 직전 판과 같은 후보 셋이 나오면 다시 뽑는다. `처음으로`는 첫 판을 새로.
- 짚은 판 수·점수는 세지 않는다.

## 5. 글자

| 자리 | 문구 |
|---|---|
| 제목(h1) | 기록 두 장으로 막힌 곳 짚기 |
| 부제 | 다 펼쳐 세어 보고 고칠 점을 골라요 · 체험 활동 |
| 짚기 물음 | 두 장만 보고, 가장 자주 막힌 곳은? |
| 버튼 | 후보 이름 / 나머지 펼치기 / 다음 판 / 처음으로 |
| 표 머리 | 친구 / 결과 / 걸린 시간 / 막힌 곳 |
| 상시 | 연습용 기록이에요. 우리 기록지는 종이에 |

쓰지 않는 말: 게임, 점수, 맞았어요, 틀렸어요, 잘했어요, 순위.
