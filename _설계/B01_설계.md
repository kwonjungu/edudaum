# B01 체험 설계 — 신호등 명령 바꾸기

## 0. 만들까 말까

**만든다.**

종이에서는 초록불을 20초에서 5초로 줄이면 달라지는 일을 상상해서 적을 뿐 확인할 수
없는데, 명령 한 줄을 바꾸면 신호등이 그대로 도는 것은 웹에서만 눈으로 본다(2절 1·2).
명령만 바뀌고 기둥과 전구는 그대로라는 점도 같은 그림 위에서 곧바로 드러난다.

과정안 유의점 "실제 기기를 조작하지 않고 종이에 적힌 명령만 한 줄 바꾸게 한다"는
지킨다. 이 웹은 실물 신호등이나 마이크로비트가 아니고, 종이에 적어 둔 예상을 뒤에
견주어 보는 자리로만 쓴다(2절 끝 단서).

## 1. 과정안 어디에 붙는가

B01 2차시 활동3 「명령을 한 줄 바꿔 보기」(16분) **뒤**.
학생이 활동지에 "초록불을 5초로 줄이면 달라지는 일"을 먼저 적은 다음, 교실에서
5~7분 동안 확인하는 자리로 쓴다. 활동지를 걷기 전에 연다.

## 2. 한 문장

초록불 초 수를 바꾸면 신호등이 그 명령대로 돌고, 사람이 다 건너는지가 달라진다.

## 3. 화면 (1화면)

| | 보이는 것 | 학생이 하는 것 | 넘어가는 조건 |
|---|---|---|---|
| 1 | 신호등과 횡단보도를 그린 그림, 명령 세 줄, 초 수 슬라이더, 실행·다시 하기 | 슬라이더로 초록불 초 수를 바꾸고 실행을 누른다 | 없음. 한 화면에서 끝난다 |

실행하면 초록불이 켜지고 사람이 한 칸씩 건넌다. 초록불이 끝나기 5초 전부터 깜빡인다.
초록불이 꺼지면 사람은 그 자리에 선다. 신호등 기둥과 전구 세 개는 어떤 명령에서도
같은 자리에 같은 모양으로 남는다.

## 4. 조작과 값

| | |
|---|---|
| 조절하는 값 | 초록불을 켜 두는 초 수 **하나** |
| 범위 | 3 ~ 20 (1초 단위) |
| 기본값 | 20 (과정안 신호등 명령 둘째 줄과 같다) |
| 결과 반영 | 사람은 1초에 한 칸씩 열두 칸을 건넌다. 초 수가 12보다 작으면 남은 칸에서 멈춘다 |

건너는 데 드는 칸 수(12칸)는 고정이다. 학생이 바꿀 수 있는 값은 초 수 하나뿐이다.
화면 시간은 1초를 220ms로 줄여 돌린다. 20초짜리도 4.4초면 끝난다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 | 글자 |
|---|---|---|
| 제목 | `신호등 명령 바꾸기` | 9 |
| 명령 1 | `빨간불 30초 켜기` | 10 |
| 명령 2 | `초록불 ○○초 켜기` | 10 |
| 명령 3 | `끝나기 5초 전 깜빡` | 11 |
| 버튼 | `실행` / `다시 하기` | 2 / 5 |
| 결과 (다 건넘) | `다 건넜어요` | 6 |
| 결과 (멈춤) | `○칸 남기고 멈췄어요` | 11 |
| 관찰 물음 | `무엇이 그대로인가요?` | 11 |

한 화면 합계는 공백까지 180자 안쪽이다. 정의문과 목표 문장을 쓰지 않는다.

## 6. 연습 모드

외부에서 가져오는 것이 없으므로 막힐 자리가 없다. 인터넷을 끊어도 그대로 열린다.
카메라·마이크·저장소를 쓰지 않는다. 그래서 연습 모드를 따로 두지 않는다(공통기준 7절
표의 네 줄이 모두 해당 없음).

## 7. 만드는 방법

외부 라이브러리 없음. 순수 HTML·CSS·JS 단일 파일. 그림은 인라인 SVG.

```
상태 = { greenSec: 20, t: 0, step: 0, running: false }
실행():
  running이면 무시한다            # 두 번 눌러도 한 번만 돈다
  t=0, step=0, running=true, 결과문구 지움
  타이머 = setInterval(220ms):
    t += 1
    램프 = t <= greenSec ? (t > greenSec-5 && t 홀수 ? 꺼짐 : 초록) : 빨강
    t <= greenSec 이면 step += 1
    step >= 12 또는 t > greenSec 이면
      정지, running=false
      결과 = step>=12 ? "다 건넜어요" : (12-step)+"칸 남기고 멈췄어요"
다시하기(): 타이머 끄고 greenSec=20, t=0, step=0, 결과 지움
```

바뀌는 것은 램프 채움색, 사람 x좌표, 결과 문구 세 군데뿐이다. 화면을 다시 그리지
않는다(8-3 첫 줄).

**포인트색은 앰버 `#F59E0B` 하나다.** 다만 신호등 램프의 빨강·초록은 장식이 아니라
이 활동이 다루는 대상 자체여서 그대로 쓴다. 램프 밑에 `빨강`·`초록` 글자를 함께 두어
색으로만 구별하지 않게 한다(5-5).

## 8. 난이도 점검

| 재는 것 | 상한 | 이 차시 |
|---|---|---|
| 첫 조작까지 | 30초 안 | 슬라이더가 화면 가운데 있다. 5초 |
| 화면 수 | 3 이하 | **1** |
| 한 화면의 조작 요소 | 5 이하 | **3** (슬라이더, 실행, 다시 하기) |
| 한 번에 바꾸는 값 | 1 | **1** (초 수) |
| 전체 체험 시간 | 5~10분 | 5~7분 |
| 새로 배우는 조작법 | 0 | **0** (끌기·누르기) |

## 9. 디버깅

8-2 점검표에 더해 이 차시만의 항목.

- [ ] 실행 중에 슬라이더를 움직여도 돌고 있는 판이 흔들리지 않는다(실행 중 잠근다).
- [ ] 실행 버튼을 빠르게 두 번 눌러도 타이머가 두 개 돌지 않는다.
- [ ] 초 수 3(최소)과 20(최대) 양 끝에서 사람이 판 밖으로 나가지 않는다.
- [ ] 다시 하기를 누르면 초 수가 20으로, 사람이 출발선으로 돌아온다.
- [ ] `prefers-reduced-motion`일 때 사람이 미끄러지지 않고 칸 단위로 바로 옮겨진다.
