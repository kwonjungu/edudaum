# B15 체험 활동 설계 — 세 칸으로 나누기 활동

2026. 10. 11. 교사가 고친 지도안(6학년 1~2차시)에 맞춰 다시 짰다. 옛 설계(소음 신호등 칸과 예시로 배우는 칸 견주기,
마이크·카메라 사용)는 고친 지도안에서 마이크로비트·CreateAI 시연이 빠지고 B16으로 옮겨 가 버렸다. 옛 글은 git 기록에 남아 있다.
구조는 `판이 나온다 → 짚는다 → 확인한다`이고, 학생에게 보이는 이름은 '체험 활동'이다.

## 0. 지도안의 어느 활동 앞/뒤에 붙나

**1차시 활동1. 인공지능의 의미와 특징 알아보기**의 첫 줄 **뒤**에 4~5분.

> - 음성 비서·사진첩 장면을 다시 보며 ‘무엇을 받아들였나(보기·듣기) / 무엇을 알아냈나(판단) / 무엇을 해 주었나(결과)’ 세 칸으로 나누어 적기

- 두 장면을 함께 세 칸에 나눈 뒤, 같은 세 칸 나누기를 장면을 바꿔 가며 혼자 해 본다. 다음 줄
  `인공지능의 뜻 함께 읽기`·`특징 세 가지 정리하기`로 넘어가기 전에, 세 칸이 장면마다 되풀이된다는 것을 손으로 겪는다.
- 장면은 지도안의 두 장면(음성 비서에게 날씨 묻기, 사진첩이 얼굴별로 사진을 묶어 준 화면)과,
  활동2 사례 카드 가운데 둘(손동작 알아보기, 영상 추천)이다.
- **만들지 않는 것.** 활동2 사례 카드 여덟 장 스티커 판정, ‘인공지능이다/아니다/더 알아봐야 함’ 고르기,
  활동3 분류판, 활동4 발표. 화면은 어느 것이 인공지능인지 **말하지 않는다**(지도안 △ `생각이 나뉜 사례는 … 틀렸다고 하지 않는다`).
  자동문·타이머 같은 ‘기계’ 카드는 3~4차시 비교 몫이라 장면에 넣지 않는다.
- 센서·카메라·마이크를 쓰지 않는다. 고친 지도안 1~2차시에는 학생 기기 활동이 없다.

**다섯 칸.** 목표(세 장을 제 칸에 놓기) · 실패(칸이 어긋날 수 있음) · 예상(다 놓기 전 확인 잠금) ·
제약(한 칸에 한 장) · 되풀이(다음 장면이 새로 나옴) — 다섯 다 채움.

## 1. 지도안 어디에 붙는가

- 블록 B15, 6학년 1차시 전개 활동1, 첫 줄(세 칸으로 나누어 적기) 뒤 4~5분. 활동지 ‘인공지능 특징 카드’ 쓰기 앞.
- 칸 이름은 지도안 그대로 `받아들였나`·`알아냈나`·`해 주었나`, 괄호 말 `보기·듣기`·`판단`·`결과`.

## 2. 한 문장

뒤섞인 장면 카드 세 장을 `받아들였나 → 알아냈나 → 해 주었나` 칸에 놓고 확인하면, 카드마다 제 칸과 몇 칸 떨어졌는지가 보인다.

## 3. 화면 (1화면)

| 구역 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 장면 | 장면 이름 한 줄(예: `음성 비서에게 날씨 묻기`) | 읽는다 |
| 세 칸 | 칸 셋(받아들였나·알아냈나·해 주었나). 놓인 카드는 칸 안에 보인다 | 놓인 칸을 누르면 카드가 빠진다(확인 전) |
| 카드 | 뒤섞인 카드 세 장 | 누르면 빈 칸 가운데 가장 위 칸에 놓인다 |
| 단추 | `확인하기` `다시 하기` `다음 장면`, 상태 한 줄 | |

### 장면과 카드 (칸 순서대로)

| 장면 | 받아들였나 | 알아냈나 | 해 주었나 |
|---|---|---|---|
| 음성 비서에게 날씨 묻기 | “오늘 날씨 어때?” 말을 들어요 | 날씨를 묻는 말인 줄 알아내요 | “맑아요”라고 알려 줘요 |
| 사진첩이 얼굴별로 묶어 주기 | 사진 속 얼굴을 봐요 | 같은 사람끼리 알아내요 | 얼굴별로 사진을 묶어 줘요 |
| 손동작 알아보기 | 카메라로 손 모양을 봐요 | 주먹인지 보자기인지 알아내요 | 알아낸 모양을 화면에 띄워요 |
| 영상 추천 | 내가 본 영상 목록을 읽어요 | 좋아할 만한 영상을 골라내요 | 다음 볼 영상을 띄워 줘요 |

## 4. 조작과 값

- **판.** 장면 하나를 뽑는다(직전과 다르게). 세 카드를 뒤섞되, 칸 순서 그대로 놓인 순서는 다시 뒤섞는다.
- **놓기.** 카드를 누르면 빈 칸 가운데 맨 위 칸에 놓인다. 놓인 칸을 누르면 그 카드가 카드 줄로 돌아간다(확인 전).
- **예상.** 세 칸이 다 차기 전에는 `확인하기`가 잠긴다.
- **제약.** 한 칸에 한 장. 확인한 뒤에는 카드와 칸이 잠긴다.
- **확인.** 칸마다 `같은 칸` / `한 칸 떨어짐` / `두 칸 떨어짐`. 상태 한 줄은
  - 모두 같은 칸: `세 장 모두 그 칸이었어요`
  - 아니면: `N장이 제 칸에서 떨어져 있었어요`
- **되풀이.** `다음 장면`은 새 판. `다시 하기`는 확인 전이면 놓은 카드를 다 빼고, 확인 뒤에는 다음 장면과 같다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 |
|---|---|
| 제목 | 세 칸으로 나누기 활동 |
| 부제 | 장면 카드를 받아들였나·알아냈나·해 주었나 칸에 놓아요 |
| 소제목 | 세 칸 / 카드 |
| 칸 이름 | 받아들였나(보기·듣기) / 알아냈나(판단) / 해 주었나(결과) |
| 상태(놓기 전) | 카드를 눌러 위 칸부터 채워요 / 칸을 누르면 카드가 빠져요 / 확인하면 드러나요 |
| 단추 | 확인하기 / 다시 하기 / 다음 장면 |
| 되짚기(상시) | 어느 것이 인공지능인지는 교실에서 이야기해요 |

**쓰지 않는 말**: 게임, 판, 점수, 등수, 맞았어요, 틀렸어요, 잘했어요, 퀴즈, 알고리즘, 모델.

## 6. 연습 모드

해당 없음. 센서·카메라·마이크·외부 호출을 쓰지 않는다.

## 7. 만드는 방법

외부 라이브러리 없음. 단일 파일.

```
새판():
  장면 = 0~3 (직전과 다르게); 순서 = [0,1,2] 뒤섞기 (그대로면 다시)
  칸 = [없음, 없음, 없음]; 확인함 = 거짓
카드 누름(c): 확인함이거나 c가 놓였으면 무시; 칸[첫 빈 칸] = c
칸 누름(k): 확인함이면 무시; 칸[k] = 없음
확인(): 빈 칸 있거나 확인함이면 무시; 확인함 = 참; 칸마다 |k − 칸[k]|
```

## 8. 난이도 점검

첫 조작 5초(카드 하나 누르기), 1화면, 조작 요소: 카드 셋 + 칸 셋(빼기) + 단추 셋, 한 번에 바꾸는 값 1개, 4~5분, 새 조작법 0개.

## 9. 디버깅

- [ ] 세 칸이 다 차기 전에는 `확인하기`가 흐리다.
- [ ] 카드는 빈 칸 가운데 맨 위로 들어간다. 놓인 칸을 누르면 빠진다.
- [ ] 판이 시작될 때 카드가 칸 순서 그대로 놓여 있지 않다.
- [ ] 확인 뒤 카드·칸이 잠기고, 거리는 `|칸 번호 − 카드의 제 칸 번호|`다.
- [ ] 화면 어디에도 ‘인공지능이다/아니다’ 판정이 없다.
- [ ] 폭 390·세로 800에서 `확인하기`에 스크롤로 닿고 가로 스크롤이 없다.

- [x] 칸 이름·괄호 말이 지도안 그대로다. 알고리즘·모델 같은 낱말이 없다(지도안 △).

## 11. 재미 검토 (2026. 10. 11.)

- 고친 것: 확인한 뒤 `다음 장면`이 주 단추로 바뀌고 초점이 옮겨 가, 장면을 바꿔 가며 되풀이하기 쉬움.
