## 1. 다섯 칸

| 칸 | 이 활동에서 |
|---|---|
| 목표 | 두 번 안에 카드 조건의 여섯 번을 다 알아보게 한다 |
| 실패 | 원인을 다르게 짚으면 달라진 칸이 없다. 원인이 두 갈래인 판은 한 번으로 안 끝난다. 두 번을 다 쓸 수 있다 |
| 예상 | `다시 시험` 전에 원인 카드 하나를 짚는다(근거 세 줄을 보고) |
| 제약 | 한 번에 한 부분, 두 번까지, 시험 기록(시험 방법)은 잠김 |
| 되풀이 | `다음 카드`가 사용 조건 카드·숨은 원인·근거를 새로 뽑는다 |

## 2. 한 문장

근거 세 줄(그 조건 샘플 수·기본 조건 결과·사용 메모)을 보고 원인 카드 하나를 짚은 뒤, 그 부분만 고쳐 같은 시험으로 다시 본다.

## 3. 화면 (1화면, 위아래 두 칸)

| 칸 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 위 `시험 기록`(자물쇠) | 사용 조건 카드 한 장, 기본 조건·카드 조건 × 세 동작 표(○·✕, ✕ 칸엔 코치가 안내한 동작), 근거 세 줄, 맞힌 수 `카드 조건 N / 6`, `코치 1.0 · 남은 시험 2번` | 읽는다 |
| 아래 `원인 카드 하나` | `데이터` `모델` `사용 조건`, 고른 뒤 고칠 일 한 줄, `다시 시험` | 하나를 짚고(바꿀 수 있음) 다시 시험 |
| 끝 | `다음 카드` `다시 하기`, 상시 한 줄 | |

- 표의 두 줄: 기본 조건(`다른 모둠 친구가 오른손 손목 위에 차고 보통 빠르기로` — 지도안) / 카드 조건. 동작마다 두 번씩 해서 칸에 ○○·○✕ 꼴.
  → 칸마다 두 번이므로 줄마다 여섯 번. 맞힌 수는 **카드 조건 줄** 여섯 번으로 센다.
- 다시 시험하면 칸마다 지난 기록을 흐리게 두고 이번 기록을 나란히. 달라진 칸은 테두리가 굵어지고 한 번 튄다.

### 근거 세 줄 (지도안 활동2의 세 물음과 같은 순서)
1. `계획표 · 왼손 샘플 0개` — 데이터 원인이면 0개, 아니면 3개.
2. `기본 조건 · 손바닥↔손가락 헷갈림` 또는 `기본 조건 · 헷갈림 없음` — 모델 원인이면 기본 줄에서도 두 동작이 서로로 안내된다.
3. `사용 메모 · 밴드가 헐거웠어요` / `동작을 짧게 했어요` / `메모 없음` — 사용 조건 원인이면 메모가 있다.
   다섯에 한 판꼴로 원인이 아닌데도 메모가 붙는다(근거가 하나로 딱 떨어지지 않는 판).

### 원인 카드를 고르면 (지도안 활동3의 고칠 일)
- 데이터 → `그 조건으로 동작마다 샘플 3개씩 더 녹화해요`
- 모델 → `헷갈린 두 동작이 더 달라 보이는 샘플을 더해요`
- 사용 조건 → `밴드를 고치거나 사용 안내 카드를 써요`
모델 원인도 고치는 길은 데이터 쪽이다(지도안 `초등에서는 모델 속을 고치지 않고`). 버튼 이름은 원인 카드 이름이다.

### 결과 문구
- `N칸이 달라졌어요` / `달라진 칸이 없어요` / `여섯 번을 다 알아봤어요` / `두 번을 다 썼어요 · 알려진 한계에 적어요`.
- 숨은 원인은 끝까지 적지 않는다. `맞았어요·틀렸어요` 없음.
- 끝나면 `고친 점 기록 · 왼손 · 1.0 2/6 → 2.0 6/6` 한 줄(활동지에 옮겨 적을 것, 저장 없음).

## 4. 조작과 값

```
CARDS = 왼손 · 빠르게 · 천천히 · 손등 착용          (지도안 활동1의 네 장)
판 뽑기: card, causes = [하나] (1/3 확률로 둘), pair(모델 원인 두 동작, 60%는 손바닥·손가락)
needs[줄][동작] = 그 칸을 알아보려면 고쳐야 할 부분들
  모델  → pair 두 동작, 두 줄 모두
  데이터 → 카드 줄, keep 한 동작 빼고 (네에 하나꼴로 keep 없음)
  사용  → 카드 줄, 무작위 한두 동작
칸의 두 번: needs가 남아 있으면 두 번 다 ✕ (단 사용 원인 칸은 한 번만 ✕일 수 있음)
✕ 칸의 안내 동작: 모델이면 pair의 짝, 아니면 나머지 둘 가운데 하나
처음부터 다 알아보는 판·직전 판과 같은 판은 다시 뽑는다
```

## 교사 검토 (2026-10-11)
- 지도안 정리 유의점 `비교표의 맞힌 수는 기본 조건과 뽑은 조건으로 나누어 적게`: 맞힌 수를 `기본 N/6 · 카드 N/6`으로 나누고, 고친 점 기록 한 줄도 두 줄을 따로 적는다.
- 활동1 `못 알아본 동작은 무엇으로 안내했는지 함께 적기`: ✕ 칸 아래 `→손가락` 꼴 글자가 무엇인지 표 밑 한 줄로 밝혔다.
- 맞힌 수 글꼴을 고정폭에서 본문 글꼴로(`카드 조건` 글자가 벌어져 읽히던 것).
- 그대로 둔 것: 지도안의 `모르겠음` 칸은 판마다 근거가 화면에 있어 두지 않았다. 지도안 활동1의 `두 장 뽑기`는 판마다 한 장으로, `다음 카드`가 둘째 장 노릇을 한다.

## 재미 검토 (2026-10-11)
- `판이 나온다(카드·기록·근거) → 짚는다(원인 카드) → 확인한다(다시 시험)`: 짚기 전 `다시 시험` 잠금, 다시 시험 전엔 다른 원인으로 바꿀 수 있음(390×800 직접 눌러 확인, `다시 시험`은 위에서 약 560px로 접힘 위).
- 이미 고친 원인 카드는 `데이터 · 고침`으로 바뀌고 잠긴다. 같은 카드를 또 골라 한 번을 헛되이 쓰는 일을 막아, 두 번째 시험이 늘 새 짚기가 되게 했다.
- 달라진 칸이 굵은 테두리로 한 번 튀고, 다 알아보면 맞힌 수가 튄다. 숨은 원인은 끝까지 보이지 않는다.
