# B18 체험 설계 — 말과 글이 글자로 나오는 네 단계

## 0. 만들까 말까

**만들지 않는다.**

7차시 활동1이 이미 네 단계를 손으로 끝까지 한다. 소리 카드의 숫자를 규칙표에서
찾아 가장 차이가 작은 줄의 글자를 고르는 것이 곧 "숫자로 바꾸기 → 가장 비슷한 것
찾기"다. 웹으로 같은 네 단계를 한 번 더 돌리면 공통기준 2절 끝문단(실물로 하는 일을
웹으로 되풀이하지 않는다)에 바로 걸린다.

활동2·활동3은 학급 기기의 받아쓰기와 번역을 그대로 쓴다. 번역 되돌리기는 외부
API 없이는 흉내밖에 못 내고, 흉내 낸 번역 결과를 화면에 띄우면 학생이 그것을 실제
결과로 옮겨 적게 된다. 결과를 미리 정해 두지 않는다는 10절 5번을 어긴다.

**판단이 갈린 지점.** 마이크로 자기 목소리를 막대와 숫자로 바꾸어 보여 주는 조각은
종이로 못 하는 일이라 기준 1번을 세게 넘긴다. 그러나 (가) 그 조각이 보여 줄 "가장
비슷한 것 찾기"를 B17에서 이미 막대로 보고, (나) 이 차시는 목소리를 남기지 않는
것이 지도 요점이라 마이크를 켜는 화면을 하나 더 두는 값이 크지 않다고 보았다.
B17을 먼저 써 보고 학급에서 아쉬움이 남으면 그때 다시 판정할 일로 남긴다.
