# B05 체험 설계 — 순서도 두 경우로 시험하기

## 0. 만들까 말까

**만든다.**

순서도를 그리는 일은 종이가 낫고 여기서 옮기지 않는다. 대신 **내가 이어 둔 갈래를
컴퓨터가 그대로 따라가 결과를 내놓는 일**은 종이로 안 된다. 종이에서는 자기가 그린
길을 자기가 읽으므로 머릿속 규칙이 끼어들어 잘못된 연결을 그냥 지나친다(2절 1).

예·아니요를 맞바꾸면 두 경우의 결과가 곧바로 뒤바뀌고, 한 경우만 돌렸을 때는
멀쩡해 보인다는 점이 기록 두 줄로 남는다(2절 2). 이것이 이 차시 정리 물음
"한 가지 경우만 시험하면 무엇을 놓칠 수 있는지"와 바로 닿는다.

## 1. 과정안 어디에 붙는가

B05 10차시 활동3 「두 가지 경우로 잘못된 곳 찾기」(15분) **뒤**, 활동4 앞.
학생이 종이에서 잘못된 순서도를 따라가 본 다음, 5~7분 동안 같은 일을 화면에서
두 경우로 돌려 견준다. 자기 순서도를 화면에 옮겨 그리게 하지 않는다.

## 2. 한 문장

마름모에서 나가는 예·아니요를 맞바꾸면, 같은 책 두 권이 서로 다른 끝으로 간다.

## 3. 화면 (1화면)

| | 보이는 것 | 학생이 하는 것 | 넘어가는 조건 |
|---|---|---|---|
| 1 | 도서관 순서도 한 장, 조작 버튼 넉 장, 기록 두 줄 | 갈래를 바꾸고 두 경우를 차례로 넣어 본다 | 없음. 한 화면에서 끝난다 |

책을 넣으면 시작에서부터 도형이 한 칸씩 밝아지며 내려가고, 마름모에서 지금 이어진
갈래를 따라 꺾인다. 끝에 닿으면 무슨 일이 일어났는지 기록칸에 한 줄로 쌓인다.
두 경우의 줄이 나란히 남아야 갈래가 뒤바뀐 것이 보인다.

**판정하지 않는다.** 화면은 맞았다·틀렸다를 말하지 않고 일어난 일만 적는다.
규칙과 견주는 일은 학생이 활동지에서 한다(4절 퀴즈 금지).

## 4. 조작과 값

| | |
|---|---|
| 조절하는 값 | 마름모에서 나가는 두 갈래의 예·아니요 자리 **하나** |
| 범위 | 두 가지 (바른 연결 / 뒤바뀐 연결) |
| 기본값 | **뒤바뀐 연결** — 과정안 활동3의 잘못된 순서도 카드와 같다 |
| 결과 반영 | 빌릴 수 있는 책이 예약 안내로, 빌릴 수 없는 책이 책 건네기로 간다 |

실행은 두 가지다(빌릴 수 있는 책 / 빌릴 수 없는 책). 주된 조작을 하나로 두라는
5-2와 다르게 하는 자리인데, 한 경우만 돌 수 있으면 이 차시의 알맹이인 "두 경우를
다 시험한다"가 무너진다. 그래서 일부러 둘로 두고 기록칸도 두 줄로 나눴다.

| 자리 | 문구 | 글자 |
|---|---|---|
| 제목 | `도서관 순서도 시험` | 9 |
| 버튼 | `갈래 바꾸기` | 6 |
| 버튼 | `빌릴 수 있음` | 7 |
| 버튼 | `빌릴 수 없음` | 7 |
| 버튼 | `다시 하기` | 5 |
| 도형 글 | `시작` `상태 확인` `빌릴 수 있나?` `기록 남기기` `책 건네기` `예약 안내` `끝` | 2~8 |
| 기록 (있음) | `있음 → 책 건네기` | 9 |
| 기록 (없음) | `없음 → 예약 안내` | 9 |
| 관찰 물음 | `두 줄이 바뀌었나요?` | 11 |

한 화면 합계는 공백까지 220자 안쪽이다.

## 6. 연습 모드

외부에서 가져오는 것이 없다. 카메라·마이크·저장소를 쓰지 않는다. 인터넷을 끊어도
그대로 열린다. 그래서 연습 모드를 따로 두지 않는다.

## 7. 만드는 방법

외부 라이브러리 없음. 순수 HTML·CSS·JS 단일 파일. 순서도는 인라인 SVG 한 장이고
도형 채움색과 흐름선 굵기만 JS가 바꾼다.

```
상태 = { 뒤바뀜: true, 도는중: false, 기록: {있음:null, 없음:null} }
길(빌릴수있나) =
   실제갈래 = 뒤바뀜 ? !빌릴수있나 : 빌릴수있나
   실제갈래 ? [시작,상태확인,마름모,기록남기기,책건네기,끝]
            : [시작,상태확인,마름모,예약안내,끝]
넣기(빌릴수있나):
   도는중이면 무시
   도는중=true, 모든 도형 끄기
   길의 도형을 380ms 간격으로 하나씩 켠다
   끝나면 기록[경우] = 마지막 처리 이름, 도는중=false
갈래바꾸기(): 도는중이면 무시. 뒤바뀜 = !뒤바뀜. 예·아니요 라벨 두 개를 맞바꾼다.
             기록 두 줄을 지운다(갈래가 달라졌으니 앞 기록은 뜻이 없다)
다시하기(): 뒤바뀜=true, 기록 비움, 도형 모두 끄기
```

`prefers-reduced-motion`이면 도형을 한 칸씩 켜지 않고 길 전체를 한 번에 켜고
기록만 남긴다.

**포인트색은 그린 `#12B76A` 하나다.**

## 9. 디버깅

8-2 점검표에 더해 이 차시만의 항목.

- [ ] 도는 중에 다른 버튼을 눌러도 두 갈래가 한꺼번에 밝아지지 않는다.
- [ ] 갈래를 바꾸면 앞서 남은 기록 두 줄이 함께 지워진다(옛 결과가 섞이지 않는다).
- [ ] 같은 경우를 두 번 넣으면 기록 줄이 쌓이지 않고 덮어 쓰인다.
- [ ] 다시 하기를 누르면 갈래가 뒤바뀐 처음 상태로 돌아온다.
- [ ] 화면에 맞음·틀림 표시가 없다.
