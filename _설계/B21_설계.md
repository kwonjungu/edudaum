# B21 체험 설계 — 질문 하나에 몇 마리

## 0. 만들까 말까

**만든다.**

- 질문 다섯 개가 지금 남은 후보를 각각 몇 대 몇으로 가르는지 **다섯 개를 한꺼번에** 보여 줄 수 있다. 종이로는 한 질문을 던지고 세어 본 뒤에야 다음 질문을 고를 수 있어서, 한 판을 끝내기 전에는 견줄 거리가 없다.
- 질문을 누르면 남은 후보 수가 즉시 줄고 질문 수가 올라간다. 되돌리기로 같은 동물에 대해 다른 질문 순서를 다시 걸어 볼 수 있어서 **두 판 견주기**가 5분 안에 된다.

**되돌아본 점.** 남은 후보 수를 세는 일(활동2)과 가지 그림을 그리는 일(활동3)은 학생이 종이로 하는 본론이다. 그래서 이 웹은 **속성표를 보여 주지 않는다.** 학생이 채워야 할 칸을 미리 채워 놓지 않기 위해서다. 웹이 그리는 가지 그림도 학생이 지나온 길 한 줄기뿐이고, 학생이 그릴 전체 그림을 대신 그려 주지 않는다.

## 1. 과정안 어디에 붙는가

- 블록 B21, 13~14차시. 활동2 "질문마다 남은 후보 수 세기"를 **종이로 끝낸 뒤**, 활동3 가지 그림을 그리기 직전 5분.
- 활동1(속성표 채우기) 앞에서는 열지 않는다. 활동1의 판정을 웹이 대신해 버린다.
- 교실에서 5분.

## 2. 한 문장

어느 질문을 고르느냐에 따라 **남은 후보 수가 몇으로 줄어드는지**, 그래서 **질문을 몇 번 해야 하는지**가 달라진다.

## 3. 게임 (2화면, 한 쪽에 세로로)

2026. 9. 17. 관찰 도구에서 게임으로 다시 짰다. **해내야 할 것**: 질문 다섯 번 안에 몰래 고른
동물을 한 마리로 좁혀라. 화면을 열면 후보 8~12마리 가운데 하나가 그 자리에서 몰래 뽑힌다.

| 화면 | 보이는 것 | 학생이 하는 것 | 제약 |
|---|---|---|---|
| ① 남은 후보 | 남은 수·질문 수(N/5), 이번 판 후보 이름(빠진 것은 줄이 그어진다) | 줄어드는 것을 본다 | 판마다 후보 수가 8~12로 다시 뽑힌다 |
| ② 질문 고르기 | 질문 다섯 개(문구만, 갈리는 수는 안 보인다) | 질문을 눌러 바로 묻는다 | 질문은 다섯 번까지·한 질문은 한 번만 |

**예상은 구조로 강제한다.** 어느 질문이 몇 대 몇으로 가르는지 **누르기 전에는 안 보인다.**
눌러야 드러난다 — "질문을 고를 때마다 남은 후보 수가 몇으로 줄어들지 미리 보이면 안 된다"는
지시를 그대로 구현했다. 질문 자체가 짚기이고 각 질문은 판마다 한 번만 쓸 수 있다(무르지 못함).
다섯 번을 다 쓰거나 후보가 하나가 되면 판이 잠긴다.

## 4. 조작과 값

- 조절하는 값: **어느 질문을 고르는가** 하나. 판마다 다섯 번까지.
- 질문 다섯 개는 과정안 활동1의 속성 다섯 가지 그대로다. `날개가 있어요? / 물속에서 살아요? / 다리가 넷이에요? / 다리가 여섯이에요? / 사람이 길러요?`
- 동물 전체 16마리: 개·고양이·소·사자·코끼리·거북·닭·앵무새·참새·독수리·나비·잠자리·금붕어·상어·고래·문어. 판마다 그 가운데 **8~12마리를 무작위로 뽑아** 후보로 삼고, 찾을 동물도 그 후보 안에서 무작위로 정한다. 직전 판과 같은 후보·목표면 다시 뽑는다.
- 이미 물은 질문은 다시 못 누른다(회색 처리, 체크 표시). 갈리는 수가 0/전부여도 미리 잠그지 않는다 — 눌러 보고 "거의 안 줄었다"를 겪는 것이 이 차시의 알맹이다(다리가 여섯인가요는 대개 2/14 근처로 갈린다).
- `다시 하기`는 **같은 후보·같은 목표**로 질문 수만 0으로 되돌린다. 같은 동물에게 다른 질문 순서를 걸어 두 판을 견줄 수 있다. `다음 판`은 후보·목표를 통째로 새로 뽑는다.

## 7. 만드는 방법

- 순수 JS. 외부 라이브러리 **없음**. 가지 그림은 인라인 SVG를 직접 그린다.
- 동물 16마리의 속성은 0/1 배열 상수. 질문은 속성 번호 하나를 가리킨다.

```
pool = 0..15, target = 무작위 하나
split(q)  = [pool 가운데 q가 1인 수, 0인 수]
ask(q)    : history에 pool과 steps를 밀어 넣고
            ans = target의 q값
            pool = pool 가운데 q값이 ans와 같은 것
            steps에 {질문, 답, 예 수, 아니요 수, 남은 수} 추가
done()    : pool이 1 이하거나, 어느 질문도 양쪽이 0이 아니게 못 가르면 끝
되돌리기  : history에서 하나 꺼내 pool과 steps를 되돌린다
```

**속성이 같은 동물이 남는다.** 개·고양이·소는 다섯 속성이 모두 같아서 질문 다섯 개로는 한 마리까지 좁혀지지 않는다. 이것을 오류로 처리하지 않고 `더 갈라 줄 질문이 없어요`로 정직하게 멈춘다. 과정안 활동4의 "막히는 지점"과 정리의 "새 자료가 들어와 통하지 않을 때"로 이어진다.

| 재는 것 | 상한 | 실제 |
|---|---|---|
| 첫 조작까지 | 30초 안 | 열자마자 질문 다섯 개가 보인다 |
| 화면 수 | 3 이하 | 3 |
| 한 화면의 조작 요소 | 5 이하 | 질문 화면 5 + 보조 2 (아래 까닭) |
| 한 번에 바꾸는 값 | 1 | 1 (질문 하나) |
| 전체 체험 시간 | 5~10분 | 5분 |
| 새로 배우는 조작법 | 0 | 0 (누르기만) |

**기준과 다르게 한 곳 (공통기준 10-6).** 질문 버튼 5개와 같은 칸에 되돌리기·다시 하기 2개를 두어 조작 요소가 7개다. 질문 다섯 개는 과정안 활동1의 속성 다섯 가지를 그대로 옮긴 것이라 줄이면 `다리가 여섯이에요?`(2/14)라는 가장 좋은 보기가 사라진다. 되돌리기와 다시 하기는 주된 조작이 아니라 보조이고, 질문 줄과 시각적으로 떼어 놓았다.

### 남은 것
