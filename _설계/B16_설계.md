# B16 체험 설계 — 예시를 옮겨 보기

## 0. 만들까 말까

**만든다.**

예시를 바꾸면 거기서 찾은 규칙이 바뀐다는 것은 종이 카드로는 확인할 수 없다.
학생이 규칙을 다시 찾는 데만 몇 분이 들고, 짝마다 결과가 달라 견줄 기준이 없다.
화면은 예시 한 장을 옮기는 즉시 규칙과 새 카드 판정을 다시 내놓는다.

교실에서 하는 일(규칙표로 판정, 스스로 규칙 찾기, 새 카드 판정)을 되풀이하지 않는다.
웹이 맡는 것은 학생이 손으로 할 수 없는 **다시 찾기**뿐이다. 5분 안에 끝나고
설치·서버·외부 호출이 없다.

## 1. 과정안 어디에 붙는가

- 블록 B16 (3~4/32차시), 4차시 **활동3 뒤 · 활동4 앞**.
- 활동3에서 두 방식의 판정을 기록표에 다 적은 뒤에 연다. 활동4의 "예시에서 찾은
  규칙이 치우칠 수 있다"를 쓰기 전에 근거를 눈으로 잡는 자리다.
- 교실에서 **5분**. 실물 카드 활동 뒤에 붙는다.

## 2. 한 문장

예시 카드 한 장을 다른 상자로 옮기면, 기계가 찾아내는 규칙이 바뀌고 새 카드 세 장의
판정도 따라 바뀐다.

## 3. 화면 (2026. 9. 17. 게임으로 다시 짠다)

**1화면, 두 구획.** 값을 바꾸면 결과가 바로 보이는 관찰 도구였던 것을,
판을 뽑고 → 세 장 모두 짚고(무르지 못함) → 확인해야 상자로 들어가는 구조로 바꾼다.

| 구획 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 예시 카드 | 1상자·2상자에 나뉜 예시 카드 4장. **판마다 나뉜 모양이 새로 나온다** | 카드를 눌러 옆 상자로 옮긴다(자유롭게, 여러 번) |
| 새 카드 | 새 카드 3장, 각 장마다 `1상자`/`2상자` 짚기 버튼 두 개 | 세 장 모두 상자를 짚는다 — **첫 짚기부터 예시 카드는 잠긴다** |

세 장을 다 짚어야 `확인하기`가 풀린다. 누르면 그 순간의 예시 배치로 규칙을 다시 찾고,
새 카드 세 장이 차례로(약 0.26초 간격) 실제로 가는 상자로 들어간다. 빗나간 장이 있으면
`몇 장이 달랐는지만` 적는다.

## 4. 조작과 값

- 조절하는 값 둘: **예시 카드의 자리**(확인 전까지 자유)와 **새 카드 세 장의 짚은 상자**(한 번 정하면 못 무름).
- 카드 열두 가지(칠함/안칠함 × 큼/작음 × 동그라미/네모/세모)에서 판마다 예시 4장·새 카드 3장을
  겹치지 않게 그 자리에서 뽑는다. 값을 미리 표로 적어 두지 않는다.
- 예시 4장은 각각 동전 던지듯 1상자·2상자에 뿌려진다(한쪽으로 몰릴 수도 있다).
- 기계가 하는 일: 칠하기 → 크기 → 모양 차례로, 두 상자의 값이 **하나도 겹치지 않는**
  첫 특징을 규칙으로 삼는다. 겹치지 않는 특징이 없으면 `못 찾음`, 한 상자가 비면
  `한쪽이 비었어요` — 이때 새 카드 셋은 모두 `어디에도 안 맞아요`로 남는다(상자로 들어가지 않는다).
- 확인 결과: `셋 다 짚은 대로 갔어요` / `한 장이 달리 갔어요` / `두 장이 달리 갔어요` / `세 장이 달리 갔어요`.
  `맞았어요`류 표현은 쓰지 않는다.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 | 글자 |
|---|---|---|
| 제목 | 예시를 옮겨 보기 | 8 |
| 부제 | 카드를 옮기고 새 카드를 짚어요 | 14 |
| 소제목 | 예시 카드 / 새 카드 | 4·3 |
| 라벨 | 1상자 / 2상자 | 3·3 |
| 안내 | 카드를 눌러 옆 상자로 옮겨요 / 카드는 잠겼어요 | 13·6 |
| 안내 | 세 장 모두 짚어요 / 확인하기를 눌러요 | 8·8 |
| 결과 | 어디에도 안 맞아요 | 8 |
| 결과 | 셋 다 짚은 대로 갔어요 / 한 장이 달리 갔어요 / 두 장이 달리 갔어요 / 세 장이 달리 갔어요 | 10·8·8·8 |
| 버튼 | 확인하기 / 다시 하기 / 다음 판 | 4·5·4 |

화면 전체 글자 수는 구획별로 감사기 상한(250자) 아래다(자동 감사로 확인).

## 6. 연습 모드

바깥에서 가져오는 것이 없다. 인터넷을 끊어도 같게 열린다. 카메라·마이크를 쓰지 않아
권한을 묻지 않는다. 그러므로 따로 연습 모드를 두지 않았다 — 막힐 것이 없다.

## 7. 만드는 방법

외부 라이브러리 없음. CDN 없음. 바닐라 JS 한 파일. 카드 그림은 인라인 SVG.

```
카드마다 fill/size/shape 세 값을 data-*로 들고 있다
누르면 그 카드를 반대쪽 slot으로 appendChild 한다 (화면을 다시 그리지 않는다)

findRule():
  한쪽 상자가 비면 -> '한쪽이 비었어요'
  [fill, size, shape] 차례로:
     v1 = 1상자의 값 모음, v2 = 2상자의 값 모음
     겹치는 값이 없으면 -> 그 특징을 규칙으로 돌려준다
  끝까지 없으면 -> '못 찾음'

새 카드 판정:
  카드의 그 특징 값이 v1에 있으면 1상자, v2에 있으면 2상자, 둘 다 아니면 알 수 없음
  앞서 적어 둔 판정과 다르면 그 카드에만 '바뀜'을 붙인다
```

`처음으로`는 네 장을 처음 자리로 되돌리고 `바뀜` 표시를 모두 지운다.

|---|---|---|

| 새로 배우는 조작법 | 0 | 0 (누르기만) |

## 9. 디버깅

공통기준 8-2 점검표에 이 차시에서 더 본 것:

- 카드를 빠르게 여러 번 눌러도 자리가 어긋나지 않는가 (DOM 이동이라 쌓이지 않는다).
- 네 장을 모두 한쪽으로 몰았을 때 `한쪽이 비었어요`가 뜨고 화면이 깨지지 않는가.
- `바뀜` 표시가 바뀐 카드에만 붙고, `처음으로` 뒤에는 사라지는가.
- 카드 버튼에 글자가 없으므로 `aria-label`이 자리(1상자/2상자)까지 알려 주는가.
