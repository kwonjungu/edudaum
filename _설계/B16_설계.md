# B16 체험 활동 설계 — 기계와 인공지능 짝 가르기

2026. 10. 11. 교사가 고친 지도안(검토반영본)에 맞춰 다시 쓴다. 앞선 '예시를 옮겨 보기'는
지도안에서 규칙표·예시 카드·새 카드 활동이 모두 빠져 붙을 자리가 없어졌다(옛 설계는 git 기록에 남는다).
사람에게 보이는 이름은 '게임'이 아니라 **체험 활동**이다. 짜임은 `판이 나온다 → 짚는다 → 확인한다` 그대로다.

## 0. 지도안의 어느 활동에 붙나

**3차시 전개 · 활동2. 판단의 유무로 사례 구분하기 (20분)** 의 앞 두 줄 **뒤**, 비교표에 붙이기 **앞**에 5~7분.

> - 사례 카드 여덟 장을 짝 지어 비교하기: 자동문↔사진 속 얼굴 묶기, 주방 타이머↔영상 추천,
>   계산기↔손동작 알아보기, 복도 전등↔걸음 수 세기
> - 짝마다 "정해진 조건 하나로 반응하는가, 여러 가지를 보고 스스로 판단하는가" 질문으로 가르기
> - 비교표에 '단순히 반응하는 기계 / 스스로 판단하는 인공지능'으로 나누어 붙이고 까닭 한 줄 적기
> - 헷갈리는 카드(걸음 수 세기 등)는 모둠 토의 뒤 '더 알아봐야 함'에 두기

유의점도 그대로 옮긴다.

> △ '센서가 있다 = 인공지능'이 아님을 자동문·복도 전등 사례로 확인한다.
> △ 걸음 수 세기처럼 생각이 나뉘는 사례는 단정하지 않고 '더 알아봐야 함'에 둔다.

- 왜 웹인가: 종이 카드는 지도안 짝 네 개로 끝난다. 화면은 짝을 **섞어** 새 짝(자동문↔복도 전등처럼
  둘 다 같은 칸일 수 있는 짝)을 계속 내고, 카드마다 `센서 있음` 딱지를 붙여 '센서 = 인공지능' 생각을
  일부러 건드린다. 짚은 뒤 확인하면 활동1 비교 활동지의 '받아들이는 것 → 하는 일'이 열린다.
- 대신하지 않는 것: 활동1(소음 신호등 박수·동작 모델 시연과 비교 활동지), 비교표에 붙이고 까닭 한 줄 쓰기,
  모둠 토의. 화면 상시 한 줄 `까닭은 비교표에 한 줄로 써요`.

## 1. 다섯 칸

| 칸 | 이 활동 |
|---|---|
| 목표 | 이번 짝 두 장을 구분 기준으로 따진 칸에 놓아라 |
| 실패 | `센서 있음`에 끌려 기계를 인공지능 칸에 놓으면 기준과 반대 칸이 된다 |
| 예상 | 두 장을 다 짚어야 `확인하기`가 풀린다. 확인 전엔 '받아들이는 것 → 하는 일'이 가려져 있다 |
| 제약 | 칸은 셋뿐이다. 확인하면 그 판은 더 못 바꾼다 |
| 되풀이 | 지도안 짝 네 개를 섞인 차례로 낸 뒤, 여덟 장을 섞은 새 짝을 판마다 낸다 |

다섯 칸 모두 찬다.

## 2. 한 문장

판마다 사례 카드 두 장이 짝으로 나오면, 카드마다 세 칸(기계 / 인공지능 / 더 알아봐야 함) 가운데 하나를
짚고 확인해 '받아들이는 것 → 하는 일'과 기준 칸을 본다.

## 3. 화면 (1화면, 두 구획)

| 구획 | 보이는 것 | 학생이 하는 것 |
|---|---|---|
| 이번 짝 | 질문 한 줄, 카드 두 장(이름, `센서 있음` 딱지), 카드마다 칸 버튼 셋 | 카드마다 칸 하나를 짚는다. 확인 전엔 바꿀 수 있다 |
| 확인 | `확인하기`(두 장 다 짚기 전 잠금) · `다시 하기` · `다음 짝`, 결과 한 줄, 상시 한 줄 | 확인하면 두 카드 아래에 '받아들이는 것 → 하는 일'과 딱지가 차례로(0.3초 간격) 열린다 |

## 4. 조작과 값

카드 여덟 장. '받아들이는 것 → 하는 일'은 활동1 비교 활동지 앞 두 칸을 따른다.

| 짝 | 카드 | 센서 | 받아들이는 것 → 하는 일 | 기준 칸 |
|---|---|---|---|---|
| 1 | 자동문 | 있음 | 다가오는 사람 → 늘 같게 문을 연다 | 기계 |
| 1 | 사진 속 얼굴 묶기 | — | 사진 속 생김새 → 같은 사람끼리 묶는다 | 인공지능 |
| 2 | 주방 타이머 | — | 맞춰 둔 시간 → 시간이 되면 늘 같게 울린다 | 기계 |
| 2 | 영상 추천 | — | 내가 본 영상들 → 볼 만한 영상을 골라 준다 | 인공지능 |
| 3 | 계산기 | — | 누른 숫자 → 정해진 대로 셈한다 | 기계 |
| 3 | 손동작 알아보기 | 있음 | 손의 움직임 → 어떤 동작인지 알아본다 | 인공지능 |
| 4 | 복도 전등 | 있음 | 지나가는 움직임 → 늘 같게 불을 켠다 | 기계 |
| 4 | 걸음 수 세기 | 있음 | 몸의 흔들림 → 걸음으로 센다 | 정하지 않음 |

- 판 뽑기: 처음 네 판은 지도안 짝 네 개를 섞은 차례로. 다섯째 판부터 여덟 장에서 두 장을 그 자리에서 뽑는다
  (지도안 짝과 같거나 직전 판과 같은 두 장이면 다시 뽑는다). 짝 안 두 장의 왼쪽·오른쪽도 판마다 섞는다.
- 칸 버튼: `기계` · `인공지능` · `더 알아봐야 함` (카드마다 세로로 셋. 칸 이름표에 지도안의 온 이름을 한 번 적는다).
- 확인 뒤 카드마다 딱지:
  - 기준 칸과 같은 칸 → 줄만(딱지 없음).
  - 기준과 **반대** 칸(기계↔인공지능) → `구분 기준으로는 ○○ 칸`.
  - `더 알아봐야 함`에 둔 기준 있는 카드 → `구분 기준으로는 ○○ 칸 · 모둠에서 따져 봐요`.
  - 걸음 수 세기 → 어느 칸이든 `생각이 나뉘는 카드예요 · 모둠에서 따져 봐요` (단정하지 않음).
- 결과 한 줄(얼마나 떨어졌는지만): 반대 칸 수 0 → `구분 기준과 반대 칸에 놓은 카드는 없어요`,
  1·2 → `구분 기준과 반대 칸에 놓은 카드가 한 장이에요`·`… 두 장이에요`.
  `맞았어요`·`틀렸어요`·`잘했어요`, 맞힌 판 수, 점수는 없다.
- `다시 하기`: 확인 전 이 판에서 짚은 것만 지운다. `다음 짝`: 새 판.

## 5. 글자 (그대로 쓸 문구)

| 자리 | 문구 |
|---|---|
| 제목 | 기계와 인공지능 짝 가르기 |
| 부제 | 짝마다 두 장을 칸에 짚고 확인해요 |
| 소제목 | 이번 짝 / 확인 |
| 질문 | 정해진 조건 하나로 반응하나요, 여러 가지를 보고 스스로 판단하나요? |
| 칸 이름표 | 기계: 단순히 반응하는 기계 · 인공지능: 스스로 판단하는 인공지능 |
| 안내 | 두 장 모두 칸을 짚어요 / 확인하기를 눌러요 |
| 상시 | 까닭은 비교표에 한 줄로 써요 |
| 버튼 | 확인하기 / 다시 하기 / 다음 짝 |

## 7. 만드는 방법

바닐라 JS 한 파일, 외부 라이브러리 없음.

```
CARDS = [{n, pair, sensor, io, ref}]   ref: 'm' 기계 | 'a' 인공지능 | null 나뉨
queue = shuffle([1,2,3,4])  // 지도안 짝 먼저
newRound(): queue 가 남았으면 그 짝, 아니면 무작위 두 장(지도안 짝·직전 판 아님) ; 좌우 섞기
pick(slot, k): 확인 전이면 guess[slot]=k
confirm(): guess 둘 다 있을 때만 ; 반대 칸 수 세기 ; 카드 두 장 차례로 열기
```

## 교사 검토 (2026-10-11)

- 질문을 지도안 문구 그대로 `정해진 조건 하나로 …`로, 셋째 칸을 지도안 칸 이름 `더 알아봐야 함`으로 고쳤다.
- 딱지·결과 줄의 `기준`을 지도안 낱말 `구분 기준`으로 바꿨다.
- 칸 이름표를 비교표 머리글(단순히 반응하는 기계 / 스스로 판단하는 인공지능) 그대로 적었다.
- 걸음 수 세기 딱지에도 `모둠에서 따져 봐요`를 붙여 지도안의 '모둠 토의 뒤 더 알아봐야 함'과 잇는다.
- 주방 타이머 줄에 `늘 같게`를 넣어 기계 카드 넷이 같은 말로 '정해진 반응'을 드러내게 했다.
- 실물(소음 신호등·동작 모델 시연, 종이 비교표, 까닭 쓰기)을 대신하지 않음을 다시 확인했다.

## 재미 검토 (2026-10-11)

`판이 나온다 → 짚는다 → 확인한다`, 짚기 전 확인 잠금, 확인 전엔 바꿀 수 있음을 다시 보고 더한 것:

- 소제목 옆에 `지도안 짝 1/4` → `섞은 짝`을 띄워 끝(지도안 짝 네 개)과 그 뒤 되풀이할 까닭을 보인다. 맞힌 수는 세지 않는다.
- 섞은 짝의 절반은 `센서 있음` 카드 두 장끼리 낸다(자동문·복도 전등 ↔ 손동작 알아보기·걸음 수 세기). 지도안 유의점의 '센서 = 인공지능 아님'에 걸려 넘어질 자리를 일부러 만든다.
- 확인 뒤 기준과 다른 카드는 테두리가 바뀌고, 구분 기준 칸 버튼에 점선 테두리가 생긴다 — 얼마나 떨어졌는지를 글자 말고 자리로도 보인다.
- 확인이 끝나면 `다음 짝`이 주 버튼 색으로 바뀌고 초점이 그리로 간다.
