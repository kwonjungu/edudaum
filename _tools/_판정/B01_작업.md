# B01 작업 (2026-10-29)
바꾼 것: B01/index.html
1. 물건마다 SVG 그림 6종과 카드 뒤집기 움직임. 조각이 칸에 떨어질 때 내려앉는 움직임.
2. 진행 막대(넣은 조각 수 4칸). 확인 뒤 조각 왼쪽에 칸 색(하늘=하드웨어, 민트=소프트웨어) 띠 추가(글자 딱지는 그대로).
3. 예상을 걸 때, 네 조각을 다 넣을 때, 다시 하기를 누를 때 캐릭터가 상황을 짚는 말을 한다. 확인 뒤 말은 두 칸이 어떻게 찼는지 되묻는 말로.
4. 옛 강조색(#FF385C 등) SVG 직접 색을 변수로. 360~400px에서 단추 글자 줄임, 가로 넘침 방지.
5. 사실·교육 정합성 점검: 마이크로비트 LED 25개·A/B 버튼, 조각 내용은 지도안(하드웨어=만질 수 있는 몸체·부품, SW=미리 정해 준 명령)과 일치. 고칠 오류 없음.
다섯 칸 전→후: 목표 O→O, 실패 O→O, 예상 O→O(예상 뒤 말 추가), 제약 O→O, 되풀이 O→O(카드 그림·뒤집기로 새 판 느낌 강화).
