- 목표: 있음 → 있음(걸었던 기준 확인)
- 예상: 있음(기준 걸기) → 있음 + 새 판마다 다시 걺
- 제약: 보통(아홉 칸 다 채워야 걸기) → 같음
- 실패: 약함(내가 넣은 표시뿐이라 늘 맞아떨어짐) → 새 판에서 걸었던 기준이 빗나갈 수 있음
- 되풀이: 없음(다시 하기뿐) → 새 판 받기
