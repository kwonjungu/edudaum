# B17 작업 (2026-10-29)
바꾼 것: B17/index.html
1. 책 색(fun.css)으로 옮김. 옛 강조색·하드 그림자 변수를 지우고 하늘·민트·노랑 변수 사용. 캐릭터 띠(말랑쌤)와 도장을 붙임.
2. 예상 칸 추가: 조건을 고른 뒤 `공이 앞서요 / 모자라요` 가운데 하나를 걸어야 확인하기가 열린다. 확인 뒤 캐릭터가 예상과 같았는지 짚고, 아슬아슬하면 다시 하기를 권한다.
3. 눈에 보이는 움직임: 고르지 않은 조건 단추는 자물쇠 그림에 점선으로 잠기고, 단추마다 단계 점 4개가 보인다. 판 시작 때의 사진이 작은 `처음` 쪽지로 옆에 남는다. 막대는 천천히 차오르고 1등 칸은 색이 바뀐다(공이면 민트). 막대 앞에 공·상자·컵 SVG 그림.
4. 빗나갔을 때(한 가지로는 모자라요) 사진이 흔들리고 맞아떨어지면 조각이 터진다. 한 판을 끝낼 때 Fun.stamp 한 번.
5. 사실·정합성 점검: 조건 셋(거리·배경·밝기)은 6차시 활동3(거리·무늬 천·창 등지기)과 맞고 사물만 그려 얼굴을 다루지 않는다. 계산식·판정 문구는 설계서 그대로. 고칠 오류 없음. 360px 가로 넘침 방지(main overflow-x).
다섯 칸 전→후: 목표 O→O, 실패 O(모자라요)→O, 예상 X→O(걸기 필수), 제약 O(잠긴 조건 둘)→O(잠금이 눈에 보임), 되풀이 O(새 판 뽑기)→O.
