# B27 작업 (2026-10-29)
바꾼 것: B27/index.html (fun.css·fun.js 연결, data-block=B27)
1. 담을 때마다 24x24 미리보기 칸이 줄(20칸)에 쌓인다. 약속한 조건은 초록 테두리, 다른 조건은 노란 점선. 위·옆 글자와 배경(흰 종이·책상) 띠가 붙는다. 방금 담은 칸은 튕긴다.
2. 각도·배경 단추에 SVG 그림, 사진 칸에 지금 조건 딱지. 약속 막대는 민트색으로 갈린다.
3. 지킴쌤이 상황을 짚는다(다른 조건이 담겼을 때, 약속 장수에 닿았을 때, 되돌릴 때, 새 판). 약속 장수에 닿으면 한 판에 한 번 도장(Fun.stamp)과 burst.
4. 사실 정합: 과정안 활동3 배경이 "흰 종이·책상"이라 "교실 바닥"을 "책상"으로 고침.
5. 버그: 다음 판이 앞 판 담은 것을 남겨 새 약속이 시작부터 채워지거나 앞 판이 섞임으로 세어지던 문제 -> 다음 판에서 비우고 조건 선택도 비움(설계서의 "담은 것은 그대로 둔다"와 다름). 카메라 허락 대기 중 담기가 흐린 까닭을 "카메라를 켜는 중이에요"로 안내. 사진 칸 높이 제한 완화.
다섯 칸 전->후: 목표 O->O, 실패 O->O(섞임이 줄에 보임), 예상 비움->비움(설계 의도: 약속을 먼저 보여 주고 조건은 학생이 고름), 제약 O->O, 되풀이 O->O(다음 판이 새 판).
