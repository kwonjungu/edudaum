# 에듀다움 체험 — 학교자율시간 5·6학년

학교자율시간 AI 교육과정(에듀다움) 과정안의 활동 하나를 **수업 중 5~10분** 동안
잠깐 만져 보는 웹이다. 설치 없이 브라우저로 열면 된다.

- 보기: https://kwonjungu.github.io/edudaum/
- 과정안 원본: 28블록 64차시(5·6학년 각 32차시)

## 이 웹이 하는 일

값을 바꾸면 결과가 달라지는 것을 **눈으로 보게** 한다. 그뿐이다.

수업을 대신하지 않는다. 마이크로비트·엔트리·실제 측정을 대체하지 않는다.
과정안에 있는 설명을 옮겨 적지도 않는다. 실물 활동의 **앞(예상)** 이나
**뒤(견주기)** 에 붙는 짧은 보조 도구다.

**스물여덟 차시에 하나씩 있다.** 다만 어느 쪽도 실물을 대신하지 않는다. 종이·몸·칠판이
본론인 활동은 그 **앞이나 뒤에 붙는 얇은 조각**만 맡는다. 무엇을 맡고 무엇을 맡지 않는지는
`_설계/BXX_설계.md`의 0절에 적혀 있다. 판정을 뒤집은 기록은 `_설계/_재판정_2026-09-17.md`에 있다.

`5~6차시`는 **교사 준비용**이다. 과정안이 그 블록에서 기기를 쓰지 않는다고 못박아 두어,
수업 중이 아니라 교사가 전날 자료를 짜는 자리로 만들었다.

## 구조

```
index.html          허브 (차시 목록, _tools/make_hub.py가 만든다)
_tools/blocks.py    블록↔차시 대응표 (표시의 단 하나의 근거)
BXX/index.html      차시 하나에 폴더 하나, 단일 파일
_공통기준.md         설계·구현이 지켜야 할 규격
_설계/BXX_설계.md    차시별 설계서 (만들지 않기로 한 것 포함)
_tools/             감사 하네스
assets/             공용 그림 (있을 때만)
```

- 서버·API 키·로그인·데이터베이스를 쓰지 않는다. 정적 호스팅에서 그대로 열린다.
- 학생 이름을 받지 않는다. 점수·순위를 만들지 않는다.
- 카메라·마이크는 화면에만 쓰고 저장하지 않으며 밖으로 보내지 않는다.

## 감사 하네스

내기 전에 세 검사를 모두 통과해야 한다. **하나라도 지적이 남으면 내지 않는다.**

```bash
npm install                      # puppeteer-core (설치된 Edge/Chrome을 그대로 씀)
python _tools/run_all.py         # 셋 다
python _tools/run_all.py B10     # 한 차시만
python _tools/run_all.py --no-head   # 브라우저 검사 빼고
```

| 검사 | 도구 | 보는 것 |
|---|---|---|
| 문법 | `_tools/jscheck.py` | `<script>`를 뽑아 `node --check` |
| 정적 | `_tools/audit.py` | 글자 상한, 개념 정의문, 퀴즈, 이모지 아이콘, CDN 허용 목록, 단일 파일, 44px, 되돌리기, `focus-visible`, `prefers-reduced-motion`, 개인정보 문구, 연습 모드, 이름 입력, 순위표, 미리 채운 값 |
| 헤드리스 | `_tools/headless.mjs` | 콘솔 오류, 첫 조작 요소의 위치·크기, 폭 360px 가로 넘침, 키보드 접근, 버튼을 눌렀을 때의 오류, 전체 글자 수, 화면 사진 |

결과는 `_tools/_감사보고.md`에 남는다. 화면 사진은 `_tools/_shot/`에 쌓인다.
**검사기를 고쳐서 통과시키지 않는다.**

## 허브 다시 만들기

```bash
python _tools/make_hub.py
```
차시 폴더를 훑어 카드를 세운다. 폴더가 없으면 저절로 빠진다.

## 만드는 규칙

`_공통기준.md`를 먼저 읽고, 만드는 순서는 `_정교화_프로세스.md`를 따른다. 요점만 옮기면,

- **만들까 말까**: 기본값은 만들지 않는다. 웹이 아니면 못 하는 것만 만든다.
- **어렵지 않게**: 첫 조작 30초, 3화면 이하, 한 번에 바꾸는 값 1개, 새 조작법 0개.
- **글자를 줄인다**: 한 화면 250자, 제목 20자, 버튼 10자. 개념 정의문과 퀴즈를 쓰지 않는다.
- **직관과 사용성**: 첫 화면에 바로 조작 요소, 주 조작 하나, 되돌리기 상시, 44px 터치,
  상태를 늘 보이게, 끌기 전용 금지, 확인창 금지.
- **안 될 때를 먼저 만든다**: 권한 거부·CDN 실패는 연습 모드로 넘어간다.
