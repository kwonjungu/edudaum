# 에듀다움 — 학교자율시간 SW·AI 교육과정 누리집

경기 AI 융합교육 에듀다움 교사연구회의 학교자율시간 교육과정(5학년 SW 32차시 · 6학년 AI 32차시)
누리집이다. 과정안(hwpx)을 단 하나의 원본으로 두고 계획서·주제별 활동·차시별 과정안 쪽을 만들며,
차시마다 연동 도구·교사 링크·수업 중 체험 게임을 잇는다. 설계는 `_설계/_누리집_종합설계서.md`에 있다.

- 보기: https://kwonjungu.github.io/edudaum/

| 쪽 | 주소 | 만드는 것 |
|---|---|---|
| 홈 | `/` | 네 갈래 입구, 64차시 지도 |
| 1) 계획서·성취기준 | `/plan/` | `make_site.py` |
| 2) 주제별 활동 내용 | `/topics/` | `make_site.py` |
| 3) 차시별 교수학습 과정안 | `/lessons/`, `/lessons/BXX/` | `make_site.py` ← `_data/lessons.json` ← hwpx |
| 연동 도구 | `/tools/` | `make_site.py` ← `_data/tools.json`, `_data/links.json` |
| 체험 게임 목록 | `/play/` | `make_site.py` |
| 체험 게임 | `/BXX/` | 사람이 만든다(아래 규칙) |

### 과정안이 바뀌었을 때

```bash
python _tools/export_plans.py "<과정안 hwpx 폴더>"          # _data/lessons.json, assets/plan/*.jpg
python _tools/public_copy.py "<hwpx 폴더>" "<공개용 폴더>"   # 개발자 칸 → 연구회 이름
powershell -File _tools/hwpx2pdf.ps1 -Src "<공개용 폴더>" -Out assets/pdf   # 한글 설치 PC
python _tools/public_copy.py --strip-pdf assets/pdf         # PDF 작성자 정보 비우기
python _tools/make_site.py                                  # 누리집 쪽 전부
python _tools/run_all.py                                    # 게임 3종 + 누리집 점검 0건
```

개발자 이름은 누리집·PDF 어디에도 싣지 않는다(`site_check.py` S8이 확인). 웹 쪽 HTML을 손으로 고쳐 과정안 문장을 바꾸지 않는다. 차시에 링크를 더 걸려면 `_data/links.json`,
도구를 더하려면 `_data/tools.json`을 고친다. 교사 개인 링크는 차시 쪽 「내 수업 링크」에 건다(브라우저에만 저장).

# 체험 게임 — 수업 중 5~10분

학교자율시간 AI 교육과정(에듀다움) 과정안의 활동 하나를 **수업 중 5~10분** 동안
잠깐 만져 보는 웹이다. 설치 없이 브라우저로 열면 된다.

- 보기: https://kwonjungu.github.io/edudaum/play/
- 과정안 원본: 28블록 64차시(5·6학년 각 32차시)

## 이 웹이 하는 일

**해내야 할 것을 하나 준다.** 판이 나오고, 답을 보기 전에 짚고, 확인한다.

짚기 전에는 확인 버튼이 잠긴다. 빗나가면 얼마나 떨어졌는지만 알려 준다.
점수도 등수도 맞힌 판 수도 세지 않는다. `맞았어요` `틀렸어요` `잘했어요`를 쓰지 않는다.
쪽마다 무엇을 해내게 할지는 `_게임설계.md`에 있다.

수업을 대신하지 않는다. 마이크로비트·엔트리·실제 측정을 대체하지 않는다.
과정안에 있는 설명을 옮겨 적지도 않는다. 실물 활동의 **앞(예상)** 이나
**뒤(견주기)** 에 붙는 짧은 보조 도구다.

**스물여덟 차시에 하나씩 있다.** 다만 어느 쪽도 실물을 대신하지 않는다. 종이·몸·칠판이
본론인 활동은 그 **앞이나 뒤에 붙는 얇은 조각**만 맡는다. 무엇을 맡고 무엇을 맡지 않는지는
`_설계/BXX_설계.md`의 0절에 적혀 있다. 판정을 뒤집은 기록은 `_설계/_재판정_2026-09-17.md`에 있다.

`5~6차시`는 **교사 준비용**이다. 과정안이 그 블록에서 기기를 쓰지 않는다고 못박아 두어,
수업 중이 아니라 교사가 전날 자료를 짜는 자리로 만들었다.

## 구조

```
index.html          누리집 홈 (_tools/make_site.py가 만든다)
play/ plan/ topics/ lessons/ tools/   누리집 쪽 (make_site.py)
_data/              과정안·성취기준·도구·링크 데이터
_tools/blocks.py    블록↔차시 대응표 (표시의 단 하나의 근거)
BXX/index.html      차시 하나에 폴더 하나, 단일 파일
_공통기준.md         설계·구현이 지켜야 할 규격
_설계/BXX_설계.md    차시별 설계서 (만들지 않기로 한 것 포함)
_tools/             감사 하네스
assets/             공용 그림 (있을 때만)
```

- 서버·API 키·로그인·데이터베이스를 쓰지 않는다. 정적 호스팅에서 그대로 열린다.
- 학생 이름을 받지 않는다. 점수·순위를 만들지 않는다.
- 카메라·마이크는 화면에만 쓰고 저장하지 않으며 밖으로 보내지 않는다.

## 감사 하네스

내기 전에 세 검사를 모두 통과해야 한다. **하나라도 지적이 남으면 내지 않는다.**

```bash
npm install                      # puppeteer-core (설치된 Edge/Chrome을 그대로 씀)
python _tools/run_all.py         # 셋 다
python _tools/run_all.py B10     # 한 차시만
python _tools/run_all.py --no-head   # 브라우저 검사 빼고
```

| 검사 | 도구 | 보는 것 |
|---|---|---|
| 문법 | `_tools/jscheck.py` | `<script>`를 뽑아 `node --check` |
| 정적 | `_tools/audit.py` | 글자 상한, 개념 정의문, 퀴즈, 이모지 아이콘, CDN 허용 목록, 단일 파일, 44px, 되돌리기, `focus-visible`, `prefers-reduced-motion`, 개인정보 문구, 연습 모드, 이름 입력, 순위표, 미리 채운 값 |
| 누리집 | `_tools/site_check.py` | 쪽·PDF 있음, 안 링크, 제목=학습 주제, 개인정보 꼴, https, 게임↔과정안 상호 링크 |
| 헤드리스 | `_tools/headless.mjs` | 콘솔 오류, 첫 조작 요소의 위치·크기, 폭 360px 가로 넘침, 키보드 접근, 버튼을 눌렀을 때의 오류, 전체 글자 수, 화면 사진 |

결과는 `_tools/_감사보고.md`에 남는다. 화면 사진은 `_tools/_shot/`에 쌓인다.
**검사기를 고쳐서 통과시키지 않는다.**

## 누리집·허브 다시 만들기

```bash
python _tools/make_site.py      # make_hub.py도 같은 일을 한다
```
체험 게임 목록은 `play/`에 있다. 차시 폴더를 훑어 카드를 세우고, 폴더가 없으면 저절로 빠진다.

## 만드는 규칙

`_공통기준.md`를 먼저 읽고, 만드는 순서는 `_정교화_프로세스.md`를 따른다. 요점만 옮기면,

- **만들까 말까**: 기본값은 만들지 않는다. 웹이 아니면 못 하는 것만 만든다.
- **어렵지 않게**: 첫 조작 30초, 3화면 이하, 한 번에 바꾸는 값 1개, 새 조작법 0개.
- **글자를 줄인다**: 한 화면 250자, 제목 20자, 버튼 10자. 개념 정의문과 퀴즈를 쓰지 않는다.
- **직관과 사용성**: 첫 화면에 바로 조작 요소, 주 조작 하나, 되돌리기 상시, 44px 터치,
  상태를 늘 보이게, 끌기 전용 금지, 확인창 금지.
- **안 될 때를 먼저 만든다**: 권한 거부·CDN 실패는 연습 모드로 넘어간다.
