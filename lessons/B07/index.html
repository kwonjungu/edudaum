13차시전개32분

활동1. 마이크로비트 살펴보고 연결하기 (12분)

  • 마이크로비트를 받아 앞면 LED 스물다섯 칸 세어 보기
  • A·B 버튼(앞면)·리셋 버튼(뒷면)·연결 단자(윗면) 짚어 보기
  • 데이터 전송용 케이블로 마이크로비트와 학생 기기 잇기
  • makecode.microbit.org에서 ‘새 프로젝트’를 만들고 이름 붙이기
  • 블록 꾸러미·작업 공간·모의 실행 화면 짚어 보기

활동2. 예제 따라 LED 그림 두 개 차례로 표시하기 (20분)

  • 작업 공간에서 ‘시작하면 실행’ 블록 찾기
  • [기본]의 ‘아이콘 출력’을 넣고 하트 고르기
  • ‘일시중지(ms) 1000’을 붙여 그림이 잠시 머물게 하기
  • ‘아이콘 출력’을 하나 더 붙여 웃는 얼굴 고르기
  • 모의 실행 화면에서 두 그림이 나오는 차례 확인하기
  • ‘다운로드’로 마이크로비트에 옮기고 리셋 버튼을 눌러 다시 보기
  • 붙인 차례를 번호로 적고 실행 결과를 한 문장으로 쓰기
준비물학생 기기, 마이크로비트 V2, 데이터 전송용 USB 케이블
자료실습 활동지, 따라 하기 예제 카드, [활동1] 기기 연결 도해
유의점충전 전용 케이블로는 코드가 옮겨지지 않으므로 구별해 나누어 준다.
유의점바로 옮겨지지 않으면 .hex 파일을 MICROBIT 드라이브로 끌어다 놓게 한다.
유의점기기가 부족하면 조작 차례를 정해 모두가 한 번씩 직접 옮기게 한다.
유의점메뉴와 블록 이름은 교사가 수업 전 실제 화면에서 확인한다.
유의점블록 찾기가 어려운 학생에게는 꾸러미 위치 도움 카드를 준다.
14차시전개33분

활동3. 순서 바꾸고 짝과 맞히기 놀이 (15분)

  • 마이크로비트를 잇고 지난 작품을 찾거나 예제 카드로 다시 만들기
  • 두 ‘아이콘 출력’ 블록의 자리를 바꾸기 전에 결과를 먼저 예상해 적기
  • 자리만 맞바꿔 옮기고 기기에 나온 차례를 실제 결과로 적기
  • 예상과 실제 결과가 같았는지 표에 표시하기
  • 원래 차례로 되돌려 옮기고 처음과 같은지 확인하기
  • 짝이 몰래 순서를 바꿔 옮기면 LED만 보고 블록 순서 맞히기

활동4. 해결단 LED 이름표 만들어 목에 걸기 (18분)

  • ‘LED 출력’ 칸을 눌러 모둠 기호를 그리고 세 컷 이상 차례 정하기
  • 예: 모둠 기호 → 일시중지 → 하트 → 문자열 출력 “TEAM1”
  • 모의 실행으로 확인한 뒤 옮기고 짝에게 보여 주기
  • 블록 순서가 결과를 어떻게 바꾸는지 한두 문장으로 쓰기
  • 작품을 저장하고 케이블을 뺀 뒤 배터리 팩 연결하기
  • 명찰 틀 창에 마이크로비트를 끼우고 목걸이 줄 달기
준비물배터리 팩(AAA 2개), 명찰 틀(LED 창 낸 골판지), 목걸이 줄, 마스킹테이프
자료순서 바꾸기 활동지, [활동3] 표시 차례 비교 도해
유의점명찰 창은 교사가 칼로 미리 내고, 학생은 가위와 테이프만 쓴다.
유의점배터리 팩은 선이 아니라 커넥터 몸통을 잡고 끼운다.
유의점순서는 한 번에 한 곳만 바꾸게 한다.
유의점순차 구조만 다루므로 ‘무한반복’과 버튼 블록은 쓰지 않는다.
유의점기기를 둘이 함께 쓰는 학급은 조작 차례를 나누고 기록은 각자 하게 한다.
유의점명찰 틀 솜씨는 평가하지 않고 LED 표시 순서만 본다.
유의점빨리 끝낸 학생은 ‘일시중지’ 값을 바꾸어 달라진 점을 적게 한다.
14차시정리7분

배운 내용 정리 (5분)

  • 이름표를 목에 걸고 모둠 안에서 차례로 켜 보며 별점 스티커 붙이기
  • 표시 순서를 바꾸었을 때 달라진 점 각자 쓰기
  • 예상과 실제 결과가 달랐던 곳 말하기

다음 차시 예고 (2분)

  • 버튼으로 바꾼 값에 따라 LED가 달라지는 다음 활동 안내 듣기
  • 활동지 두 장을 함께 정리해 내기
준비물별점 스티커
자료순서 바꾸기 활동지
유의점마이크로비트·케이블·배터리 팩은 수를 세어 거두고, 명찰 틀은 각자 보관하게 한다.
유의점기기 고장이나 코드 전송 실패를 학생의 이해 부족으로 평가하지 않는다.

평가 계획

컴퓨팅 사고력 · 순차 구조의 확인과 설명

LED 그림 두 개를 차례로 표시하는 코드를 기기로 옮겨 실행하고, 순서를 바꾼 결과를 예상과 견주어 설명할 수 있는가?

수준평가 기준
매우 잘함하트와 웃는 얼굴을 차례로 표시하는 코드를 만들어 마이크로비트에서 실행하고, 순서를 두 번 이상 바꾸어 보며 예상과 실제 결과를 모두 기록한다. 세 컷 이상의 LED 이름표를 스스로 만들어 시연하며, 순서가 결과를 바꾸는 까닭을 실행 결과를 들어 설명한다.
잘함두 그림을 차례로 표시하는 코드를 기기에서 실행해 확인하고 순서를 바꾼 뒤 달라진 점을 기록한다. LED 이름표를 만들어 순서와 결과의 관계를 한 문장으로 쓴다.
보통코드를 만들어 기기로 옮기기는 하나 일부 블록의 자리가 다르거나, 순서를 바꾼 기록에서 예상이나 달라진 점 한 가지가 빠져 있다.
노력요함교사가 절차를 한 단계씩 짚어 주고 블록 위치와 기기 연결을 함께 해 준 뒤에도 차례대로 표시하는 코드를 실행하거나 바뀐 결과를 기록하는 데 어려움이 있다.
미관찰결석이나 미제출, 기기와 케이블 장애로 확인하지 못한 경우. 낮은 성취로 적지 않고 따로 기록한 뒤 보충 확인 시점을 정한다.
