평가

말과 글이 글자 결과로 나오는 네 단계를 순서대로 말하고, 통역 도우미를 만들어 시험하며 결과가 달라진 곳이 어느 단계인지 근거를 들어 설명할 수 있는가?

평가 기준 자세히

인공지능 소양 · 말과 글이 처리되는 네 단계의 이해와 결과가 달라진 지점의 확인 — 말과 글이 글자 결과로 나오는 네 단계를 순서대로 말하고, 통역 도우미를 만들어 시험하며 결과가 달라진 곳이 어느 단계인지 근거를 들어 설명할 수 있는가?

수준평가 기준
매우 잘함네 단계를 순서대로 말하고 각 단계에서 하는 일을 자기 말로 설명한다. 받아쓰기 비서와 통역 도우미를 실행해 받아쓰기 기록표와 되돌리기 기록표를 빠짐없이 채우고, 달라진 곳에서 한 단계를 골라 그 근거를 자기 기록에서 찾아 설명한다. 사용 규칙 세 줄을 자기 관찰과 이어 쓴다.
잘함네 단계를 순서대로 말하고, 받아쓰기 비서나 통역 도우미를 실행해 두 기록표를 채우며 처음 문장과 달라진 곳을 찾는다. 한 단계를 고르고 근거를 한 문장으로 쓴다.
보통네 단계는 말하나 각 단계에서 하는 일의 설명이 짧다. 기록표 일부가 비었거나, 달라진 곳만 적고 단계를 고른 근거가 없다.
노력요함교사가 카드를 한 장씩 가리켜 주고 문장을 읽어 준 뒤에도 단계 순서를 말하거나 기록표에서 달라진 곳을 찾는 데 어려움이 있다.
미관찰결석이나 미제출, 기기 장애로 확인하지 못한 경우. 낮은 성취로 적지 않고 따로 기록한 뒤 보충 확인 시점을 정한다.

    교수학습 활동

    7차시도입8분

    동기 유발

    • 교사 기기의 음성 비서(스마트폰·스마트 스피커)에 준비한 질문 두 가지(“오늘 날씨 알려 줘.”, “지금 몇 시야?”)를 말해 시연하기
    • 학생 두세 명이 같은 질문을 말하고 답 듣기
    • 발문: “음성 비서가 엉뚱하게 알아들은 적이 있나요? 그때 무엇이 달랐을까요?”
    • 예상 반응: “작게 말했어요.”, “사투리로 말하니 못 알아들었어요.”, “컴퓨터가 말을 알아들어요.”
    • 5학년 담임 선생님의 의뢰 편지 읽기: “전학 온 친구에게 우리 학교를 안내할 통역 도우미를 만들어 주세요.”
    • 오늘 미션 확인: 말을 글자로 바꾸고, 다른 언어로 번역해 읽어 주는 통역 도우미 만들어 전달하기

    학습문제 제시

    • 말과 글이 글자 결과로 나오기까지의 네 단계를 짚어 보고, 엔트리 통역 도우미를 만들며 결과가 달라지는 곳을 찾아봅시다.
    준비물필기구
    자료네 단계 활동지, 의뢰 편지, [도입] 상황 그림, 교사 기기(음성 비서)
    유의점음성 비서는 교사 기기로만 시연하고, 이름·주소 같은 개인정보는 묻지 않는다.
    유의점‘컴퓨터가 알아듣는다’는 학생 답은 고쳐 주지 않고 그대로 판서해 두었다가, 정리 단계에서 네 단계로 다시 풀어 쓰게 한다.
    유의점활동지 배부 시간을 도입 시간에 포함한다.
    7차시전개32분

    활동1. 네 단계 릴레이 놀이 (15분)

    • (7분) 네 단계 카드를 ‘① 소리나 글 넣기 → ② 숫자로 바꾸기 → ③ 배운 자료에서 가장 비슷한 것 찾기 → ④ 결과 내놓기’ 차례로 함께 읽기
    • 모둠 네 명이 역할 나누기: 귀(①)·숫자 바꾸기(②)·비슷한 것 찾기(③)·입(④)
    • 귀가 소리 카드를 뽑아 넘기면 → 숫자 바꾸기가 카드의 숫자를 쪽지에 적어 넘기고 → 비슷한 것 찾기가 규칙표에서 차이가 가장 작은 줄의 글자를 고르고 → 입이 소리 내어 말하기 (역할 바꾸어 두 판)
    • (8분) 마이크로비트를 ‘귀’로 써서 네 단계 확인하기 (V2 마이크 사용)
    • 07-1 따라 만들기: [입력] ‘A 버튼 누를 때’ 안에 [기본] ‘수 출력’을 넣고, 숫자 자리에 [입력] ‘소리 크기’ 끼우기
    • 시뮬레이터에서 마이크 막대를 올렸다 내리며 A 버튼 → 보드에 내려받아 작게·크게 말하고 숫자 확인 (① 넣기 → ② 숫자로 바꾸기)
    • 07-2 바꿔 보기: [기본] ‘무한반복 실행’ 안에 [변수] ‘소리값 에 (소리 크기) 저장’을 넣고, [논리] ‘만약 ~이면 / 아니면서 만약 / 아니면’으로 소리값을 60·150과 비교해 잠든 얼굴·웃는 얼굴·놀란 얼굴을 ‘아이콘 출력’하기 (③ 기준표와 비교 → ④ 결과)
    • 기준 숫자 60을 30으로 바꾸면 결과가 어떻게 달라지는지 확인하기
    • 활동지에 내가 맡은 일과 마이크로비트의 각 블록이 네 단계 가운데 몇 번인지 적기
    • 발문: “같은 목소리인데 기준 숫자만 바꾸었더니 결과가 달라졌어요. 어느 단계가 바뀐 걸까요?”

    활동2. 엔트리 받아쓰기 비서 만들기 (17분)

    • (3분) 엔트리에서 작품 만들기 → 블록 꾸러미 [인공지능] → ‘인공지능 블록 불러오기’에서 ‘오디오 감지’와 ‘읽어주기’ 추가하기
    • (6분) 코드 07-3을 한 블록씩 붙이며 그때마다 실행해 보기

    ① [시작] ‘시작하기 버튼을 클릭했을 때’ → ② [인공지능] ‘음성 인식하기’

    ③ [생김새] ‘(안녕!)을(를) 말하기’의 글자 칸에 [인공지능] ‘음성을 문자로 바꾼 값’ 끼우기

    ④ [인공지능] ‘(엔트리) 읽어주고 기다리기’의 글자 칸에도 ‘음성을 문자로 바꾼 값’ 끼우기

    • (5분) 정해진 세 문장(높임말·우리 지역 말·보통 문장)만 한 번씩 읽고, 말풍선 글자를 받아쓰기 기록표에 그대로 옮겨 적은 뒤 다른 곳에 밑줄 긋기
    • (3분) 결과가 달라진 문장에서 네 단계 가운데 한 단계를 고르고 근거를 한 문장 이상 적기
    • 발문: “마이크로비트는 소리 크기만 숫자로 바꿨고, 엔트리는 글자까지 찾아냈어요. ③ 단계에서 무엇이 달랐을까요?”
    • 예상 오류: 마이크 사용 창에서 ‘차단’을 누름 → 주소창 왼쪽 자물쇠에서 마이크를 ‘허용’으로 바꾸고 새로 고침
    • 빨리 끝낸 학생(07-4): 시작 블록을 ‘스페이스 키를 눌렀을 때’로 바꾸고, 목소리 속도 바꾸어 보기
    준비물필기구, 소리 카드 묶음, 역할 이름표, 마이크로비트 V2(모둠당 1개), USB 케이블, 배터리 팩
    자료네 단계 카드, 네 단계 활동지, 받아쓰기 기록표, 학급 공용 기기(마이크), MakeCode(makecode.microbit.org), 엔트리(playentry.org)

    자료예제② 소리 판정기(교사 확인용, 07-2):
    https://makecode.microbit.org/_fV5LKfKR5etb
    자료시험 문장 세 개(활동3에서도 사용): 높임말(예: 교장 선생님께서 도서관에 오셨습니다.), 우리 지역 말(교사가 미리 준비), 보통 문장(예: 도서관은 2층에 있습니다.)
    유의점소리 크기 블록은 마이크가 있는 V2에서만 동작한다(보드 뒷면 마이크 구멍 확인). V1만 있으면 [입력] ‘빛 밝기’로 바꾸어 손으로 가렸다 떼며 같은 활동을 한다.
    유의점보드가 부족하거나 연결이 안 되면 시뮬레이터의 마이크 막대로 대신한다. 내려받기가 안 되면 USB 케이블(데이터용)과 MICROBIT 드라이브를 확인한다.
    유의점마이크로비트는 소리를 숫자로 바꾸는 단계까지만 직접 보여 주고, 말소리를 글자로 바꾸는 일은 엔트리로 이어 간다고 안내한다.
    유의점목소리는 녹음하지 않고 화면 글자만 옮겨 적은 뒤 지우며, 이름·주소·친구 이야기는 읽지 않게 한다.
    유의점엔트리 인공지능 블록은 인터넷이 필요하다. 수업 전에 교사 기기로 실제 블록 이름과 마이크 허용을 확인한다.
    유의점교실이 시끄러우면 인식이 잘 안 되므로 모둠 안에서 말하는 차례를 정한다.

    활동3. 번역 되돌리기 실험하기 (14분)

    • 시험 문장 세 개가 어떻게 다른지 말하고, 바꿀 언어를 반 전체가 같은 한 가지(예: 영어)로 정하기
    • 코드 08-1 만들기: 말 대신 글자로 넣어, 받아쓰기에서 생기는 차이를 빼고 번역만 살펴보기

    ① [시작] ‘시작하기 버튼을 클릭했을 때’ → ② [자료] ‘(번역할 문장을 입력하세요)을(를) 묻고 대답 기다리기’

    ③ [자료] ‘(번역한 문장)을(를) ( )로 정하기’에 [인공지능] ‘(한국어) ( )을(를) (영어)로 번역하기’를 끼우고, 글자 칸에 [자료] ‘대답’ 넣기

    ④ [자료] ‘(되돌린 문장)을(를) ( )로 정하기’에 ‘(영어) (번역한 문장)을(를) (한국어)로 번역하기’ 끼우기

    ⑤ [생김새] ‘(번역한 문장)을(를) (4)초 동안 말하기’ → ‘(되돌린 문장)을(를) 말하기’

    • 세 문장을 차례로 넣고 되돌리기 기록표에 결과를 적은 뒤, 달라진 낱말에 동그라미 치기
    • 짝과 기록표를 나란히 놓고 비교해 서로 다른 곳을 아래 칸에 적기
    • 발문: “높임말 ‘께서’, ‘오셨습니다’는 되돌린 뒤 어떻게 바뀌었나요? 지역 말은요?”

    활동4. 우리 학교 통역 도우미 완성하기 (19분)

    • (2분) 보건실·도서관·급식실 안내 문장 가운데 하나 고르기
    • (6분) 엔트리 08-2: 글상자 ‘영어’ 단추를 클릭하면 [생김새] ‘말하기’와 [인공지능] ‘읽어주기’에 ‘(한국어) (안내 문장)을(를) (영어)로 번역하기’를 끼워 번역해 말하고 읽어 주기 (도전 08-3: 단추 복제해 세 언어 / 선택 도전 08-4: 웹캠으로 얼굴을 인식하면 인사)
    • (5분) 마이크로비트 08-5 ‘사람 확인 단추’ 만들기: 도우미 얼굴에 달아, 번역을 들은 짝이 알아들었으면 A(✔), 다시 확인이 필요하면 B(✘)를 누르게 하기
    • [변수] ‘알아들음’, ‘다시확인’ 만들기 → [입력] ‘A 버튼 누를 때’ 안에 [변수] ‘알아들음 값 1 증가’와 [기본] ‘아이콘 출력(체크)’
    • ‘B 버튼 누를 때’도 같은 방법으로 ‘다시확인 값 1 증가’와 ‘아이콘 출력(엑스)’ → ‘A+B 버튼 누를 때’는 두 값을 차례로 ‘수 출력’
    • 도전 08-6: [입력] ‘흔들림 감지하면 실행’ 안에 ‘알아들음 에 0 저장’, ‘다시확인 에 0 저장’으로 기록 지우기
    • (3분) 골판지 도우미 얼굴 틀에 마이크로비트(확인 단추)와 입(스피커 자리)을 붙이고, 언어 단추를 알려 주는 깃발 달기
    • (3분) 짝과 세 문장을 시험해 ✔·✘ 개수를 세고, 그 결과를 근거로 사용 규칙 세 줄 쓰기: 그대로 써도 될 때·사람이 다시 확인할 때·넣지 않을 내용
    • 높임말과 지역 말이 사라진 까닭을 배운 자료와 이어 쓰고, 개발 일지에 고친 점 한 줄 적은 뒤 화면 글을 지우고 기기 끄기
    준비물골판지 도우미 얼굴 틀(앞 차시 작품이 있으면 이어서 사용), 색지, 빨대 깃발대, 테이프, 마이크로비트(V1/V2), 배터리 팩
    자료되돌리기 기록표, 번역 기록 활동지, 학급 공용 기기, 엔트리, MakeCode, 웹캠(선택 도전)
    자료예제③ 사람 확인 단추(학생 배포용, 08-5):
    https://makecode.microbit.org/_c8qKFKgH0J8D
    자료예제④ 사람 확인 단추 + 기록 지우기(교사 확인용, 08-6):

    유의점번역 실험은 ‘묻고 대답 기다리기’로 글자를 넣게 해, 받아쓰기 차이와 번역 차이가 섞이지 않게 한다.
    유의점읽어주기 목소리가 번역한 언어를 자연스럽게 읽는지 수업 전에 확인하고, 어색하면 말풍선(말하기)만 쓴다.
    유의점마이크로비트는 배터리 팩에 연결해 도우미 얼굴에 붙이고, A·B 버튼이 가려지지 않게 테이프 위치를 정한다.
    유의점08-5의 A+B는 두 버튼을 동시에 눌러야 하므로 시뮬레이터에서 ‘A+B’ 버튼으로 먼저 확인한다.
    유의점규칙을 ‘쓰면 안 된다’로 끝내지 않고 ‘언제 사람이 다시 확인할지’로 쓰게 한다.
    유의점번역 결과는 그 언어를 아는 사람이 확인하기 전까지 실제 안내문으로 붙이지 않는다.
    유의점이주배경 학생에게 발표를 강요하지 않고, 결과 차이는 어느 언어가 더 낫거나 못해서가 아니라 배운 자료가 달라서 생긴다고 설명한다.
    유의점웹캠 도전은 원하는 모둠만 하고 화면을 저장하지 않는다.

    • 도입에서 판서한 ‘컴퓨터가 말을 알아듣는다’를 네 단계로 풀어 쓰기
    • 담임 선생님께 드릴 보고 쓰기: 결과가 이상했던 문장과 그 단계, 확인 단추로 센 ✘ 개수, 사람이 확인할 점
    • 발문: “통역 도우미를 친구에게 그대로 건네도 될까요? 누가 무엇을 다시 확인해야 할까요?”
