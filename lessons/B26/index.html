학습 문제 — 사용 조건 카드로 못 알아본 사례를 모아 원인을 가리고, 한 부분만 고쳐 같은 방법으로 다시 시험해 봅시다.

개요

성취기준[6실인공지능04-03] 인공지능이 만들어지는 과정을 체험하고, 인공지능이 틀리는 원인을 데이터·모델·사용 조건에서 찾는다.

유의점물 없이 책상 앞에서 동작을 해 보이게 한다.
유의점쓰는 친구가 서툴러서 틀렸다고 적지 않게 한다.
25차시전개32분

활동1. 사용 조건 카드로 버그 사냥하기 (17분)

  • 조건 카드(다른 사람·왼손·빠르게·천천히·손등 착용) 두 장 뽑기
  • 기본 조건과 뽑은 조건을 사용 조건 기록표에 적기
  • 다른 모둠 친구가 코치를 차고 세 동작을 두 번씩 하기
  • 기대한 안내와 실제 아이콘·소리를 나란히 적기
  • 못 알아본 동작은 무엇으로 안내했는지 함께 적기
  • 기본 조건에서도 한 번 해 보고 결과를 따로 적기

활동2. 원인 가려 오류 도감 카드 만들기 (15분)

  • 원인 그림 카드 세 장(데이터·모델·사용 조건) 가운데 하나 고르기
  • 데이터부터: 그 조건의 샘플이 계획표에 몇 개였는지 세기
  • 모델: 기본 조건에서도 동작끼리 헷갈렸는지 보기
  • 사용 조건: 밴드가 헐겁거나 동작이 너무 짧았는지 보기
  • 근거를 찾지 못하면 ‘모르겠음’ 칸에 그대로 표시하기
  • 사례 하나를 골라 조건·원인·근거를 담은 도감 카드 만들기
준비물원인 그림 카드 3장(데이터·모델·사용 조건)
자료사용 조건 카드와 기록표, 원인 구별 활동지, 동작 데이터 계획표, 오류 도감 카드
유의점뽑은 조건 말고는 기본 조건과 같게 두어 조건마다 따로 견주게 한다.
유의점원인은 먼저 데이터(샘플 부족·치우침)에서 찾게 하고, 사용 조건은 그다음에 살핀다.
유의점원인 카드 뜻: 데이터는 샘플 부족·치우침, 사용 조건은 착용·동작 차이다.
유의점모델 원인은 기본 조건에서도 동작끼리 헷갈리는 경우로, 구별할 특징이 부족함을 뜻한다.
유의점초등에서는 모델 속을 고치지 않고 데이터·사용 조건 쪽으로만 고친다.
유의점원인을 ‘인공지능이 이상해서’라고 적지 않게 한다.
유의점‘빠르게’ 조건에서는 주변을 비우고 밴드를 조여 기기를 떨어뜨리지 않게 한다.
유의점느린 학습자는 원인 고르기 도움 카드를 쓰고, 빠른 학습자는 도감 카드를 하나 더 만든다.
26차시전개33분

활동3. 한 부분만 골라 고치기 (15분)

  • 고칠 부분을 데이터와 사용 조건 가운데 하나로 정해 적기
  • 모델 원인이면 두 동작 차이가 잘 드러나는 샘플 더하기
  • 데이터라면 CreateAI에 다시 연결해 그 조건 샘플 더하기
  • 예: 왼손에 차고 동작마다 샘플 3개씩 더 녹화하기
  • 사용 조건이라면 밴드를 고치거나 사용 안내 카드 쓰기
  • 시험 담당의 시도는 샘플로 녹화하지 않기
  • 고친 점 기록(2.0 기록)에 1.0과 달라진 점과 그대로 둔 점 적기

활동4. 코치 2.0 다시 시험하기 (18분)

  • 데이터를 고쳤다면 다시 학습시키고 MakeCode로 옮겨 내려받기
  • 지난 차시와 같은 시험 담당·순서 카드로 맞힌 수 적기
  • 활동1과 같은 조건 카드로 다른 친구가 다시 써 보기
  • 고치기 전후 결과를 비교표에 나란히 적기
  • 아직 못 알아보는 상황을 ‘알려진 한계’ 칸에 적기
  • 도전: AI for Oceans에서 적게·많이 가르친 결과 견주기
준비물밴드 보수 재료(벨크로·고무줄), 안전가위
자료고치기 전후 비교표, 고친 점 기록(2.0 기록)
유의점글루건이 필요한 보수는 교사가 맡는다.
유의점내려받은 기기는 CreateAI 연결 과정을 처음처럼 다시 거친다.
유의점맞힌 수가 오르지 않은 결과도 그대로 적게 하고 낮은 성취로 보지 않는다.
유의점빠른 학습자는 AI for Oceans(code.org/oceans)에서 적게·많이 가르친 결과를 견준다.

평가 계획

인공지능 소양 · 사용 조건별 오류의 원인 구별과 데이터 보완

사용 조건 카드로 모은 오류의 원인을 데이터·모델·사용 조건으로 가리고, 한 부분만 고쳐 같은 방법으로 다시 시험한 결과를 설명할 수 있는가?

수준평가 기준
매우 잘함조건 카드마다 다른 친구가 쓴 기록을 빠짐없이 남긴다. 못 알아본 사례마다 데이터·모델·사용 조건 가운데 원인을 샘플 수나 기본 조건 결과 같은 근거와 함께 가려 도감 카드로 정리한다. 한 부분만 고쳐 같은 시험 방법으로 다시 시험하고, 전후 결과와 남은 한계를 자기 기록으로 설명한다.
잘함다른 친구의 사용 기록을 적고 못 알아본 원인을 세 갈래 가운데 하나로 가리며, 한 부분만 고쳐 같은 시험 방법으로 다시 시험한 결과를 전후로 견주어 설명한다.
보통사용 기록을 적고 한 부분을 고쳐 다시 시험하지만, 원인을 샘플 수나 사용 조건과 잇지 못하거나 전후 비교표의 일부 칸이 비어 있다.
노력요함교사가 못 알아본 사례를 함께 짚어 주고 원인 후보와 기록할 칸을 지정해 준 뒤에도, 원인을 가려 적거나 한 부분만 고치는 조건을 지키는 데 어려움이 있다.
미관찰결석이나 미제출로 확인하지 못한 경우. 낮은 성취로 적지 않고 따로 기록한 뒤 보충 확인 시점을 정한다.
