아이콘 출처 — Microsoft Fluent UI System Icons (Color)
https://github.com/microsoft/fluentui-system-icons
Iconify 묶음 @iconify-json/fluent-color 1.2.21 (아이콘 판 1.1.316)에서 쓰는 것만 뽑아 SVG 파일로 저장했다.
파일 이름은 누리집에서 쓰는 이름으로 바꾸었고, 그라디언트 id 앞에 파일 이름을 붙였다. 모양은 바꾸지 않았다.
